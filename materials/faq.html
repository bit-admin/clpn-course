常见问题 FAQ

全课程层面的常见问题（共 22 条），分为学习与使用、R 与软件、统计概念、CLPN 方法、写作与报告五类。各课页面中还有针对本课内容的“常见问题与误区”。

学习与使用

我完全没学过统计和编程，真的能学会吗？

能。课程从均值和“什么是变量”讲起（1.1），R 从安装讲起（2.1）。关键是按顺序学、每节课都动手跑代码，每周保持 5–7 小时。

一定要按顺序学吗？

建议按 16 周计划 学。每节课页面顶部列出了先修课；已经掌握的内容可以只做测验，测验全对再跳过。

进度为什么不见了？

“已完成”标记保存在浏览器的本地存储里，换浏览器、无痕模式或清除缓存都会丢失。重要的记录请写进学习日志。

练习答案在哪里？

每节课的练习都有可展开的参考答案。需要写代码的练习，完整答案在 R/solutions/，包含在下载页的课程压缩包里。运行结果在 R/output/sol_*_log.txt。

R 与软件

安装包时报错怎么办？

先确认网络正常，并在 RStudio 中把 CRAN 镜像设为国内镜像（Tools → Global Options → Packages）。Windows 用户名或路径中有中文时容易出错，建议把课程放在 D:\clpn-course\ 这样的路径下。详见 R 代码使用说明。

为什么我运行的数字和网页上不完全一样？

大多数脚本设置了随机种子，结果应该完全一致。bootstrap 相关的脚本（8.2、8.3、10.2）默认单核运行，固定种子后结果也完全一致；如果你把 nCores 改成大于 1（并行），种子不能控制各子进程，每次运行的结果都会不同。边权重区间的端点通常只在小数点后两三位上变化，但 CS 系数不是连续变化的：它只能取删除比例网格上的值（相邻两档相差约 0.08），所以可能整档跳动。课程数据的 in-EI 就会在 0.44 和 0.52 之间跳，一次在 0.5 以上、一次在 0.5 以下，判断结论随之改变。需要报告的结果请用单核、固定种子运行。另外，R 或软件包版本不同也可能带来细微差异。

中文显示成方框或乱码？

图中的中文：_setup.R 会尝试设置中文字体；如果仍有问题，见 2.6 的常见错误。读入的中文乱码：多半是 GBK 编码，见 2.4。

Quarto 和 R Markdown 用哪个？

都可以。课程示例用 Quarto（R/solutions/week06.qmd）；如果没有安装 Quarto，同样的内容可以改为 .Rmd 文件，用 rmarkdown 渲染。

_setup.R 里有什么？

找到课程根目录、设置输出文件夹和中文字体、定义题目名称和常用函数（clpn_estimate()、cl_only()、edge_list() 等）。值得读一遍，但不需要修改。

统计概念

p 值到底是什么？

假如零假设为真，看到当前或更极端数据的概率。它不是“零假设为真的概率”，也不衡量效应大小。见 1.6。

相关显著但回归不显著，是不是算错了？

不是。回归系数是控制其他变量后的“独特”关联，与相关回答的是不同的问题。课程数据中的社会支持就是一个例子（2.5）。

为什么要用 LASSO，不用普通回归？

节点多时普通回归会有大量“碰巧不为 0”的小系数（过拟合、假阳性）。LASSO 把小系数压成 0，得到更稀疏、更易解释的网络。代价是保留下来的系数偏小。见 3.5、6.3。

lambda.min 和 lambda.1se 选哪个？

lambda.min 预测误差最小、边更多；lambda.1se 更保守、边更少。事先在分析计划中选定一个作为主分析（本课程用 lambda.min），另一个作为敏感性分析。见 7.2。

被试间和被试内有什么区别？

被试间：比别人更孤独的人是否也更抑郁；被试内：比自己平时更孤独的时候，之后是否更抑郁。标准 CLPM / CLPN 把两者混在一起。见 4.1、5.3。

CLPN 方法

CLPN 的边能说明因果吗？

不能直接说明。边是“控制所有 T1 节点后的时间预测”，可能受稳定特质、未测量混杂和间隔选择的影响。写作中用“预测”“与……一致”，不用“导致”“驱动”。见 5.4。

至少需要多少样本？

没有公认的“N 至少是节点数的几倍”这类硬性规则。N/p（样本量 ÷ 节点数）只是快速核算用的粗略指标：它越小，每个逐节点回归的信息越少，网络越稀疏、越不稳定。9 个节点就有 81 个系数；课程数据 N/p = 800/9 ≈ 89。真正需要多大样本，取决于假定的真实网络（边有多强、有多少条）和你要回答的问题，要用模拟来回答：Constantin、Schuurman 与 Vermunt（2026）给出了网络模型样本量规划的一般蒙特卡罗方法，7.6 课做了一个简化版。数据收集完之后，再用 bootstrap 和 CS 检查稳定性，见 8.2、8.3。

只有两波数据可以做 CLPN 吗？

可以估计 T1 → T2 网络，但无法在另一时间段检验复现，也无法用 RI-CLPM 分离稳定特质（至少需要 3 波）。局限部分要写明。

中心性排序第一的节点就是干预靶点吗？

不是。需要先确认 CS ≥ 0.25（最好 ≥ 0.5）、与第二名的差异经 bootstrap 检验显著，而且即便如此，它也只是“预测作用强”。是否适合干预需要干预研究来检验。见 6.5、7.4。

课程数据是真实的吗？

课文用的面板不是，是按设定的真实结构模拟的 N = 800、三波社区成年居民数据（data/simulate_data.R），所以可以检验方法能否找回真实结构（总体目标值与被试内真值，见 7.2）。数据字典见 数据字典。另外有两份真实的公开数据：7.6 课的练习用体育教练心理健康追踪（CC0，文件在课程包里）；ELSOC 案例用智利社会纵向研究的 PHQ-8（CC0，预处理后的分析文件在课程包里）。两份的来源、许可和引用格式都写在数据字典里。

写作与报告

方法部分最容易漏写什么？

λ 规则、CV 折数、随机种子、是否标准化、协变量是否惩罚、中心性是否包含自回归、bootstrap 次数和 CS 标准。对照报告检查表逐项检查。

结果中的数字怎样保证不出错？

每个数字都应能追溯到某个输出文件（10.2 的“数字—文件”对照表）。最好用 Quarto 行内代码自动插入，不要手抄。

怎样写局限？

至少包括：标准 CLPN 混合了被试间与被试内效应；观察数据无法排除未测量混杂；结论依赖于时间间隔；样本的代表性。见 10.3。
