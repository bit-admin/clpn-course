速查卡 2 · 回归结果怎么读

输出中的项含义报告写法
Estimate（b）其他预测变量不变时，x 每高 1 个单位，y 平均高 bb = 0.32
Std.all / β标准化系数：x 高 1 SD，y 平均高 β SDβ = .25（APA：不超过 1 的统计量去掉小数点前的 0；中文期刊常写 0.25，全文一致即可）
Std. Errorb 的抽样不确定性通常放在表里
t value = b / SE离 0 有几个标准误t(797) = 7.82
Pr(>|t|)假如零假设 b = 0 成立，得到与当前结果一样极端或更极端结果的概率p < .001（不写 p = 0）
confint()95% 置信区间；不含 0 ⇔ p < .0595% CI [0.24, 0.40]
R² / 调整 R²模型解释的结果变异比例R² = .10
glm 的 Estimatelog-odds；exp() 后为 OROR = 1.65，95% CI [...]
ORx 高 1 单位，几率乘以 OR（不是概率）几率增加 (OR − 1) × 100%
一句话模板

“控制协变量后，预测变量正向 / 负向预测结果（b = __，95% CI [__, __]，p = __）；模型解释了结果 __% 的变异。”

五个别犯的错
  • 把 b 说成因果（“导致”“使得”）。
  • p > .05 写成“没有关系”。
  • 用 β 跨样本比较。
  • 相关显著、回归不显著不是矛盾，而是“控制”的结果（2.5）。
  • OR 当作风险比。

速查卡 4 · 报告检查表

基于课程 9.3 课（参考 Burger 等人 2023 的网络分析报告规范）。逐项核对：

  • [ ] 样本：N、招募方式、各波人数与流失率、流失分析结果
  • [ ] 设计：波数、时间间隔，以及为何选择这个间隔
  • [ ] 节点：题目全文或简称、来源量表、为何选这些节点；冗余检查（goldbricker）
  • [ ] 缺失处理：方法（列表删除 / 插补 / FIML）及理由
  • [ ] 预处理：是否标准化；定序题目的处理
  • [ ] 估计：软件与版本（R、glmnet、bootnet）；逐节点 LASSO；λ 规则（lambda.min / 1se）；CV 折数；随机种子
  • [ ] 协变量：有哪些、是否惩罚（penalty.factor = 0）
  • [ ] 中心性：指标名称；是否含自回归；桥接的社群划分
  • [ ] 准确性：bootstrap 类型与次数；边权区间图
  • [ ] 稳定性：case-dropping 次数；CS 系数与判断标准（0.7 / 95% / 0.25）
  • [ ] 敏感性分析：做了哪些、主要结论是否保持
  • [ ] 图：图注说明颜色、粗细（maximum）、阈值、布局；自回归如何呈现
  • [ ] 表：完整 B 矩阵（可放补充材料）；非零交叉滞后边表
  • [ ] 措辞：用“预测”而非“导致 / 驱动”；不把单题写成构念
  • [ ] 局限：被试间 / 被试内混合、未测量混杂、间隔、样本代表性
  • [ ] 开放：代码与（模拟或可共享的）数据；预注册（如有）
