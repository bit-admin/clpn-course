M2 阶段测验

学完 2.1–2.6 后做（标准节奏第 5 周，与 M1 阶段测验一起）。8 道自动判分题 + 1 道简答，约 15 分钟。题目只需要读代码，不需要运行 R；做完可以在 RStudio 里自己验证。

自动判分题

在 R 里依次运行 x <- 5 和 x <- x * 2 + 1，现在 x 的值是多少？

<- 把右边算出来的结果存进左边的名字。第二行用的是 x 原来的值 5。
5 × 2 + 1 = 11，结果再存回 x。赋值与对象见 2.1。

scores <- c(3, 8, 5, 10)，那么 scores[3] 是多少？

R 的位置从 1 开始数。
第 3 个元素是 5。R 从 1 开始计数（有些语言从 0 开始），见 2.2。

dep <- c(2, NA, 4)。运行 mean(dep) 的结果是什么？

  • 默认情况下，R 不会自动跳过缺失值。
  • 对。只要有一个 NA，默认的平均数就是 NA；要用 mean(dep, na.rm = TRUE) 才会得到 3。
  • 不是。
  • 不会报错，只会返回 NA。
NA 表示缺失，na.rm = TRUE 告诉函数先去掉缺失值再计算，见 2.2。

数据里性别存成了 "男"、"女" 两种文字。在 R 里，最适合用哪种数据类型表示这种分类变量？

  • 文字不是数值。
  • 逻辑型只有 TRUE / FALSE。
  • 对。因子专门用来存“有固定几个类别”的变量。
  • 函数不是数据类型的选择。
数值、字符、逻辑、因子等类型见 2.2。

课程数据 clpn_sim_wide.csv 读进 R 后，dim(dat) 显示 800 34。这两个数分别表示什么？

  • 对。数据框是“行 = 个案、列 = 变量”。
  • 方向反了。
  • 不是。
  • dim() 给的是维度，不是统计量。
数据框的结构见 2.3。

想从数据框 dat 中只保留女性（gender == 1）。用 dplyr 应该写哪一个？

  • select() 是选“列”，不是选“行”。
  • 对。filter() 按条件选“行”。
  • 这会把所有人的性别都改成 1。
  • summarise() 用来汇总统计量。
select 选列、filter 选行、mutate 新建或修改列、summarise 汇总，见 2.3。注意判断“等于”要用两个等号 ==。

你昨天已经运行过 install.packages("glmnet")。今天重新打开 RStudio，要使用 glmnet，应该运行哪一行？

  • 安装只需要一次，重复安装浪费时间。
  • 对。每次新开 R 都要加载一次。
  • 关掉 R 以后，加载的包就失效了。
  • source() 是运行一个脚本文件。
install.packages() 安装一次，library() 每次加载，见 2.4。

同学把你的课程文件夹拷到自己电脑上，脚本里的 read.csv("C:/Users/小张/Desktop/data/clpn_sim_wide.csv") 就报错了。最好的改法是？

  • 不现实。
  • 对。项目会把工作目录设在课程文件夹，相对路径在任何电脑上都能用。
  • 下次换电脑还会出问题。
  • 不行。
RStudio Project 与相对路径，是“别人拿到也能运行”的前提，见 2.4。

简答题

简答 1

你运行 read.csv("data/my_survey.csv") 时出现报错：cannot open file 'data/my_survey.csv': No such file or directory。请写一条发到 R 论坛或学习群里的求助消息（4–6 句），要让从没见过你电脑的人不用来回追问就能帮你找到问题。

参考答案与评分标准

示例：“你好，我在运行 R/L2-4.R 第 12 行 read.csv("data/my_survey.csv") 时报错：cannot open file 'data/my_survey.csv': No such file or directory。我是双击 clpn-course.Rproj 打开的项目，getwd() 显示 ……/clpn-course。data 文件夹里有 clpn_sim_wide.csv，但我刚刚发现 my_survey.csv 放在了下载文件夹里。我已经试过把文件名重新输入一遍。请问应该把文件放在哪里？我的 R 版本是 4.5.0（下面贴了 sessionInfo() 的文字输出）。”

要点：说清楚运行的是哪一行代码、完整的报错原文、自己已经检查过什么（工作目录、文件是否在那个位置）、软件版本。

等级标准
3包含运行的代码、完整报错原文、已做过的检查（如 getwd()、文件位置）和软件版本，读者可以直接定位问题
2有代码和报错，但缺少已做过的检查或环境信息
1只说“读数据报错了怎么办”，没有代码或报错原文
0没有作答

做完以后

一次答对 70% 及以上就进入下一个模块；不到 70% 的，按错题解释里的链接回去复习，过几天再做一次。把一次答对的题数记进学习日志。计分方式和评分标准见测评总页。
