M8 阶段测验

学完 8.1–8.3 后做（标准节奏第 14 周）。8 道自动判分题 + 1 道简答，约 20 分钟。不需要打开 R。

自动判分题

对一份 N = 200 的样本做非参数 bootstrap，每个 bootstrap 样本是怎样得到的？

  • 样本量要与原样本相同，而且要有放回。
  • 对。
  • bootstrap 不收集新数据。
  • 那更像置换（7.7），不是 bootstrap。
非参数 bootstrap 的做法见 8.1。

做了 1000 次 bootstrap，把 1000 个相关系数从小到大排好。95% 百分位区间的下限取第几个值？

两端各去掉 2.5%。1000 的 2.5% 是多少？
1000 × 2.5% = 25，所以下限取第 25 个，上限取第 975 个。见 8.1。

为什么网络分析特别需要做准确性（稳定性）检验？

  • 这不是主要原因。
  • 对。
  • 与美观无关。
  • 恰恰是样本有限时最需要。
网络分析为什么需要准确性检验，见 8.1（Epskamp et al., 2018）。

某条交叉滞后边的估计值是 0.08，bootstrap 区间是 [0.00, 0.17]。下面哪种解读最恰当？

  • 区间下限是 0，说明至少 2.5% 的 bootstrap 样本把它压成了 0，谈不上“非常稳定”。
  • 对。下限为 0 只说明为 0 的样本不少于 2.5%；具体比例要看“为 0 的比例”（prop0）。
  • “不稳定”不等于“一定不存在”。
  • 区间越宽，估计越不精确。
边权重 bootstrap 区间的读法见 8.2。

为什么课程说，LASSO 估计的 CLPN 边的 bootstrap 区间“不能当作严格的置信区间”？

  • 对。
  • 次数再多也解决不了压缩带来的偏差。
  • 置信区间可以用于很多统计量。
  • CLPN 的边有方向，而且这与问题无关。
正则化估计下 bootstrap 区间的注意事项见 8.2。

两条边的 bootstrap 区间部分重叠。想知道“边 A 是否显著强于边 B”，应该怎么做？

  • 区间重叠不能直接说明差异不显著。
  • 对。
  • 单独的 p 值不能比较两条边。
  • 无关。
边权重差异检验见 8.2。

按 Epskamp 等人（2018）的经验标准，中心性的 CS 系数不应低于多少？

还有一个“最好高于”的标准是 0.5。
CS 不应低于 0.25，最好高于 0.5。这是基于模拟研究的经验规则，不是数学定理。见 8.3。

case-dropping bootstrap 在做什么？

  • 删除是随机的，不是按缺失挑的。
  • 对。
  • 删的是人，不是边。
  • 不对。
case-dropping bootstrap 与 CS 系数见 8.3。

简答题

简答 1

一项 CLPN 研究报告：in-EI 的 CS 系数 = 0.44，out-EI 的 CS 系数 = 0.13。作者在讨论中写道：“out-EI 最高的‘无人理解’是最重要的干预靶点。”请用 3–4 句话评价这句话，并给出你建议的写法。

参考答案与评分标准

out-EI 的 CS = 0.13，低于 0.25 的最低标准，说明 out-EI 的排序很不稳定：随机删掉一小部分样本，排第一的节点就可能变了，所以不能根据 out-EI 的排序挑出“最重要”的节点。即使稳定，out-EI 高也只说明它在时间上预测其他节点较多，不等于干预它就能改善其他症状（因果 / 干预需要实验或干预研究）。in-EI 的 CS = 0.44，可以谨慎解读排序（介于 0.25 和 0.5 之间）。建议写法：“out-EI 的稳定性不足（CS = 0.13），本研究不解释其排序；in-EI 的稳定性尚可（CS = 0.44），……可作为后续研究和随访监测的参考。”

等级标准
3指出 out-EI CS 低于 0.25、排序不可解释，并指出“干预靶点”是因果 / 干预层面的过度解读，给出合理的改写
2指出 CS 过低的问题，但没有提到干预语言的问题（或反之），改写基本合理
1只说“CS 有点低”，没有说明后果，也没有改写
0没有作答，或认为原文没有问题

做完以后

一次答对 70% 及以上就进入下一个模块；不到 70% 的，按错题解释里的链接回去复习，过几天再做一次。把一次答对的题数记进学习日志。计分方式和评分标准见测评总页。
