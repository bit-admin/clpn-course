结果（草稿，自动填数）

交叉滞后面板网络包含 9 个节点，共估计出 52 条非零交叉滞后边（共 72 条可能的边）。自回归边介于 0.28 至 0.45 之间。
最强的三条交叉滞后边依次为：T1“睡眠问题”→ T2“疲乏”（β = 0.14）、T1“被冷落”→ T2“无人理解”（β = 0.13）和 T1“无人理解”→ T2“疲乏”（β = 0.11）。
从孤独到抑郁方向的边权重之和为 0.56，从抑郁到孤独方向为 0.08。
出期望影响最高的节点为“无人理解”（out-EI = 0.61），入期望影响最高的节点为“疲乏”（in-EI = 0.40）。
case-dropping bootstrap 显示，out-EI 的 CS 系数为 0.20，in-EI 为 0.52；其中 CS < 0.25 的指标排序不予解释。in-EI 的 CS 接近 0.5 的界值（边缘稳定；换随机种子可能落到相邻一档），其排序仅作谨慎解释。
敏感性分析中，lambda.1se、加入协变量以及 T2→T3 网络与主分析边权重的相关分别为 0.67、0.997、0.64。

完整流程敏感性分析。按照 Wysocki 等人（2025）推荐的完整流程，先在 T1→T2 与 T2→T3 两段分别做逐节点 LASSO，任一段非零的 67 条交叉滞后路径进入路径模型（其余固定为 0），再在 lavaan 中无惩罚地重新估计（同一波内残差两两相关，FIML）。跨时间等值约束的嵌套检验为 Δχ²(76) = 84.69，p = 0.232，AIC 与 BIC 均偏向约束模型，因此最终采用两段路径相等的约束模型（χ²(167) = 249.39，CFI = 0.987，TLI = 0.975，RMSEA = 0.025，SRMR = 0.027）。按 p < .01 修剪后保留 16 条交叉滞后边（孤独→抑郁 3 条，抑郁→孤独 2 条，构念内 11 条）。主分析的 52 条非零交叉滞后边中有 16 条在完整流程中保留；主分析最强的 10 条边中有 8 条保留，未保留的是：T1“无人理解”→ T2“疲乏”（主分析 β = 0.11；完整流程 β = 0.03，p = 0.264）、T1“无价值感”→ T2“疲乏”（主分析 β = 0.09；完整流程 β = 0.04，p = 0.131）。修剪后，从孤独到抑郁方向的边权重之和为 0.30，从抑郁到孤独方向为 -0.04（主分析分别为 0.56 和 0.08）。

（局限性提示：观测得分 CLPN 混合了被试间与被试内效应；结果为预测关系，不能作因果解释。）
