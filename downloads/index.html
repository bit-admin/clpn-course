整门课一个压缩包：离线网站、数据、R 脚本和练习解答。解压后打开 index.html 学习，双击 clpn-course.Rproj 运行 R。

课程压缩包

clpn-course.zip

整门课一个压缩包。解压后得到 clpn-course/ 文件夹：

  • 离线网站：index.html、学习指南、全部课件和学习资料，双击 index.html 用浏览器打开即可，不需要联网；
  • 数据：data/（模拟数据、数据字典、simulate_data.R、生成数据时用的系数；另有 7.6 练习用的一份真实公开数据 coaches_mhc_raw.csv，CC0）；
  • R 脚本：R/（各课配套脚本、_setup.R、一键运行全部的 run_all.R、R 代码使用说明）、R/solutions/（练习解答）、R/output/（参考结果）；
  • README.md（文件夹说明，先看这个）、clpn-course.Rproj（双击用 RStudio 打开）、LICENSE（课程内容 CC BY 4.0，代码 MIT）、THIRD_PARTY_NOTICES.md。

解压后：浏览器打开 index.html 学习；双击 clpn-course.Rproj 运行 R。详细步骤见本页下方“怎样使用”。

数据

模拟的面板数据，不含真实个人信息。true_B_within.csv 与 true_B_population.csv 是生成数据时用的系数，不是你自己的估计结果。标准 CLPN 对准的是后者（总体 OLS，含特质混杂），两者不是同一张矩阵。也可以单独打开：

  • 数据字典
  • clpn_sim_wide.csv
  • clpn_sim_wide.sav（SPSS）
  • simulate_data.R

另有一份真实的公开数据，供 7.6 课的测量不变性练习使用：coaches_mhc_raw.csv（瑞士 422 名体育教练、3 波的心理健康连续体简版 MHC-SF 14 题；Ackeret et al., 2023，doi.org/10.5061/dryad.8931zcrws，CC0 1.0）。文件按原样收录（分号分隔），使用前请先读数据字典的说明：自带的分量表列与题目列对不上，波次间隔的说明也前后矛盾。

还有一份真实面板供 ELSOC 案例（案例页）使用：elsoc_phq8_wide.csv（智利社会纵向研究 2016–2018 年原始样本的 PHQ-8 三波与性别、年龄；COES 2022，doi.org/10.7910/DVN/LQMURF，CC0 1.0）。这是预处理后的子集，由 R/data_elsoc.R 从同样附带的原始文件 data/elsoc/ELSOC_Wide_2016_2021_v1.00_R.RData 写出；分析脚本是 R/case_elsoc.R。引用格式见数据字典最后一节。

怎样使用

1. 下载并解压

从下载页取得 clpn-course.zip，解压（Windows：右键 →“全部解压缩”；Mac：双击）。得到一个文件夹 clpn-course/，学习和运行 R 需要的东西都在里面：

clpn-course/
├── index.html             ← 课程网站的离线版：双击用浏览器打开，不需要联网
├── README.md              ← 文件夹说明（先看这个）
├── START_HERE.html        ← 学习指南
├── lessons/、materials/   ← 课件与学习资料
├── clpn-course.Rproj      ← 双击它，用 RStudio 打开课程项目
├── LICENSE、THIRD_PARTY_NOTICES.md
├── data/                  ← 模拟数据、数据字典、simulate_data.R、true_B_*.csv；7.6 练习用的真实数据 coaches_mhc_raw.csv
└── R/
    ├── README.md / .html  ← R 代码使用说明
    ├── _setup.R、run_all.R
    ├── L0-2.R、L1-1.R … L10-3.R、L2-6_report.Rmd、assess_answers.R
    ├── data_elsoc.R、case_elsoc.R   ← 真实数据案例（预处理、CLPN）
    ├── solutions/         ← 练习解答
    └── output/            ← 参考结果（网页上的图、日志）；运行脚本会用你的结果覆盖

请先解压再使用，不要在压缩包的预览窗口里直接打开文件。路径里最好不要有中文和空格（例如放在 D:\clpn-course）。从 GitHub 获取整个仓库的，仓库根目录就是同样的课程文件夹。

2. 打开项目

  1. 按 R 代码使用说明 安装 R 和 RStudio（先装 R，再装 RStudio）。
  2. 双击 clpn-course/clpn-course.Rproj。RStudio 以“项目”方式打开，工作目录就是 clpn-course 文件夹。每个脚本第一行的 source("R/_setup.R") 都依赖这一点：不要直接双击 .R 文件打开。
  3. 打开 R/L2-4.R 点 Source，安装课程需要的包（只需一次）。
  4. 打开 R/L1-1.R，逐行运行（Ctrl/Cmd + Enter），确认能看到输出。之后每节课打开对应的 R/Lx-y.R（0.1 课和 9.1 课没有脚本）。

3. 运行顺序与依赖

按课号顺序运行即可。下面这些脚本要读取前面脚本在 R/output/ 生成的文件。压缩包里的 R/output/ 已带有参考结果，所以直接运行也能读到；但如果你修改并重新运行了前置脚本，后面的脚本就会用你的新结果。如果需要的文件不存在（例如删掉了 R/output/），脚本会在开头停下，并告诉你先运行哪个脚本。

脚本需要先运行
L6-5.R、solutions/L6-4_solution.R、solutions/L6-5_solution.RL6-4.R
L10-1.R → L10-2.R → L10-3.R依次：L4-3.R → L10-1.R → L10-2.R → L10-3.R（每一步都需要上一步的结果）
solutions/L8-3_solution.RL8-2.R（读 L8-2_boot.rds）和 L8-3.R
case_elsoc.R随课程提供的 data/elsoc_phq8_wide.csv（由 data_elsoc.R 从随课程提供的原始文件写出）
其余脚本无

一次运行全部：source("R/run_all.R")。它按课号运行全部课文脚本和期末答案脚本，再运行全部答案脚本（R/solutions/）。约 40–95 分钟（视电脑而定），大部分时间是 L8-2、L8-3、L10-2 的 bootstrap；结果汇总在 R/output/run_all_status.csv。其中也包括真实数据案例的 data_elsoc.R 和 case_elsoc.R。

bootstrap 默认单核运行（nCores = 1）、固定种子，在同一 R / 包版本下结果逐位可重复，与网页上的数字一致。改成并行会快几倍，但结果不再可重复：区间端点一般只在小数点后两三位上变化，CS 系数却可能整档跳动（课程数据的 in-EI 会在 0.44 和 0.52 之间变化，正好跨过 0.5 的参考线）。

课内“配套脚本”链接指向单个 .R 文件，可在浏览器中直接阅读；要运行，请在 RStudio 里通过 clpn-course.Rproj 打开。
