Data Dictionary and Data-Generating Model Specification

Source Markdown: data_dictionary.md

File: clpn_sim_wide.csv (identical content in clpn_sim_wide.sav). Generated by data/simulate_data.R (random seed set.seed(20261016)). Fully simulated data containing no real personal data.

  • Sample: N = 800 adults (community sample aged 18–85), 3 waves (T1/T2/T3), 6-month wave lag (T1 → T2 → T3 across one full year), wide format (one row per participant), no missing data (for missing data and attrition exercises, see R/L4-3.R).
  • Nodes (9 items): Loneliness lone1–lone4 (scored 1–4, modeled on the UCLA-3); Depression dep1–dep5 (scored 0–3, modeled on the PHQ-9, right-skewed).
  • Column naming convention: <item>_t<wave>, e.g., dep3_t2 = "Sleep problems" at Wave 2.
  • Detailed variable descriptions:

Data-Generating Model ("Ground Truth")

  1. Within-person lagged structure (true_B_within.csv): B[k, j] = item k at wave T → item j at wave T+1. Autoregressive effects: 0.35 (Loneliness items) / 0.30 (Depression items). Cross-lagged edges:
    • Loneliness → Depression: lone3 → dep1 (0.18), lone1 → dep2 (0.14), lone4 → dep5 (0.12)
    • Depression → Loneliness: dep2 → lone3 (0.12), dep4 → lone2 (−0.15; negative edge for contrasting expected influence vs. strength centrality)
    • Within-construct: dep3 → dep4 (0.16), dep1 → dep5 (0.10), lone2 → lone4 (0.10)
  2. Contemporaneous residual correlations: 0.35 within construct, 0.15 across constructs; T1 drawn from the stationary distribution.
  3. Stable traits (random intercepts): Loneliness trait and depression trait correlated at 0.50; trait variance per item ≈ 0.45 (with within-person variance = 1); female indicator adds +0.2 to depression items.
  4. Latent continuous scores are discretized into Likert categories using thresholds.

What should CLPN recover? Due to stable traits and categorization, standard CLPN on observed data targets the population target (data/true_B_population.csv) rather than the within-person truth (data/true_B_within.csv). This population target represents the population OLS coefficients obtained by regressing each standardized T2 item on all standardized T1 items in a large simulated population of N = 200,000 generated from the same model. Within-construct spurious edges of approximately 0.05–0.07 arise from stable between-person trait confounding—the fundamental limitation examined in Lessons 5.3 and 7.5.

Known Issues (Mention Them in Your Exercise Write-Up)

  1. Contradictory wave intervals: The dataset abstract and documentation state "baseline, 3 months later, 6 months later", whereas the published Methods section states "baseline, month 6 and month 12". Because we did not contact the authors for clarification, this dataset is used strictly to test whether the same constructs are measured across time (longitudinal measurement invariance), without interpreting the temporal rate of change, and it is not used for CLPN estimation.
  2. Pre-calculated subscale columns do not match raw item columns: Correlations between subscale means recomputed from raw items and the author-provided summary columns (which should be ~1.00):
WaveEmotional (w1–3)Social (w4–8)Psychological (w9–14)*_WB_cont vs. Sum of 14 Items
T10.900.150.180.97
T20.350.220.251.00
T30.300.090.221.00

For T2 and T3, *_WB_cont equals exactly "sum of 14 items − 14" for all participants; at T1, this holds for only 89 of 420 participants. The raw item columns themselves exhibit good longitudinal consistency: correlations of the 14-item sum across waves are T1–T2 = 0.73, T2–T3 = 0.76, and T1–T3 = 0.73. Due to these discrepancies, the course computes all scores directly from the raw item columns. This serves as a practical lesson in real-world data analysis: when using external datasets, always verify that summary columns replicate from raw items before using them.

  1. Documentation states "only complete respondents included", but in Wave 1 two participants have incomplete responses on the 14 items (complete item responses: T1 = 420, T2 = 301, T3 = 259). The exercise uses Full Information Maximum Likelihood (FIML; missing = "ml"), retaining all 422 participants in the model.

Appendix: ELSOC (Real-Data Case Study)

The Real-Data Case Study applies the course's primary "LASSO-only" CLPN methodology to depression symptoms from the Chilean Longitudinal Social Study (ELSOC) across 2016–2018. The analysis dataset data/elsoc_phq8_wide.csv is bundled with the course (available in both the repository and clpn-course-en.zip). Sample sizes, coefficients, and intervals are detailed on the case study page and dynamically loaded during site generation from R/output/data_elsoc_log.txt and case_elsoc_*.csv rather than transcribed manually.

  • Source (recommended Harvard Dataverse citation): Reproducible Research, Centre for Social Conflict and Cohesion Studies COES, 2022, "Estudio Longitudinal Social de Chile 2016-2021", https://doi.org/10.7910/DVN/LQMURF, Harvard Dataverse, V1, UNF:6:z/vWFguq9fg03YaOLWFddA== [fileUNF]. Please cite this dataset using this format whenever it is used.
  • License: Released under CC0 1.0 Universal on Dataverse; freely redistributable. The course bundles both the raw dataset and the preprocessed subset, enabling offline completion of the case study even if remote Dataverse downloads fail.
  • Raw File: data/elsoc/ELSOC_Wide_2016_2021_v1.00_R.RData (V1, 4.8 MB, 1,848 columns), identical byte-for-byte to the Dataverse file (MD5 a5a45571d39cf9db12e1949fdcb6fff2). It contains all original survey variables, including PHQ item 9 which is excluded from this case study (see item 1 in "Three Things to Know Before Use" below).
  • Generation: R/data_elsoc.R reads the raw file (downloading from Dataverse and verifying via MD5 if missing) and exports data/elsoc_phq8_wide.csv. Running this script is not necessary to complete the case study; run it only if you wish to inspect the data preparation process.

Three Things to Know Before Use

  1. Item 9 is excluded: Standard PHQ-9 item 9 asks about passive/active thoughts of death or self-harm, requiring clinical follow-up protocols and making it inappropriate as a routine node in instructional settings. The PHQ-8, widely used in epidemiological research, similarly omits this item. The preprocessing script does not export it; do not add it back.
  2. Scoring is 1–5, not 0–3: ELSOC uses a 5-point frequency scale (1–5), yielding an 8-item sum score range of 8–40 rather than the 0–24 range standard in clinical PHQ-8 administrations. Do not interpret sum scores using standard clinical cut-offs (such as 10 or 20).
  3. Item numbering swap relative to standard PHQ-9: ELSOC transposes standard items 6 and 7. In ELSOC:
    • phq6 = Trouble concentrating (item 7 in standard PHQ-9)
    • phq7 = Low self-worth / feeling bad about oneself (item 6 in standard PHQ-9) Course labels and script outputs follow the original item wording rather than the standard PHQ-9 numbering: phq6 = "Trouble concentrating", phq7 = "Low self-worth".
