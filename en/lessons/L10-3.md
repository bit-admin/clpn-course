### Structure of the results section (APA style)

1. **Network structure:** number of edges (as a share of the possible edges), range of autoregression, the strongest cross-lagged edges, sums of edge weights in the two directions.

2. **Centrality:** nodes with the highest out-EI / in-EI / bridge EI (point to the table and figure).

3. **Accuracy and stability:** overall picture of the bootstrap intervals, CS-coefficients and the standard used.

4. **Sensitivity:** how well the alternative analyses agree with the main analysis, and whether the main conclusions change.

5. **Full-procedure sensitivity analysis:** model choice (equality test, AIC, BIC), edges kept after pruning, edge-by-edge agreement with the main analysis (see "How to write up the two analyses" below).

The results section only states the findings without discussing them; interpretation, comparison with the literature, limitations and practical implications go in the discussion.

### How to write up the two analyses: methods, results and discussion

The main analysis (LASSO only) and the required sensitivity analysis (the full procedure, Lesson 10.2) each appear once in three places, with different jobs: the methods say how each analysis was done and how results are interpreted; the results state the two sets of results side by side; the discussion explains what the agreements and disagreements mean.

#### Writing the methods (data analysis)

Describe the settings of both analyses in enough detail that someone else could redo them (Lesson 9.3). You can adapt the paragraph below, replacing the content in parentheses with your own settings:

“The main analysis was a LASSO-only cross-lagged panel network: each T2 item was regressed on all 9 T1 items in a separate LASSO regression (glmnet, 10-fold cross-validation, lambda.min, random seed 2026), with items z-standardized beforehand; the nonzero coefficients form the edges of the network. As specified in the analysis plan, the full procedure recommended by Wysocki et al. (2025) served as a sensitivity analysis: the same LASSO was run for T1→T2 and for T2→T3, cross-lagged paths that were 0 in both intervals were fixed to 0, and the remaining cross-lagged paths and all autoregressive paths were estimated without penalty in a path model in lavaan (version number); all residuals within a wave were allowed to correlate, and missing values were handled with FIML. A model with equality constraints across time was compared with an unconstrained model using a nested χ² test, AIC and BIC, and the constrained model was used when none of the three argued against equality. Cross-lagged paths with p < .01 in the final model were considered retained, and each node's in-prediction and out-prediction were computed. Edges retained in both analyses were treated as main findings, and edges found in only one analysis as exploratory findings.”

Note the last sentence: the interpretation rule is part of the method, so it belongs in the methods, not introduced only in the discussion.

#### Writing the results

The full procedure gets its own paragraph, after the other sensitivity analyses. The draft generated automatically by `R/L10-3.R` (`L10-3_results_draft.md` in the "Actual output" below) already contains this paragraph, which covers five things in order:

1. what was done (a one-sentence recap of the settings; details in the methods);

2. model choice: Δχ², degrees of freedom and p-value of the equality test, which way AIC and BIC point, which model was used and its fit indices;

3. how many cross-lagged edges were kept after pruning, and how many in each direction;

4. agreement with the main analysis: how many of the main analysis's edges were kept, and which of the strongest were not (with both estimates and the p-value);

5. construct level: the sums of edge weights in the two directions in each analysis.

For the course data, the key numbers of this paragraph are: 67 cross-lagged paths entered the SEM; equality test Δχ²(76) = 84.69, p = 0.232, so the constrained model was used; 16 edges kept after pruning; 8 of the 10 strongest edges of the main analysis kept. The results only state these, without explaining "why".

#### Writing the discussion

| Situation | Results | Discussion |
| --- | --- | --- |
| Kept by both analyses | List these edges with both estimates | Interpret them as main findings; note that they do not depend on the estimation method. Cite the unpenalized estimates for effect sizes |
| Nonzero only in the main analysis | State that they were not kept by the full procedure (give the p-value) | Describe them as "sensitive to the estimation method" and interpret them only as exploratory; do not base practice recommendations on them. If an edge appears in only one interval of data, say so |
| Kept only by the full procedure | State that they were 0 in the main analysis | Likewise report them only as exploratory; explain that they come from combining the two intervals of data |
| Direction at the construct level | Sums of edge weights in the two directions, one set per analysis | If the directions agree, it can go in the abstract; if not, you can only say "the direction depends on the estimation method" |

A discussion paragraph for the course data could read like this (numbers from the L10-2b output):

“The networks from the two estimation methods are similar overall (correlation of the coefficients over the 72 cross-lagged positions r = 0.842), but the full procedure keeps far fewer edges (16, against 52 in the main analysis). Loneliness → depression edges kept by both analyses: "Lack of companionship → Loss of interest" (0.114), "Feeling isolated → Depressed mood" (0.095), "No one understands me → Worthlessness" (0.094); depression → loneliness edges: "Fatigue → Feeling left out" (−0.117), "Loss of interest → Feeling isolated" (0.079). The fairly strong 'No one understands me → Fatigue' edge of the main analysis was not kept by the full procedure: it appears only in the T1→T2 interval (its LASSO estimate in the T2→T3 interval is 0.000), and it is not significant once the two intervals are combined (p = 0.264). This study therefore does not treat it as a main path from loneliness to depression. In both analyses, the sum of edge weights in the loneliness → depression direction is larger than in the reverse direction; this construct-level pattern does not depend on the estimation method.”

**Common mistakes when writing up the two analyses**

- **Mentioning the full procedure only when it agrees.** It is required, and it matters even more when it disagrees.

- **Writing "the full procedure confirmed …".** A sensitivity analysis can only show whether a result depends on the estimation method; it cannot "confirm" an edge, let alone prove causation.

- **Attributing numbers to the wrong analysis.** p-values and standard errors come only from the full procedure (LASSO gives no p-values); CS-coefficients and bootstrap intervals come only from the main analysis. Make clear which analysis each number comes from.

- **Mixing the coefficients of the two analyses in one ranking table.** LASSO coefficients are shrunk and unpenalized estimates are not, so their sizes cannot be compared.

- **Thinking that agreement between the two analyses removes the limitations.** Both are based on observed scores and both mix between-person and within-person effects (Lesson 10.2, "Agreement between the two analyses does not make it a within-person process").

### Limitations

The limitations tell readers where the results can and cannot be generalized. A CLPN study should discuss at least these five points:

| Aspect | What to say | Example wording |
| --- | --- | --- |
| Between-person / within-person | A standard CLPN is based on observed scores and mixes stable individual differences with within-person change (Lessons 5.2–5.3) | “The cross-lagged edges in this study may partly reflect stable between-person differences rather than within-person dynamic processes; future research could use models that separate between-person effects (such as network extensions of the RI-CLPM).” |
| Causation | Edges are predictive relationships over time and may be affected by unmeasured third variables | “The cross-lagged edges cannot be interpreted as causal effects.” |
| Measurement | Single items have low reliability; item content may overlap; the measurement interval may not be the best time scale for the process (Lesson 5.4) | “Each node was measured by a single item … the 6-month interval may …” |
| Estimation method | The LASSO coefficients of the main analysis are shrunk and include false positives; the full procedure is more conservative and misses weak edges; both are based on observed scores | “Some edges of the main analysis were not retained by the full procedure, and their interpretation is exploratory; at p < .01 the full procedure may miss weaker true edges.” |
| Sample | Source of the sample, representativeness, attrition | “The sample came from …; whether the conclusions generalize to … remains to be tested.” |

If you used the simulated data, you can also say: "Because the true structure is known, this study assessed the method's performance: the correlation between estimated and true edges was 0.65, suggesting …"

### Practice implications: how to explain it to social work colleagues

Imagine explaining the main findings to a social work colleague who has never studied statistics. You could say:

“We followed 800 people for six months. People who felt lonelier tended to have more depressive symptoms six months later; the other way round, depression predicted later loneliness much more weakly (this difference was tested with the bootstrap, Lesson 8.3, exercise 1). Which particular kind of loneliness matters, these data cannot say: the top few items could change with a different group of people. And this is only a predictive relationship; it does not prove that depression will go down if loneliness is reduced. If you design a group program, you could try making the reduction of loneliness as a whole the goal, and evaluate the effect.”

This explanation has three parts: the finding (in everyday language), its limits (not causal, rankings of single items unstable) and a testable suggestion for action.

**Why not recommend "focus on feeling understood"**

In the sample, "No one understands me" has both the highest out-EI and the highest bridge out-EI, and "No one understands me → Fatigue" is one of the strongest edges, so it is tempting to write "helping clients feel understood should be the priority". But the CS of out-EI is only 0.20, so the ranking cannot be interpreted. And against the two kinds of truth for the course data (Lesson 10.2, "Edge-by-edge comparison with the true structure"), "No one understands me → Fatigue" is only 0.005 in the population, while the strongest loneliness → depression edge under both kinds of truth is "Feeling isolated → Depressed mood" (0.118). The required full-procedure sensitivity analysis did not keep this edge either (Lesson 10.2: SEM re-estimate 0.031, p = 0.264). An intervention designed around the most eye-catching item in the sample would pick the wrong focus. Practice recommendations can only rest on patterns that are stable, overall and consistent across the two analyses.

### Questions readers or reviewers may ask (prepare your answers)

“Why not use the RI-CLPM?”

Suggested answer: the RI-CLPM separates between-person and within-person effects, but so far it is used mainly for a few variables (total scores); the strength of a CLPN is the network structure at the item level. The two answer different questions. In the limitations I state that the CLPN mixes between-person and within-person effects.

“What does CS = 0.20 mean?”

It means that dropping only a small share of participants may change the out-EI ranking considerably, so I do not interpret the out-EI ranking and only report the values.

“Wysocki et al. recommend the full procedure; why did you still use LASSO only for the main analysis?”

Suggested answer: to allow direct comparison with published CLPN studies, and to be able to run the edge-weight bootstrap and compute CS-coefficients, both of which are built on the LASSO estimate. The analysis plan lists the full procedure as a required sensitivity analysis, and its results are reported alongside; the main findings are only the edges kept by both analyses.

“When the two analyses disagree, which one do you believe?”

Suggested answer: I do not believe either one all the way. LASSO tends to report too many edges, the full procedure too few. By the rule written in advance, edges kept by both are the main findings; edges found in only one analysis I describe as "sensitive to the estimation method" and interpret only as exploratory. Because the course data are simulated, you can see the cost of this rule: the full procedure misses quite a few weak real edges.

“Does this show causation?”

No. A cross-lagged edge is a predictive relationship over time, controlling for all T1 items, and it may still be affected by unmeasured variables or between-person differences.

“If you did the study again, what would you change?”

For example: add waves, so that models separating within-person effects (the RI-CLPM and its network extensions) can be estimated more stably (with 3 waves the RI-CLPM is just identified, but its estimates are very imprecise; see Lesson 5.3); choose an interval that fits the time scale of the process; measure key nodes with several items; preregister; enlarge the sample to improve the stability of centrality.

## ② Essential Math Write the Intuition as Equations

The summary numbers the results section reports can all be computed directly from the estimated matrix \(\hat B\).

\[\text{density}=\frac{E}{p(p-1)}=\frac{52}{72}\approx 0.72\]

| Symbol | Reading / Meaning |
| --- | --- |
| \(E\) | Number of nonzero cross-lagged edges |
| \(p\) | Number of nodes; \(p(p-1)\) is the number of possible cross-lagged edges |

A density of 0.72 is high, which is typical of lambda.min (it tends to keep edges, including some false positives; Lesson 7.2). Reporting the density in the results reminds readers how "dense" the network is.

\[S_{L\to D}=\sum_{k\in L}\sum_{j\in D}\hat\beta_{kj}=0.56,\qquad S_{D\to L}=\sum_{k\in D}\sum_{j\in L}\hat\beta_{kj}=0.08\]

| Symbol | Reading / Meaning |
| --- | --- |
| \(L,\ D\) | The set of loneliness items (lone1–4) and the set of depression items (dep1–5) |
| \(S_{L\to D}\) | Sum of the weights of all cross-lagged edges from loneliness to depression |

Note: the number of nonzero edges may differ between the two directions, but in each direction there are 4 × 5 = 20 possible edges, so the two sums can be compared directly. They are only descriptive summaries, though, and have no significance test of their own; to say "the loneliness → depression direction is stronger", you need to test the distribution of this difference in the bootstrap (Lesson 8.3, exercise 1, does this test with `L8-2_boot.rds`).

### Structure of a 10-minute talk

A talk follows the same order as a paper, but with different proportions: question and significance, 1.5 minutes (why social workers should care how loneliness and depression are related); data and methods, 2 minutes (only N, number of waves, interval, estimation method and stability checks); results, 4 minutes (one network plot, one centrality plot, and one sentence on stability); limitations and implications, 2 minutes (stable traits, causality, how representative the sample is, and cautious implications for practice); 0.5 minutes as a buffer. Give each slide one message and make its title the conclusion, stated only as far as the data support it: for example "Edge weights sum higher in the loneliness → depression direction (0.56 vs 0.08, difference not tested)" rather than "Result 2". Only if you tested this difference with the bootstrap can you write "… significantly larger than the reverse direction".

**Common mistakes in writing and presenting**

- **Mixing discussion into the results.** The results section says only "what was found"; "what it means" belongs in the discussion.

- **Putting the whole 9 × 9 matrix on a slide.** The audience can't read it. Show only the plots and the 3–5 most important numbers; keep the full table for questions or the supplementary material.

- **Avoiding the limitations.** Raising the limitations around stable traits and causal inference yourself is much better than having the audience raise them.

## Results (Draft with Programmatically Inserted Values)

The cross-lagged panel network comprised 9 nodes, yielding 52 non-zero cross-lagged edges out of 72 possible directed edges. Autoregressive edges ranged from 0.28 to 0.45.

The three strongest cross-lagged edges were: T1 'Sleep problems' → T2 'Fatigue' (β = 0.14), T1 'Feeling left out' → T2 'No one understands me' (β = 0.13), and T1 'No one understands me' → T2 'Fatigue' (β = 0.11).

The sum of edge weights from Loneliness to Depression was 0.56, whereas that from Depression to Loneliness was 0.08.

The node with the highest out-expected influence was 'No one understands me' (out-EI = 0.61), and the node with the highest in-expected influence was 'Fatigue' (in-EI = 0.40).

Case-dropping bootstrap revealed that the CS-coefficient was 0.20 for out-EI and 0.52 for in-EI; centrality rankings with CS < 0.25 were not interpreted. The CS for in-EI was close to the 0.5 threshold (marginally stable; changing the random seed may shift it to an adjacent grid level), and its rank order should be interpreted with caution.

In sensitivity analyses, the edge-weight correlations between the primary analysis and networks estimated via lambda.1se, including covariates, and across T2→T3 were 0.67, 0.997, 0.64, respectively.

(2025), nodewise LASSO regressions were first conducted separately for the T1→T2 and T2→T3 lags. The 67 cross-lagged paths non-zero in either lag were entered into a path model (the remainder fixed to zero) and re-estimated without penalization in lavaan (cross-sectional residual covariances within wave, FIML). Nested testing of cross-time invariance constraints yielded Δχ²(76) = 84.69, p = 0.232, and both AIC and BIC favored the constrained model; therefore, the constrained model specifying equal paths across lags was retained as the final model (χ²(167) = 249.39, CFI = 0.987, TLI = 0.975, RMSEA = 0.025, SRMR = 0.027). Pruning at p < .01 retained 16 cross-lagged edges (3 Loneliness→Depression, 2 Depression→Loneliness, 11 within-construct). Of the 52 non-zero cross-lagged edges in the primary analysis, 16 were retained in the full procedure; among the 10 strongest edges in the primary analysis, 8 were retained (those not retained were: T1 'No one understands me' → T2 'Fatigue' (primary analysis β = 0.11; full procedure β = 0.03, p = 0.264); T1 'Worthlessness' → T2 'Fatigue' (primary analysis β = 0.09; full procedure β = 0.04, p = 0.131)). Following pruning, the sum of edge weights from Loneliness to Depression was 0.30, and from Depression to Loneliness was -0.04 (compared to 0.56 and 0.08 in the primary analysis).

(Methodological Caveat: Observed-score CLPN conflates between-person and within-person effects; findings reflect predictive relationships rather than causal processes.)

## ④ Concept Check Instant Check

What is the best way to get the numbers in the results section?

- A. Read them off the plots

- Reading off plots is imprecise, and you cannot read the third decimal from a plot.

- B. Copy them by hand from the tables

- Easy to miscopy; the table gets revised and the text still has the old version.

- C. Generate them automatically from the result objects with code (Correct)

- Correct.

- D. Copy them from the printout in the R console, keeping all decimals

- More precise than reading off plots, but still copying by hand: once the analysis is rerun, the text is out of date; and keeping all decimals does not follow reporting precision.

Which sentence belongs in the results section?

- A. Loneliness caused depression

- "Caused" is causal wording; a CLPN gives only predictive relationships.

- B. T1 'No one understands me' predicted T2 'Fatigue' (β = 0.11) (Correct)

- Correct.

- C. This shows social workers should make loneliness the first target of intervention

- This belongs in the discussion (practical implications), and it jumps straight from a predictive relationship to intervention.

- D. This matched our expectations completely, which is exciting

- Subjective evaluation is not a result; the results only state findings.

In discussing the limitations of a CLPN, which point is most specific to the method and must be mentioned?

- A. Sample size

- It should be discussed too, but every study has sample size issues; it is not specific to CLPN.

- B. An observed-score CLPN mixes between-person and within-person effects (Correct)

- Correct.

- C. Single items have low reliability

- It should be discussed too, but single-item reliability is common to all item-level networks; the mixing of between- and within-person effects is what is specific to an observed-score CLPN.

- D. Software version

- The software version goes in the methods; it is not a limitation.

When explaining to colleagues without a statistics background, what should you include?

- A. The LASSO formula in detail

- They do not need the formula; they need the finding and its limits.

- B. The finding in everyday language + its limits (not causal, unstable) + a testable suggestion for action (Correct)

- Correct.

- C. All 52 edges

- Information overload; cover only the most important overall pattern.

- D. Just the conclusion

- With only the conclusion, listeners easily take the predictive relationship as causal; the limits must come with it.

A results section says: "The full procedure confirmed the predictive role of Feeling left out → No one understands me." What is wrong?

- A. Nothing

- "Confirmed" goes too far.

- B. A sensitivity analysis only shows that a result does not depend on the estimation method; it cannot "confirm" an edge. Write "both analyses retained this edge" (Correct)

- Correct.

- C. It should say "the full procedure proved causation"

- The full procedure also gives only predictive relationships.

- D. The sentence should be deleted; sensitivity analyses are not reported in the results

- The required sensitivity analysis must be reported in the results.

Which of these numbers can come only from the full procedure, not from the LASSO-only main analysis?

- A. The bootstrap interval of an edge

- Bootstrap intervals come from the main analysis (the bootstrap of Lesson 10.2).

- B. The p-value and standard error of an edge (Correct)

- Correct: LASSO gives no p-values or standard errors.

- C. The CS-coefficient of out-EI

- The CS-coefficient comes from the case-dropping of the main analysis.

- D. The number of nonzero cross-lagged edges

- Each analysis has its own edge count; say which one it comes from.

What does a density of 52/72 ≈ 0.72 suggest?

- A. The network is very sparse

- Quite the opposite: 52 of the 72 possible positions are nonzero.

- B. The network is very dense; lambda.min may have kept some false-positive edges (Correct)

- Correct.

- C. The relationship between loneliness and depression is very strong

- Plausible but wrong: density only counts nonzero edges and says nothing about their strength; many of the edges lambda.min keeps are very weak.

- D. The network was estimated wrongly

- There is no evidence of an error; high density is typical of lambda.min (Lesson 7.2).

## Summary Key Takeaways & Further Reading

- Let the code fill in the numbers (L10-3.R): every number can be found in the output.

- Results: structure → centrality → accuracy and stability → sensitivity; state, do not interpret.

- Full-procedure sensitivity analysis: the methods describe the settings of both analyses and the interpretation rule; the results give it its own paragraph; in the discussion the main findings are only the edges kept by both analyses.

- Limitations: mixing of between-/within-person effects, not causal, measurement and interval, estimation method, sample and attrition.

- Practice wording: finding in everyday language + limits + a testable suggestion for action; in a 10-minute talk, one point per slide.
