Installing R and RStudio and Running Your First Line of Code

① IntuitionWhat Is R, and Why Write Code?

An analysis that "redoes itself"

Xiao Zhou ran the analysis for his graduation thesis by clicking through SPSS menus. A week before his defense, he found that 12 questionnaires had been entered incorrectly, so after fixing them he had to run everything again. He could not remember which menus he had clicked or which boxes he had ticked three months earlier, so he had to work it all out again from scratch and stayed up two nights. Xiao Lin, in the same research group, had written an R script: after correcting the data, she pressed "Run", and a minute later every table and figure was updated. Code is a complete, exact record of an analysis that can be run again.

R (R language) is a free, open-source programming language built for statistical analysis. The tools CLPN needs (glmnet, qgraph, bootnet, and others) are all R add-on packages with no matching menus in SPSS. That is the direct reason this course uses R.

RStudio / Posit (IDE) is the "workbench" for writing R code (an integrated development environment, IDE). RStudio is now developed by Posit (the company renamed itself from RStudio to Posit in 2022); the software is still called RStudio Desktop, and there is a free version. Think of it this way: R is the engine, RStudio is the car's dashboard and steering wheel. You must install R first, or RStudio cannot work.

Installation steps

  1. Install R: go to CRAN (R's official distribution site, https://cran.r-project.org), choose your system (Windows / macOS), download the latest version, and install it with the default options. If the download is slow, pick a mirror near you from the CRAN mirror list (in mainland China, for example, a university mirror such as Tsinghua University's TUNA).
  2. Install RStudio Desktop: go to the Posit website (https://posit.co/download/rstudio-desktop/), download the free version, and install it.
  3. Open RStudio (not R). In the lower-left pane, type 1 + 1 and press Enter. If you see [1] 2, it worked.
The most common installation pitfalls
  • Non-English user names / paths: if your Windows user name contains non-ASCII characters (for example Chinese characters, as in C:\Users\张三), some packages may fail to install. Keep the course folder on a plain-English path (such as D:\clpn-course).
  • Install R before RStudio. If RStudio says it cannot find R, reinstall R and restart the computer.
  • On a Mac, pick the R build that matches your chip (arm64 for Apple Silicon, x86_64 for Intel).

The course scripts were tested on R 4.5 and R 4.6; a newer version is fine.

The four panes of RStudio

  • Script editor (top left): where you write and save code, like a Word document.
  • Console (bottom left): where code actually runs and results appear. > is the prompt, meaning "R is waiting for your input."
  • Environment (top right): lists every object you have created, such as age and scores.
  • Files / Plots / Packages / Help (bottom right): browse files, see the plots you draw, and read help pages.

Console vs. script: scratch paper vs. notebook

Code typed into the console runs when you press Enter, but it is gone once you close RStudio, like working a problem on scratch paper. A script is a .R text file: the code can be saved, edited, commented, rerun, and sent to collaborators, like a notebook that keeps a full record. Rule: apart from quick tries, write all analysis code in a script.

To run code from a script, put the cursor on a line (or select several lines) and press Ctrl + Enter (Mac: Cmd + Enter); the line is sent to the console and run. New script: menu File → New File → R Script (shortcut Ctrl+Shift+N). Save: Ctrl+S. Use only English letters, digits, and underscores in file names, for example week02.R.

Objects and assignment: labeling a box

All data in R live in objects. age <- 21 means "create a box named age and put 21 in it." The arrow <- is called assignment (RStudio shortcut Alt + -). From then on, when you write age, R takes the 21 out of the box.

Analogy: labeled storage boxes

Assignment is like putting something in a storage box and sticking a label on it. age <- 22 replaces the 21 in the box with 22 (the old value is overwritten, and R does not warn you). The Environment pane at the top right is your storage shelf: it lists every box and what is in it.

Naming rules: a name may contain letters, digits, periods, and underscores, and must start with a letter or a period; if it starts with a period, the period cannot be followed directly by a digit (.2x is invalid, because R reads .2 as the number 0.2). No spaces. You cannot use reserved words such as if, TRUE, or NA. Names are case-sensitive (Age and age are two different objects; logical values must be written TRUE/FALSE, and true gives "object not found"). Lowercase letters with underscores are recommended, for example dep_sum_t1. Avoid names that match common functions, such as mean, c, or data.

= also assigns in most cases (age = 21), but the R convention is to assign with <- and keep = for function arguments (as in mean(x, na.rm = TRUE)). == is different: it asks "are these equal?" and returns TRUE or FALSE. x <- 5 means "put 5 into x"; x == 5 means "question: does x equal 5?"

Functions: machines that do things

A function is an "input → processing → output" machine. You write the function name followed by parentheses, with the inputs (arguments) inside. For example, mean(scores) computes a mean, sqrt(16) takes a square root, and round(3.14159, 2) rounds to two decimal places. c() is one of the most used functions: it combines several values into one vector.

Three ways to get help

  1. Help pages: type ?mean in the console and the bottom-right pane opens the manual for mean. Focus on Usage (how to write it), Arguments (what each argument is), and Examples (which you can copy and run). If you don't know the function name, search with ??"standard deviation".
  2. Read the error message: a red Error does not mean "the computer is broken"; it is R telling you what is wrong. When you get an error, first read the whole message and find the function or object name it mentions. Common errors and how to read them are in the R code section.
  3. Ask someone (a classmate, a colleague, or an online forum): give a minimal reproducible example, the shortest code that another person can copy, paste, and see your problem with. "My code doesn't run" is almost impossible to answer; prepare your question with the template below.
Template for asking
  1. What I want to do (the goal).
  2. The code I ran: the few shortest lines that reproduce the problem, including library() calls and the data. Don't write "my data"; make it runnable for others. You can make up a few rows (for example dat <- data.frame(x = c(1, 2, NA))), or use dput(head(d)) to turn the first rows of your own data into code that can be copied.
  3. The complete error message (copy the text; don't send only a screenshot).
  4. What I have already tried.
  5. The output of sessionInfo() (the R and package versions).

Often you find the problem yourself while preparing the minimal example.

Social workers learning to code

You don't need to become a programmer. You need to be able to read, modify, and run analysis scripts that others have written, and to know where to look when something goes wrong. It is a lot like a social worker reading policy documents: you don't have to write laws, but you need to understand the clauses and find the parts that apply.

② Essential MathR as a Calculator

This lesson has almost no new math. You only need the operators R uses:

MathIn RExample → result
\(a+b,\ a-b\)+ -1 + 1 → 2
\(a\times b\)*21 * 365 → 7665
\(a\div b\)/10 / 3 → 3.333333
\(a^b\)^2^10 → 1024
\(\sqrt{a}\)sqrt()sqrt(16) → 4
\(e^{a},\ \ln a\)exp(), log()exp(0.134) → 1.143 (the OR in Lesson 3.4)
\(\bar x=\frac{1}{n}\sum x_i\)mean()mean(c(3, 5, 2, 4)) → 3.5
\(a, b\)
Any numbers, or objects that hold numbers.
\(e\)
The natural constant, about 2.718.
\(\ln\)
Natural logarithm; R's log() is \(\ln\) by default. For base 10, use log10().
\(\bar x\)
The mean (Lesson 1.2).

The order of operations is the same as in math: powers first, then multiplication and division, then addition and subtraction; use parentheses to change the order. The [1] in front of the output is not part of the result. It means "this line starts at element 1," because R treats every result as a vector (Lesson 2.2).

③ R CodeYour First Script

Script for this lesson: R/L2-1.R. Open it in RStudio, put the cursor on each line, and press Ctrl+Enter to run it line by line.

R/L2-1.R (core part)
# This is a comment: R ignores everything after #
1 + 1
age <- 21                    # <- is "assignment": store 21 in an object named age
age * 365                    # Age converted to days (roughly)
scores <- c(3, 5, 2, 4)      # c() combines numbers into a vector
mean(scores)                 # A function: name + parentheses
# ?mean                      # Opens the help page (remove the # in RStudio, then run)
sessionInfo()$R.version$version.string
Output (R/output/L2-1_log.txt)
[1] 2
[1] 7665
[1] 3.5
[1] "R version 4.6.1 (2026-06-24)"

Note: the assignment age <- 21 prints nothing by itself; to see the value, write age on its own line. The last line shows the R version (yours may differ).

Assignment vs. comparison
x <- 5        # Assignment: store 5 in x
x == 5        # Comparison: does x equal 5?
x == 3
my_age <- 21; friend_age <- 23; teacher_age <- 45   # A semicolon puts several statements on one line
my_age + friend_age + teacher_age

[1] TRUE

The most common errors, and how to fix them

When you start with R, most of your time goes into errors. Below are the most common kinds together; each line contains one deliberate mistake. These are the messages as they appear in an English-language R (in R set to another language, such as Chinese, the messages are translated).

Deliberate mistakes (run one line at a time)
Mean(scores)             # Wrong case
mena(scores)             # Misspelled function name
mean(score)              # Misspelled object name (missing s)
"a" + 1                  # Text cannot be added
mean(scores) sd(scores)  # Two commands on one line
mean(scores              # Missing closing parenthesis
Error messages and interpretations (Illustrative output: original error messages with explanation below each →)
Error in Mean(scores) : could not find function "Mean"
  → Could not find function Mean: R is case-sensitive; the function name must be lowercase mean.
Error in mena(scores) : could not find function "mena"
  → Same category of error: misspelled function name; or the function belongs to a package that has not yet been loaded with library() (Lesson 2.4).
Error: object 'score' not found
  → Object score not found: typo, or you forgot to run the line that created it first.
Error in "a" + 1 : non-numeric argument to binary operator
  → Attempted arithmetic on a non-numeric value: check whether your variable was read as character (Lesson 2.2).
Error: unexpected symbol in "mean(scores) sd"
  → R encountered a symbol where it was not expected: missing a newline or semicolon between commands. Full-width or non-ASCII punctuation will also trigger unexpected input.
+
  → The console displays + instead of >: R expects further input to complete the expression (missing parenthesis or quote). Add ) and hit Enter, or press Esc to cancel.

The usual fix for "object not found" is to go back, run the line that creates the object, and then rerun the code that failed:

Fixing "object not found"
scores <- c(3, 5, 2, 4)  # First run the line that creates it (mind the spelling: Scores and scores are two names)
mean(scores)
Reading an error in three steps
  1. Look at the last line of the error and find the key phrase: could not find function, object ... not found, unexpected, …
  2. Find the object or function it names, go back to the line that failed, and check spelling, case, whether parentheses and quotes come in pairs, and whether you have run the code that creates the object.
  3. If it is still unclear, paste the original (English) error message into a search engine; almost every beginner's error has been asked about before. If your R shows messages in another language, Sys.setenv(LANGUAGE = "en") switches them to English, which makes them easier to search. If you still can't solve it, ask someone using the template above.
Common mistakes
  • Typing with a Chinese (or other full-width) input method switched on. Full-width commas "，", parentheses "（）", and curly quotes "“”" all cause unexpected input. Switch your keyboard to English when writing code, and type other languages only inside quotes.
  • Saving files on the desktop or in the Downloads folder. Once paths get messy, read.csv() cannot find the file. Use this course's folder structure from day one (Lesson 2.4 covers RStudio projects).

④ Concept CheckQuick Quiz

What is the difference between a script and the console? Why write code in a script?

  • The console keeps only a scattered History, not an ordered, commented analysis file you can rerun directly.
  • Correct.
  • The speed is the same: code in a script is also sent to the console to run.
The script is the complete record of your analysis; if the data change, you just run it again.

What is the difference between x <- 5 and x == 5?

  • Correct.
  • == does not change x; it only returns TRUE or FALSE. Assignment uses <- (or =).
  • It is the other way round: <- is the assignment arrow, == is comparison.
= can assign; == compares.

Running Mean(c(1, 2, 3)) gives could not find function "Mean". What is the most likely cause?

  • mean() comes with R and needs no installation; the problem is the capital M in Mean.
  • Correct.
  • That would give object ... not found; here R says it cannot find a function.
Another common cause is that the function comes from a package you forgot to load with library().

When you get an error, what should you do first?

  • Read the error yourself first; even when you ask for help, copy the error text rather than sending only a screenshot.
  • Switching the language only makes searching easier; what the error says does not change. The first step is still to understand it.
  • Correct.
If you can't understand it, search the English text, and as a last step ask someone, bringing a minimal reproducible example.

What does R return for 2^3 + 4 / 2?

Powers first, then division, then addition.
2^3 = 8, 4/2 = 2, 8 + 2 = 10.

Which object name is valid and recommended?

  • A name cannot start with a digit.
  • A name cannot contain a space.
  • Correct: lowercase with underscores, clear and readable.
  • Valid but not recommended: easy to confuse with the mean() function.
Start with a letter, no spaces, mind the case; lowercase with underscores is recommended.

Exercise 2.1-B: Reading a help page

Run ?round. (1) What are the two arguments of round()? (2) What are round(2.5) and round(3.5)? Find the reason on the help page.

Reference answer

(1) x (the number to round) and digits (how many decimal places to keep, default 0). (2) round(2.5) returns 2 and round(3.5) returns 4. The help page explains that R follows the IEC 60559 standard: a number exactly halfway goes to the nearest even number ("round half to even"), which is not the "round half up" rule taught in school.

Exercise 2.1-C: Write a minimal reproducible example

Suppose you run mean(c(1, 2, NA)), get NA, and don't know why. Use the template above to write a request for help (to a classmate, or for a forum).

Sample message

"Hi, I want to compute the mean of a sleep-duration column, but the result is NA. Minimal example: x <- c(1, 2, NA); mean(x) prints [1] NA, with no error. I looked at ?mean and saw an na.rm argument, but I'm not sure whether I should use it. R version 4.6.1." (Answer: mean(x, na.rm = TRUE) returns 1.5; the next lesson covers this.)

  • R is the language (the engine), RStudio is the workbench; analysis code goes in a script, and Ctrl+Enter runs it.
  • <- assigns, == compares; object names are case-sensitive; a function is a name + parentheses.
  • With an error: read it first, then search, then ask with a minimal reproducible example. Next lesson: 2.2 R Basic Syntax: Vectors, Data Types, and Functions.
