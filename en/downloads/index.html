Course Package (Zip)

clpn-course-en.zip

The whole English course in one zip file. Extracting it gives you the folder clpn-course-en/:

  • Offline website: index.html, the Study Guide, all lessons, and all study materials. Double-click index.html to open it in your browser; no internet connection needed;
  • Data: data/ (simulated data, data dictionary, simulate_data.R, the coefficients used to generate the data; plus a real public dataset, coaches_mhc_raw.csv, CC0, for the Lesson 7.6 exercise);
  • R scripts: R/ (the script for each lesson, _setup.R, run_all.R to run everything, the R Code User Guide), R/solutions/ (exercise solutions), R/output/ (reference results);
  • README.md (folder guide; read this first), clpn-course.Rproj (double-click to open in RStudio), LICENSE (course content CC BY 4.0, code MIT), THIRD_PARTY_NOTICES.md.

After extracting, open index.html in your browser to study, and double-click clpn-course.Rproj to run R. Step-by-step instructions are under "How to Use" below.

Datasets

Simulated panel data with no real personal information. true_B_within.csv and true_B_population.csv are the coefficients behind the simulation (the within-person truth and the population target), not estimates from your sample. A standard CLPN targets the second one (population OLS, which includes trait confounding); the two are not the same matrix. You can also open the files one by one:

  • Data Dictionary
  • clpn_sim_wide.csv
  • clpn_sim_wide.sav (SPSS)
  • simulate_data.R

A real public dataset is also included for the measurement invariance exercise in Lesson 7.6: coaches_mhc_raw.csv (the 14-item Mental Health Continuum Short Form, MHC-SF, from 422 Swiss sports coaches over 3 waves; Ackeret et al., 2023, doi.org/10.5061/dryad.8931zcrws, CC0 1.0). The file is included as published (semicolon-delimited). Read the notes in the Data Dictionary before you use it: its subscale columns do not match its item columns, and the descriptions of the wave interval contradict each other.

A second real panel is included for the ELSOC case (case page): elsoc_phq8_wide.csv (three waves of the PHQ-8 plus sex and age from the original 2016–2018 sample of the Chilean Longitudinal Social Survey; COES 2022, doi.org/10.7910/DVN/LQMURF, CC0 1.0). This preprocessed subset is written by R/data_elsoc.R from the original file, which is also included (data/elsoc/ELSOC_Wide_2016_2021_v1.00_R.RData); the analysis script is R/case_elsoc.R. The citation format is in the last section of the Data Dictionary.

How to Use

1. Download and Extract

Get clpn-course-en.zip from the Download page and extract it (Windows: right-click → "Extract All…"; Mac: double-click). You get a folder clpn-course-en/ with everything you need to study and run R:

clpn-course-en/
├── index.html             ← Offline course website: double-click to open in a browser, no internet needed
├── README.md              ← Folder guide (read this first)
├── START_HERE.html        ← Study guide
├── lessons/, materials/   ← Lesson pages and study materials
├── clpn-course.Rproj      ← Double-click to open the course project in RStudio
├── LICENSE, THIRD_PARTY_NOTICES.md
├── data/                  ← Simulated data, data dictionary, simulate_data.R, true_B_*.csv; real data coaches_mhc_raw.csv for the Lesson 7.6 exercise
└── R/
    ├── README.md / .html  ← R code user guide
    ├── _setup.R, run_all.R
    ├── L0-2.R, L1-1.R … L10-3.R, L2-6_report.Rmd, assess_answers.R
    ├── data_elsoc.R, case_elsoc.R   ← Real-data case (preprocessing, CLPN)
    ├── solutions/         ← Exercise solutions
    └── output/            ← Reference results (the figures and logs shown on the site); running the scripts overwrites them with your results

Extract the archive first; do not open files from inside the zip preview window. Keep spaces and non-ASCII characters out of the path (for example, put the folder at D:\clpn-course-en). If you clone the repository from GitHub, the en/ folder has the same layout.

2. Open the Project

  1. Follow the R Code User Guide to install R and RStudio (install R first, then RStudio).
  2. Double-click clpn-course-en/clpn-course.Rproj. RStudio opens it as a project, and the working directory is the clpn-course-en folder. The first line of every script, source("R/_setup.R"), depends on this, so do not open .R files by double-clicking them.
  3. Open R/L2-4.R and click Source to install the packages the course needs (only once).
  4. Open R/L1-1.R and run it line by line (Ctrl/Cmd + Enter) to check that you see output. After that, open the matching R/Lx-y.R for each lesson (Lessons 0.1 and 9.1 have no script).

3. Run Order and Dependencies

Run the scripts in lesson order. The scripts below read files that earlier scripts write to R/output/. The bundled R/output/ already holds reference results, so these scripts also run on their own. If you change and rerun an earlier script, the later scripts use your new results. If a file they need is missing (for example, because you deleted R/output/), the script stops at the start and tells you which script to run first.

ScriptRun first
L6-5.R, solutions/L6-4_solution.R, solutions/L6-5_solution.RL6-4.R
L10-1.R → L10-2.R → L10-3.RIn order: L4-3.R → L10-1.R → L10-2.R → L10-3.R (each step needs the results of the one before)
solutions/L8-3_solution.RL8-2.R (reads L8-2_boot.rds) and L8-3.R
case_elsoc.RThe bundled data/elsoc_phq8_wide.csv (written by data_elsoc.R from the bundled original file)
All other scriptsNone

Run everything at once: source("R/run_all.R"). It runs all lesson scripts and the final-exam answer script in lesson order, then all solution scripts (R/solutions/). This takes about 40–95 minutes, depending on your computer; most of the time goes to the bootstraps in L8-2, L8-3, and L10-2. A summary is written to R/output/run_all_status.csv. It also runs data_elsoc.R and case_elsoc.R for the real-data case.

The bootstrap runs on a single core by default (nCores = 1) with a fixed seed. With the same R and package versions, the results are bitwise reproducible and match the numbers on the site. Running in parallel is several times faster, but the results are no longer reproducible: interval endpoints usually change only in the second or third decimal place, but a CS-coefficient can jump a whole grid step (in the course data, in-EI moves between 0.44 and 0.52, right across the 0.5 reference line).

The script link in each lesson opens the .R file itself, so you can read it in your browser. To run it, open the project in RStudio through clpn-course.Rproj.
