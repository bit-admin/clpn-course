M2 module quiz

Take this after Lessons 2.1–2.6 (Week 5 of the standard pace, together with the M1 module quiz). 8 auto-graded questions + 1 short-answer question, about 15 minutes. You only need to read the code, not run R; afterwards you can check your answers in RStudio.

Auto-graded questions

In R you run x <- 5 and then x <- x * 2 + 1. What is the value of x now?

<- stores the result computed on the right under the name on the left. The second line uses the old value of x, 5.
5 × 2 + 1 = 11, and the result is stored back in x. For assignment and objects, see 2.1.

If scores <- c(3, 8, 5, 10), what is scores[3]?

R counts positions from 1.
The 3rd element is 5. R counts from 1 (some languages count from 0); see 2.2.

dep <- c(2, NA, 4). What does mean(dep) return?

  • By default, R does not skip missing values.
  • Correct. If even one value is NA, the default mean is NA; you need mean(dep, na.rm = TRUE) to get 3.
  • No.
  • There is no error; it just returns NA.
NA means missing; na.rm = TRUE tells the function to drop missing values before calculating; see 2.2.

In a dataset, gender is stored as the text values "Male" and "Female". Which R data type is best for a categorical variable like this?

  • Text is not a number.
  • A logical value is only TRUE or FALSE.
  • Correct. Factors are made for variables with a fixed set of categories.
  • A function is not a choice of data type.
For numeric, character, logical, factor and other types, see 2.2.

After you read the course data clpn_sim_wide.csv into R, dim(dat) shows 800 34. What do the two numbers mean?

  • Correct. In a data frame, rows are cases and columns are variables.
  • The other way round.
  • No.
  • dim() gives dimensions, not statistics.
For the structure of data frames, see 2.3.

You want to keep only the women (gender == 1) in the data frame dat. Which dplyr code should you write?

  • select() chooses columns, not rows.
  • Correct. filter() chooses rows by a condition.
  • This would set everyone's gender to 1.
  • summarise() computes summary statistics.
select chooses columns, filter chooses rows, mutate creates or changes columns, and summarise summarizes; see 2.3. Note that testing "equals" takes two equals signs, ==.

You ran install.packages("glmnet") yesterday. Today you open RStudio again. Which line should you run to use glmnet?

  • You only need to install once; installing again wastes time.
  • Correct. You load the package once in every new R session.
  • When you close R, loaded packages are gone.
  • source() runs a script file.
install.packages() installs once; library() loads every session; see 2.4.

A classmate copies your course folder to their own computer, and the line read.csv("C:/Users/XiaoZhang/Desktop/data/clpn_sim_wide.csv") in the script now fails. What is the best fix?

  • Not realistic.
  • Correct. The project sets the working directory to the course folder, so a relative path works on any computer.
  • It will break again on the next computer.
  • That won't work.
An RStudio Project and relative paths are what let someone else run your code; see 2.4.

Short-answer questions

Short answer 1

You run read.csv("data/my_survey.csv") and get the error cannot open file 'data/my_survey.csv': No such file or directory. Write a request for help to post on an R forum or in a study group (4–6 sentences). Someone who has never seen your computer should be able to find the problem without having to ask you follow-up questions.

Reference answer & rubric

Example: "Hi, when I run line 12 of R/L2-4.R, read.csv("data/my_survey.csv"), I get the error: cannot open file 'data/my_survey.csv': No such file or directory. I opened the project by double-clicking clpn-course.Rproj, and getwd() shows .../clpn-course-en. The data folder contains clpn_sim_wide.csv, but I just noticed that my_survey.csv is in my Downloads folder. I have already tried retyping the file name. Where should I put the file? My R version is 4.5.0 (the text output of sessionInfo() is pasted below)."

Key points: say exactly which line of code you ran, give the full error message word for word, say what you have already checked (working directory, whether the file is in that location), and give your software version.

LevelCriteria
3Includes the code that was run, the full error message, the checks already made (e.g. getwd(), file location) and the software version, so a reader can find the problem directly
2Has the code and the error, but not the checks already made or the environment details
1Only says "reading the data gives an error, what do I do?" with no code or error text
0No answer
