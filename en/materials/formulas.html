Formula Reference

All formulas used across the course compiled on a single page. Each formula notes the lesson where it is introduced; click to return to the lesson. Notation: n / N = sample size, p = number of nodes, λ = penalty parameter, B = CLPN coefficient matrix.

Descriptive Statistics & Inference

NameFormulaNotesLesson
Mean\(\displaystyle \bar x=\frac{1}{n}\sum_{i=1}^{n}x_i\)1.2
Sample Variance / SD\(\displaystyle s^2=\frac{1}{n-1}\sum_{i}(x_i-\bar x)^2,\quad s=\sqrt{s^2}\)var(), sd() in R1.2
z-Score\(\displaystyle z_i=\frac{x_i-\bar x}{s}\)Mean 0, SD 11.3
Covariance\(\displaystyle \operatorname{cov}(x,y)=\frac{1}{n-1}\sum_i(x_i-\bar x)(y_i-\bar y)\)1.4
Pearson Correlation\(\displaystyle r=\frac{\operatorname{cov}(x,y)}{s_x s_y}\)−1 ≤ r ≤ 11.4
Standard Error of the Mean\(\displaystyle SE_{\bar x}=\frac{s}{\sqrt n}\)Quadrupling n halves SE1.5
95% Confidence Interval\(\displaystyle \bar x\pm1.96\times SE\)Large-sample normal approximation1.5
Independent Samples t\(\displaystyle t=\frac{\bar x_1-\bar x_2}{s_p\sqrt{1/n_1+1/n_2}}\)1.6
Cohen's d\(\displaystyle d=\frac{\bar x_1-\bar x_2}{s_p}\)0.2 / 0.5 / 0.8 benchmarks1.6
Expected False Positives in Multiple Testing\(\displaystyle E[\text{False Positives}]=m\times\alpha\)190 × 0.05 = 9.51.6

Regression & Regularization

NameFormulaNotesLesson
Simple Linear Regression\(\displaystyle \hat y=b_0+b_1x,\quad b_1=\frac{\operatorname{cov}(x,y)}{s_x^2},\quad b_0=\bar y-b_1\bar x\)Ordinary least squares (OLS)3.1
Coefficient of Determination\(\displaystyle R^2=1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}\)In simple regression, R² = r²3.1
Multiple Regression\(\displaystyle y=b_0+b_1x_1+\dots+b_kx_k+e\)3.2
VIF\(\displaystyle \mathrm{VIF}_j=\frac{1}{1-R_j^2}\)> 5–10 indicates collinearity3.2
Standardized Coefficient\(\displaystyle \beta=b\,\frac{s_x}{s_y}\)3.3
Logistic Regression\(\displaystyle \operatorname{logit}(p)=\ln\frac{p}{1-p}=b_0+b_1x\)\(p=1/(1+e^{-\text{logit}})\)3.4
Odds Ratio\(\displaystyle \mathrm{OR}=e^{b_1}\)3.4
Ridge Regression\(\displaystyle \min_b\ \frac{1}{2n}\sum_i(y_i-x_i^\top b)^2+\lambda\cdot\frac{1}{2}\sum_j b_j^2\)α = 0 in glmnet; ridge penalty includes 1/2 factor by glmnet convention3.5
LASSO\(\displaystyle \min_b\ \frac{1}{2n}\sum_i(y_i-x_i^\top b)^2+\lambda\sum_j|b_j|\)α = 1 in glmnet3.5, 7.2
Soft Thresholding (Orthogonal Case)\(\displaystyle \hat\beta_j=\operatorname{sign}(\hat\beta_j^{OLS})\max(|\hat\beta_j^{OLS}|-\lambda,0)\)6.3
