One-Sentence Template

"After controlling for covariates, predictor positively/negatively predicted outcome (b = __, 95% CI [__, __], p = __); the model explained __% of the variance in outcome."

Five Pitfalls to Avoid
  • Describing b in causal terms ("leads to", "drives", "causes").
  • Writing p > .05 as "there is no relationship".
  • Comparing β across different samples.
  • Treating significant correlation but non-significant regression as contradictory—it is the expected result of "controlling" (Lesson 2.5).
  • Confusing odds ratios with risk ratios.

Three Bottom Lines
  • CLPN edges represent temporal prediction, not causality.
  • Standard CLPN conflates between-person and within-person effects (5.3, 7.5).
  • Centrality rankings without stability evaluation must not be interpreted.

Cheat Sheet 4 · Reporting Checklist

Based on Lesson 9.3 (adapted from Burger et al., 2023 reporting standards for network analysis). Check item by item:

  • [ ] Sample: N, recruitment strategy, sample size and attrition rate across waves, attrition analysis results
  • [ ] Design: Number of waves, measurement lag interval, and rationale for choosing this interval
  • [ ] Nodes: Full item wording or abbreviations, source scales, rationale for node selection; redundancy check (goldbricker)
  • [ ] Missing Data: Handling method (listwise deletion / imputation / FIML) and justification
  • [ ] Preprocessing: Whether items were standardized; handling of ordinal response categories
  • [ ] Estimation: Software and versions (R, glmnet, bootnet); nodewise LASSO; λ rule (lambda.min / 1se); number of CV folds; random seed
  • [ ] Covariates: Which covariates were included and whether they were penalized (penalty.factor = 0)
  • [ ] Centrality: Metric names; whether autoregressions were excluded; community definitions for bridge centrality
  • [ ] Accuracy: Bootstrap type and number of resamples (B); edge weight CI plot
  • [ ] Stability: Case-dropping bootstrap resamples; CS-coefficient and evaluation criteria (0.7 / 95% / 0.25)
  • [ ] Sensitivity Analyses: Which analyses were performed; whether primary conclusions held
  • [ ] Network Plots: Figure caption detailing edge colors, thickness scaling (maximum), threshold, layout; how autoregressions are represented
  • [ ] Tables: Full B matrix (can be placed in supplementary materials); table of non-zero cross-lagged edges
  • [ ] Language & Framing: Use 'predicted' rather than 'caused' or 'drove'; avoid equating single items directly with broad constructs
  • [ ] Limitations: Conflation of between- and within-person effects, unmeasured confounding, time lag dependence, sample representativeness
  • [ ] Open Science: Code and (simulated or shareable) data availability; preregistration details (if applicable)
