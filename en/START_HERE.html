Study Guide: How to Use This Course

This page explains how to study with this website: what is on it, what order to follow, how to work through each lesson, and how to plan your 16 weeks. Markdown version: START_HERE.md (identical content).

1. What Is on This Website

You study this course in your browser. The table below lists the pages on this site. You can download the whole site, with the data, R scripts, and exercise solutions, as one package: get clpn-course-en.zip from the Download page, extract it to the clpn-course-en/ folder, and double-click index.html to study offline. For running R, see Section 5.

2. What Order to Follow

The module numbers follow the logical order of the material: M0 Overview → M1 Statistics Foundations → M2 R Programming → M3 Regression & Regularization → M4 Longitudinal Data → M5 CLPM → M6 Network Psychometrics → M7 CLPN → M8 Stability → M9 Critical Reading & Reporting → M10 Capstone Mini-Project. In practice, study M1 (statistics) and M2 (R) side by side, alternating in Weeks 2–5, and take M3 (regression) after both: as soon as you learn a statistical idea, try it in R. 3. How to Study Each Lesson (~2–3 Hours)

  1. Read the objectives (2 min): Read "Learning Objectives" and "Core Concepts". Look up unfamiliar terms in the Glossary first.
  2. ① Intuition (20–30 min): Do not skip it. Form a picture in your head before you look at equations, and drag the interactive widgets yourself.
  3. ② Essential Math (15–30 min): Work through the worked example with pen and paper. All formulas are collected in the Formula Reference.
  4. ③ R Code (30–60 min): Double-click clpn-course.Rproj to open the RStudio project, open the matching R/Lx-y.R, and run it line by line (Ctrl/Cmd + Enter). Compare your output with the output on the page. You can expand the full script at the bottom of the page.
  5. ④ Concept Check (10 min): A wrong answer first gets a hint; the answer appears only after two wrong tries.
  6. ⑤ Exercises (1–2 hours): Do them yourself before you look at the solutions. Solutions to coding exercises are in R/solutions/. For writing exercises, check your draft point by point against the rubric in the lesson and revise it once before you save it. Keep each lesson's exercise scripts and output in one folder; you will use them again in the capstone project.
  7. Summary and log (10 min): Click "Mark lesson complete" and write three sentences in your Study Log: what you learned, what is still unclear, and what you want to work out next.
Stuck?

① Read "Common mistakes" and "Common questions and pitfalls" in the lesson. ② Check the FAQ. ③ For an R error, paste the last line of the error message into a search engine. ④ If that does not help, write a minimal reproducible example as shown in Lesson 2.1 and ask classmates, colleagues, or an R forum (such as Posit Community or Stack Overflow). If you have been stuck for more than 30 minutes, try a different approach instead of grinding on. Writing the minimal example often shows you the cause.

4. 16-Week Study Plan

Standard pace: 16 weeks, 3 sessions a week (4 in Weeks 14 and 15), 60–150 minutes per session, plus 2–3 hours of exercises a week: about 5–7 hours a week in total. Reading the core lessons takes about 85 hours (not counting optional lessons and exercises). If you study full-time during a break, you can compress this to about 12 weeks (4 sessions a week). If you study alongside other courses, you can stretch it to about 19 weeks (one buffer week after Weeks 5, 8, and 13). The optional advanced lessons 7.6, 7.7 are not part of the standard pace: if you have time, study them on your own after Week 13. The relaxed pace puts them in the buffer week after Week 13; the compressed pace leaves them out.

5. Running R on Your Computer

1. Download and Extract

Get clpn-course-en.zip from the Download page and extract it (Windows: right-click → "Extract All…"; Mac: double-click). You get a folder clpn-course-en/ with everything you need to study and run R:

├── README.md              ← Folder guide (read this first)
├── START_HERE.html        ← Study guide
├── lessons/, materials/   ← Lesson pages and study materials
├── clpn-course.Rproj      ← Double-click to open the course project in RStudio
├── LICENSE, THIRD_PARTY_NOTICES.md

    ├── solutions/         ← Exercise solutions

Extract the archive first; do not open files from inside the zip preview window. Keep spaces and non-ASCII characters out of the path (for example, put the folder at D:\clpn-course-en). If you clone the repository from GitHub, the en/ folder has the same layout.

2. Open the Project

  1. Follow the R Code User Guide to install R and RStudio (install R first, then RStudio).
  2. Double-click clpn-course-en/clpn-course.Rproj. RStudio opens it as a project, and the working directory is the clpn-course-en folder. The first line of every script, source("R/_setup.R"), depends on this, so do not open .R files by double-clicking them.
  3. Open R/L2-4.R and click Source to install the packages the course needs (only once).
  4. Open R/L1-1.R and run it line by line (Ctrl/Cmd + Enter) to check that you see output. After that, open the matching R/Lx-y.R for each lesson (Lessons 0.1 and 9.1 have no script).

3. Run Order and Dependencies

Run the scripts in lesson order. The scripts below read files that earlier scripts write to R/output/. The bundled R/output/ already holds reference results, so these scripts also run on their own. If you change and rerun an earlier script, the later scripts use your new results. If a file they need is missing (for example, because you deleted R/output/), the script stops at the start and tells you which script to run first.

ScriptRun first
L6-5.R, solutions/L6-4_solution.R, solutions/L6-5_solution.RL6-4.R
L10-1.R → L10-2.R → L10-3.RIn order: L4-3.R → L10-1.R → L10-2.R → L10-3.R (each step needs the results of the one before)

All other scriptsNone

Run everything at once: source("R/run_all.R"). It runs all lesson scripts and the final-exam answer script in lesson order, then all solution scripts (R/solutions/). This takes about 40–95 minutes, depending on your computer; most of the time goes to the bootstraps in L8-2, L8-3, and L10-2. A summary is written to R/output/run_all_status.csv. It also runs data_elsoc.R and case_elsoc.R for the real-data case.

The bootstrap runs on a single core by default (nCores = 1) with a fixed seed. With the same R and package versions, the results are bitwise reproducible and match the numbers on the site. Running in parallel is several times faster, but the results are no longer reproducible: interval endpoints usually change only in the second or third decimal place, but a CS-coefficient can jump a whole grid step (in the course data, in-EI moves between 0.44 and 0.52, right across the 0.5 reference line).

6. Progress & Self-Assessment

  • Set aside 30 minutes each week for review. Reread the "What still feels unclear" column in your Study Log, cross off what you can now resolve yourself, and for anything left, write down exactly which step you are stuck on and carry it into the next week.
  • Save exercise results as scripts plus output (or a Quarto report), not just screenshots. You will need them to check your work weeks later or to reuse code in the capstone project.
  • For writing exercises (interpretation paragraphs, peer reviews, methods and results), write a draft first, then score it point by point against the rubric in the lesson and in the Writing Workshop, and revise it once. If you can, swap drafts with a classmate or colleague and ask them to mark any sentence that reads like a causal conclusion.
  • Take the module quizzes in Weeks 5 and 8 (M1 + M2, M3 + M4). Weeks 15–16 are for the capstone project (10.1, 10.2, 10.3). Before the project starts, write a one-page analysis plan and save it with a date. If you change anything once the analysis is under way, list each change and the reason for it in the report.

7. Assessments: Pre-Test, Module Quizzes & Final Exam

  • Before you start: Take the pre-test (about 20 min, not scored). It suggests whether to follow the 16-week standard pace or the 19-week pace with a buffer week after Weeks 5, 8, and 13.
  • After each module: Take that module's quiz (15–25 min). If you get 70% or more right on the first try, move on; if not, use the links in the explanations of the questions you missed to review.
  • After Lesson 10.3: Take the final exam (about 90 min) and compare it with your pre-test to see how far you have come.
  • Record the number you got right on the first try in your Study Log. The scoring rubrics are on the Assessments page.
