### 核心概念

- **lavaan** latent variable analysis (R package)

- **模型拟合** model fit

- **CFI / TLI** comparative / Tucker–Lewis fit index

- **RMSEA** root mean square error of approximation

- **SRMR** standardized root mean square residual

- **等值约束** equality constraint

上一课用两条 `lm()` 拆解了一个时间段的 CLPM；本课用结构方程模型（SEM）软件 lavaan 一次性拟合整个三波模型，学会读懂模型拟合指标，并理解为什么许多 CLPN 论文不报告这类指标。

## ① 直觉 先建立画面

### 为什么不一直用 lm()？

用 4 个 `lm()` 也能得到三波 CLPM 的 8 条路径，但有三个不便：（1）它不能同时估计残差相关；（2）不能检验“整个模型是否与数据相符”；（3）不能方便地加约束（例如“两个时间段的路径相等”）或处理缺失数据。SEM 把所有方程放在一起估计，用一套“模型隐含的协方差矩阵”去拟合“样本协方差矩阵”。

### “模型拟合”是什么意思？

想象你只给了模型有限的路径（例如：不允许 T1 孤独直接预测 T3 抑郁）。根据这些路径，模型会“推算”出所有变量之间应该有的协方差；把推算值和实际样本协方差相比，差得越少，模型拟合 （model fit） 越好。拟合差说明你的模型漏掉了数据中的重要结构。

**类比：**

模型像一张“简化地图”，拟合指标告诉你“地图和实际地形差多少”。一张完全不简化的地图（饱和模型）永远完美拟合，但也没有任何信息量。

### 四个常见拟合指标

| 指标 | 英文 | 直觉 | 常用参考 |
| --- | --- | --- | --- |
| χ² 检验 | chi-square test | “模型完美吻合”的显著性检验；样本大时几乎总是显著 | p > .05 表示没有显著不吻合（N 大时参考价值有限） |
| CFI / TLI | comparative / Tucker–Lewis fit index | 与“所有变量都不相关”的基线模型相比，进步了多少 | ≥ .95 较好，≥ .90 可接受 |
| RMSEA | root mean square error of approximation | 每个自由度平均的“不吻合程度”，考虑了模型简约性 | ≤ .06 较好，> .10 较差 |
| SRMR | standardized root mean square residual | 观测相关与模型隐含相关之差的平均大小 | ≤ .08 较好 |

**注意：**

这些参考值（常称“Hu & Bentler 标准”）只是经验规则，不是法律。不同指标可能互相矛盾，而且好的拟合不代表模型“正确”，只代表“没被数据明显否定”。

### 在课程数据上的实际结果

配套脚本 `R/L5-2.R` 在 N = 800 的模拟数据上得到：χ²(4) = 67.99，p < .001；CFI = .962；TLI = .856；RMSEA = .141；SRMR = .031。指标互相矛盾：CFI、SRMR 看起来尚可，但 TLI 和 RMSEA 很差。为什么？一个重要原因是：模拟数据中存在很强的稳定个人特质，标准 CLPM 没法表达“T1 的孤独与 T3 的孤独之间，除了经过 T2 以外的直接相似性”。5.3 课的 RI-CLPM 就是为此设计的，它的拟合显著更好。

### 等值约束：两个时间段的路径一样吗？

如果 T1→T2 与 T2→T3 的间隔相同、所处人生阶段相近，我们可能假设两段的自回归和交叉滞后相等，这叫 等值约束 （equality constraint）。好处：参数更少、估计更稳定、解释更简单（“每半年……”）。代价：如果两段确实不同，约束会让拟合变差。我们可以比较“有约束”与“无约束”两个模型（嵌套模型 χ² 差异检验），让数据告诉我们约束是否合理。

lavaan 中给两条路径起同一个“标签”即可约束相等，例如 `dep2 ~ d*lone1` 和 `dep3 ~ d*lone2` 都用了标签 `d`。

**与 CLPN 的联系：**

本课程主线教的“仅 LASSO”简化版 CLPN 不是 SEM，而是一组独立的 LASSO 回归，所以它**没有** CFI、RMSEA 这类整体拟合指标；它也不会默认把 T1→T2 与 T2→T3 约束相等，而是分别估计后比较“复现性”（7.5 课）。Wysocki 等人（2025）推荐的完整流程则不同：它把 LASSO 选出的模型放进 lavaan 做无惩罚重估，因此**有** χ²、CFI、TLI、RMSEA，还能用嵌套 χ² 检验跨时间等值。7.5 课的 `R/L7-5b.R` 在课程数据上演示了这一做法，结果为 χ²(91) = 164.70，CFI = .988，RMSEA = .032。读 CLPN 论文时，先看作者用的是哪一种。

### 常见问题与误区

被试间和被试内的区别，用一句话怎么说？

被试间问的是“**比别人**更孤独的人，是否也比别人更抑郁”；被试内问的是“**比自己平时**更孤独的时候，之后是否更抑郁”。前者比较不同的人，后者比较同一个人在不同时间的状态。社工干预针对的是个体的变化，所以通常更关心被试内问题。

被试间相关为正，被试内相关就一定为正吗？

不一定。4.1 课和 5.3 课的交互图中，你可以把两者设为方向相反。经典例子：经常运动的人静息心率整体更低（被试间：运动多 ↔ 心率低），但同一个人正在运动的时候，心率比他平时更高（被试内：运动多 ↔ 心率高）。从群体层面推到个体层面要非常小心，否则会犯“生态谬误”。

社工连接

机构评估报告常说“孤独得分高的老人抑郁也高，所以要减少孤独”。这句话混合了两个层面。更准确的说法是：“在人群层面二者相关；至于减少某位老人的孤独是否会降低他之后的抑郁，需要被试内层面的证据或干预研究。”

## ② 最少数学 把直觉写成式子

SEM 的核心思想用一句数学话说：找参数 \(\theta\)，让模型隐含协方差矩阵 \(\Sigma(\theta)\) 尽量接近样本协方差矩阵 \(S\)。

\[\hat\theta = \arg\min_{\theta}\ F\big(S,\ \Sigma(\theta)\big)\]

| 符号 | 读法 / 含义 |
| --- | --- |
| \(\theta\) | 希腊字母 theta，所有待估参数（路径系数、方差、协方差）的集合 |
| \(S\) | 样本协方差矩阵：直接由数据算出 |
| \(\Sigma(\theta)\) | 大写 sigma：给定参数后模型“推算”出的协方差矩阵 |
| \(F(\cdot)\) | 差异函数（discrepancy function）。最大似然（ML）估计下它衡量 S 与 Σ(θ) 的差距 |
| \(\arg\min\) | “使……最小的那个参数值” |

#### 自由度（df）怎么来？

6 个观测变量有 \(6\times7/2 = 21\) 个方差和协方差（再加 6 个均值 = 27 个“已知信息”）。模型估计了 23 个参数（lavaan 输出 “Number of model parameters 23”，包括均值/截距），所以 \(df = 27 - 23 = 4\)。df 越多，模型越“简约”，被数据否定的机会也越多。

#### RMSEA 的公式（了解即可）

\[\mathrm{RMSEA}=\sqrt{\max\!\left(\frac{\chi^2-df}{df\,(N-1)},\,0\right)}\]

代入 χ² = 67.99、df = 4、N = 800：\(\sqrt{(67.99-4)/(4\times799)} = \sqrt{0.0200}\approx 0.141\)，与输出一致。可以看到：χ² 远大于 df 时 RMSEA 就大；N 越大，同样的 χ² 对应的 RMSEA 越小。

## ③ R 代码 在 R 中实现

R/L5-2.R 的核心部分

```r
source("R/_setup.R")
library(lavaan)
dat  <- read_course_data()
wide <- data.frame(id = dat$id)
for (t in 1:3) {                                   # 构念总分（原始分，未标准化）
  wide[[paste0("lone", t)]] <- rowSums(dat[, paste0(lone_items, "_t", t)])
  wide[[paste0("dep", t)]]  <- rowSums(dat[, paste0(dep_items, "_t", t)])
}
clpm <- '
  lone2 ~ lone1 + dep1      # ~  读作“被……预测”（回归）
  dep2  ~ dep1  + lone1
  lone3 ~ lone2 + dep2
  dep3  ~ dep2  + lone2
  lone1 ~~ dep1             # ~~ 读作“与……相关”（协方差）
  lone2 ~~ dep2             # T2、T3 是残差协方差
  lone3 ~~ dep3
'
fit <- sem(clpm, data = wide, missing = "fiml")   # FIML：全信息最大似然，处理缺失
summary(fit, standardized = TRUE, fit.measures = TRUE)
fitMeasures(fit, c("chisq", "df", "pvalue", "cfi", "tli", "rmsea", "srmr"))
ssol <- standardizedSolution(fit)                 # 标准化估计 + 标准化估计自己的 SE 与 95% CI
ssol[ssol$op == "~", c("lhs", "op", "rhs", "est.std", "se", "ci.lower", "ci.upper", "pvalue")]
```

**读输出：**`summary(..., standardized = TRUE)` 的 `Regressions:` 部分有 `Std.all` 列（完全标准化系数），但同一行的 `Std.Err`、`P(>|z|)` 以及 `parameterEstimates()` 给出的 `ci.lower` / `ci.upper` 都属于**未标准化**估计（原始分单位）。把未标准化区间和标准化系数放在同一行，读者会误以为“0.607 的区间是 [0.524, 0.634]”，而两者根本不在同一个尺度上。所以报告 β 时，用 `standardizedSolution()`：它对标准化估计 `est.std` 用 delta 法重新计算标准误、z 检验和 95% CI，数字与 β 在同一尺度上。课程数据结果摘录：

### 完整例题：从 lavaan 输出到一张路径表

拿到 `summary(fit, standardized = TRUE)` 的长篇输出，不要从头读到尾。按下面四步提取写论文需要的信息：

1. **先看估计是否正常结束。**输出顶部应有 “lavaan ... ended normally after N iterations”。如果出现 “did not converge” 或关于方差为负的警告，后面的数字都不能用。先检查变量的尺度（相差太大时可以先除以 10），或者模型是否写错。

2. **再看拟合（Model Test User Model 与 fitMeasures）。**记下 χ²、df、p，以及 CFI、TLI、RMSEA（附 90% CI）和 SRMR，一起放进表注。

3. **然后找 Regressions 部分。**每一行是一条路径，例如 `dep2 ~ lone1`。看 `Estimate`（未标准化）和 `Std.all`（标准化 β），以及 `P(>|z|)`。把 4 条自回归、4 条交叉滞后整理成一张表，行是路径，列是 b、SE、β、p。

4. **最后看 Covariances。**`lone2 ~~ dep2` 是 T2 两个变量的**残差**协方差，表示扣除 T1 预测之后，同一时间点上还剩多少共同变化。它不是简单的“T2 孤独与 T2 抑郁的相关”。

用 `parameterEstimates(fit, standardized = TRUE)` 可以把这些结果变成一个数据框，再用 `subset(pe, op == "~")` 只取回归路径，比从屏幕上手抄更不容易出错。

**代码层面的常见错误**

- **模型字符串里变量名写错。**lavaan 会报 “some observed variables are not found in the data”，提示的变量名就是写错的那个。逐个对照 `names(dat)`。

- **忘了 T1 变量之间的协方差。**lavaan 的 `sem()` 默认会估计外生变量（T1）之间的协方差，但如果你用 `lavaan()` 手写全部参数，就必须自己写上 `lone1 ~~ dep1`，否则模型会假设它们不相关，拟合会差得离谱。

- **用 p 值比较两条交叉滞后路径。**一条 p = .001、另一条 p = .20，并不说明两者差异显著。需要像本课那样施加等值约束，再做 χ² 差异检验。

- **只报 CFI 而回避 RMSEA。**本课数据就是一个反例：CFI 看起来尚可，RMSEA = .141 却很差。应完整报告，并讨论指标为什么不一致。

```r
# =====================================================================
# L5-2.R  用 lavaan 拟合 CLPM 并评估模型拟合  (CLPM in lavaan; model fit)
# =====================================================================
source("R/_setup.R")
library(lavaan)
log_open("L5-2_log.txt")
dat <- read_course_data()
wide <- data.frame(id = dat$id)
for (t in 1:3) {                                   # 构念总分（construct scores）
  wide[[paste0("lone", t)]] <- rowSums(dat[, paste0(lone_items, "_t", t)])
  wide[[paste0("dep", t)]]  <- rowSums(dat[, paste0(dep_items, "_t", t)])
}
clpm <- '
  lone2 ~ lone1 + dep1      # T2 孤独 被 T1 孤独（AR）和 T1 抑郁（CL）预测
  dep2  ~ dep1  + lone1
  lone3 ~ lone2 + dep2
  dep3  ~ dep2  + lone2
  lone1 ~~ dep1             # ~~ 表示（残差）相关
  lone2 ~~ dep2
  lone3 ~~ dep3
'
fit <- sem(clpm, data = wide, missing = "fiml")   # FIML：全信息最大似然，处理缺失
print(summary(fit, standardized = TRUE, fit.measures = TRUE))   # print()：用 source() 或 run_all.R 运行时也写进日志
pe <- parameterEstimates(fit, standardized = TRUE)
print(pe[pe$op == "~", c("lhs", "op", "rhs", "std.all", "ci.lower", "ci.upper", "pvalue")], digits = 3)
print(round(fitMeasures(fit, c("chisq", "df", "pvalue", "cfi", "tli", "rmsea", "srmr")), 3))
cat("提示：CFI ≥ .95、RMSEA ≤ .06、SRMR ≤ .08 常被当作“拟合良好”的参考。\n")
# 标准化估计要配标准化的置信区间：standardizedSolution() 按 delta 法为 est.std 计算 SE 和 95% CI
# （上面 parameterEstimates() 的 ci.lower / ci.upper 属于未标准化估计，不能和 std.all 并排解读）
cat("\n标准化解（standardizedSolution）：回归路径的标准化估计及其 95% CI\n")
ssol <- standardizedSolution(fit)
print(ssol[ssol$op == "~", c("lhs", "op", "rhs", "est.std", "se", "ci.lower", "ci.upper", "pvalue")], digits = 3)
saveRDS(wide, out("L5_sumscores.rds"))
log_close()
```

## ④ 理解检查 即时测验

lavaan 语法中 `~` 与 `~~` 分别表示？

- A. 相关；回归

- 反了：`~` 是回归，`~~` 才是协方差。

- B. 回归；相关（协方差）（正确）

- 正确：`y ~ x` 回归，`x ~~ y` 协方差。

- C. 潜变量定义；回归

- 潜变量定义是 `=~`，不是 `~`。

- D. 均值；方差

- 均值写作 `x ~ 1`，方差写作 `x ~~ x`；`~` 与 `~~` 本身分别表示回归和协方差。

RMSEA = 0.141 说明什么？

- A. 模型拟合很好

- RMSEA ≤ .06 才常被视为较好，.141 已超过 .10。

- B. 模型拟合较差（> .10），模型很可能遗漏了重要结构（正确）

- 正确；在本数据中，被遗漏的主要是稳定特质（见 5.3）。

- C. 交叉滞后显著

- 整体拟合指标与单条路径是否显著无关。

- D. 样本量太小

- N = 800 不小；而且 N 越大，同样的 χ² 对应的 RMSEA 越小。

CFI = .962 而 TLI = .856，下列说法正确的是？

- A. 只看 CFI 就够了

- 只挑对自己有利的指标会掩盖模型的问题；本例中 RMSEA 也很差。

- B. 指标互相矛盾时应综合判断，并思考模型可能缺了什么（正确）

- 正确。

- C. TLI 一定算错了

- TLI 对模型复杂度惩罚更多，两者不同很常见，不说明计算有误。

- D. 说明交叉滞后路径为 0

- 整体拟合指标不检验任何单条路径是否为 0。

给 T1→T2 与 T2→T3 的同类路径加“等值约束”的主要理由是？

- A. 让 p 值变小

- 约束的目的是简约和稳定；为了得到更小的 p 值去选模型，属于选择性报告。

- B. 间隔与情境相似时更简约、更稳定，且可用模型比较检验是否合理（正确）

- 正确。

- C. lavaan 要求必须加

- lavaan 默认各路径自由估计；是否约束由研究者决定并检验。

- D. 让 CFI 一定变大

- 约束减少了自由参数，拟合通常略变差或不变，CFI 不会因此一定变大。

许多 CLPN 论文没有报告 CFI / RMSEA，最可能的原因是？

- A. 因为题目层面的数据算不出协方差矩阵

- 题目同样有协方差矩阵；完整流程的 SEM 重估正是在题目层面计算拟合指标。

- B. 它们用的是“仅 LASSO”简化版：只做逐节点 LASSO 回归，没有把模型作为一个整体 SEM 重估，所以没有整体拟合指标；采用 Wysocki 等人（2025）完整流程（lavaan 重估）的论文会报告 χ² / CFI / TLI / RMSEA（正确）

- 正确。简化版依靠交叉验证/EBIC 选 λ，并用 bootstrap 评估稳定性；完整流程在 SEM 重估后有整体拟合指标，并可用嵌套 χ² 检验跨时间等值（7.5 课，R/L7-5b.R）。

- C. 因为 CLPN 的拟合总是完美的

- 逐节点 LASSO 回归没有整体拟合检验，谈不上“总是完美”；完整流程重估后的拟合也可能不好。

- D. 因为任何 CLPN 都不可能计算拟合指标

- 完整流程的 SEM 重估就能给出这些指标（7.5）。

## 小结 本课小结与延伸阅读

- SEM 拟合 = 模型隐含协方差 Σ(θ) 与样本协方差 S 的接近程度。

- 常用指标：χ²、CFI/TLI（≥ .95）、RMSEA（≤ .06）、SRMR（≤ .08）；这些是经验规则，需综合判断。

- 课程数据上的 CLPM：RMSEA = .141、TLI = .856，提示遗漏了稳定特质。

- 等值约束 = 给路径相同标签；用嵌套模型 χ² 差异检验判断是否合理。

- “仅 LASSO”的 CLPN 没有整体拟合指标，靠 λ 选择与 bootstrap 稳定性来“自证”（Wysocki 等人 2025 年的完整流程在无惩罚的 SEM 重估之后才有拟合指标）。
