假设检验、p 值与效应量

课文学习 2 小时先修：1.5 抽样、标准误与置信区间配套脚本：R/L1-6.R

本课学习目标

  1. 说出零假设检验的逻辑步骤
  2. 正确解释 p 值，并识别常见误读
  3. 区分统计显著与实际意义（效应量）
  4. 理解 I 类/II 类错误、统计功效与多重比较问题

核心概念

  • 零假设null hypothesis, H₀
  • 备择假设alternative hypothesis
  • p 值p-value
  • 显著性水平significance level, α
  • I 类/II 类错误Type I / Type II error
  • 统计功效statistical power
  • 效应量effect size
  • 多重比较multiple comparisons

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉“这个差异是真的，还是碰巧？”

女性更抑郁吗？

课程数据里，女性（427 人）的 T1 抑郁总分平均 4.21，男性（373 人）平均 3.41，差了 0.79 分。督导问：“这 0.79 分是两类人群真的有差别，还是只是这次抽样碰巧抽到的？”上一课你知道了，任何样本统计量都会因为抽样而波动；即使总体中男女完全没有差别，样本里也几乎不可能正好差 0 分。我们需要一个规则来判断：差异大到什么程度，才不太可能“只是碰巧”。

假设检验的逻辑：先假设“没有效应”，再看数据有多“意外”

类比：法庭审判

法庭遵循“无罪推定”：先假设被告无罪，再看证据。如果在“无罪”的前提下，这些证据极不可能出现，法官才判有罪。证据不足时判“无罪”，并不等于证明了被告清白，只是“不能排除合理怀疑”。

统计检验沿用这个逻辑：

  1. 提出零假设（null hypothesis, H₀）：“没有效应”。例如“总体中男女抑郁均值相同”。与之对立的是备择假设（alternative hypothesis） H₁：“有差异”。
  2. 假设 H₀ 为真，计算：像我们这样的数据（或更极端的数据）出现的概率有多大。这个概率就是p 值（p-value）。
  3. 如果 p 很小（小于事先定好的显著性水平（significance level, α），通常 α = 0.05），就说数据与 H₀“不太相容”，拒绝 H₀，称结果“统计显著”。否则“不拒绝 H₀”。

拖动滑块：观察到的检验统计量越极端（离 0 越远），两条红色尾巴的面积（p 值）越小。当 |z| 超过 1.96 时，p < 0.05。课程数据中男女抑郁差异的 t = −3.33，p ≈ 0.0009：如果总体中男女真的没有差别，抽到这么大（或更大）差异的概率不到千分之一。

p 值的常见误读

p = 0.03 不表示以下任何一项
  • “零假设为真的概率是 3%。”p 值是在假定 H₀ 为真的前提下算出来的，它不能反过来告诉你 H₀ 为真的概率。
  • “结果有 97% 的概率是真的。”理由同上。
  • “效应很大 / 很重要。”p 值同时受效应大小和样本量影响，见下文。
  • “p = 0.06 说明没有效应。”“不显著”只是证据不足，不等于证明了“没有差异”。
  • “p = 0.049 和 p = 0.051 有本质区别。”0.05 只是一条约定俗成的线。

正确：“如果零假设为真，观察到至少这么极端的结果的概率是 0.03。”

统计显著 ≠ 实际重要：效应量

p 值的大小取决于两件事：效应有多大、样本有多大。样本非常大时，微小到没有实际意义的差异也会“显著”：SE 随 \(\sqrt n\) 缩小，任何非零的差异最终都会被检测出来。所以必须同时报告效应量（effect size）：一个不随样本量膨胀、描述“效应有多大”的指标。

  • Cohen's d：两组均值差除以合并标准差，“两组相差几个标准差”。粗略参考：0.2 小、0.5 中、0.8 大。课程数据中男女抑郁差异 d = 0.235：统计上非常显著，但效应小。社工实务中，这意味着性别不是区分抑郁风险的强有力指标，个体差异远大于组间差异。
  • 相关系数 r 和标准化回归系数 β 本身也是效应量。CLPN 的边权重就是一种效应量。

两类错误与统计功效

真相：H₀ 为真（无效应）真相：H₀ 为假（有效应）
判决：拒绝 H₀I 类错误（Type I error）（假阳性），概率 = α正确发现，概率 = 功效
判决：不拒绝 H₀正确II 类错误（假阴性），概率 = β

统计功效（statistical power） = 1 − β：当效应真实存在时，研究能检测到它的概率。功效取决于效应大小、样本量和 α。小样本研究功效低，容易漏掉真实的小效应；而且小样本中“碰巧显著”的结果往往高估了效应。社工研究常常样本不大，这一点在解读“不显著”时尤其重要。（注意：这里表格中的 β 是 II 类错误的概率，与回归系数 β 只是同一个希腊字母，含义完全不同。）

多重比较：一个网络有 190 条可能的边

α = 0.05 意味着：每做一次 H₀ 为真的检验，有 5% 的机会犯 I 类错误。如果一次做很多检验呢？一个有 20 个节点的横断面网络，有 20 × 19 / 2 = 190 对节点。如果每一对都做显著性检验，即使所有真实关系都是 0，平均也会有 190 × 0.05 = 9.5 条“显著”的假边。这就是多重比较（multiple comparisons）问题。

勾选 Bonferroni 校正（把 α 除以检验次数）后，假边几乎消失；但代价是门槛变得极高，真实的小效应也很难被发现。网络分析通常走另一条路：正则化（regularization）（3.5 课的 LASSO、6.3 课的 graphical lasso），不逐条做显著性检验，而是让模型把不够强的边压成 0。所以很多 CLPN 论文里看不到每条边的 p 值。但要注意：正则化并不控制假阳性。用交叉验证选 λ（lambda.min）时，留下的边里常混有不少假阳性（7.2 用 glmnet 逐节点估计 CLPN 会看到具体数字）；CLPN 方法论文推荐的完整流程，最后也要用 p 值筛选路径（7.5 设计选择与扩展：多波数据、协变量与被试内问题）。

② 最少数学检验统计量与 Cohen's d

大多数检验统计量都长这样

$$\text{检验统计量} = \frac{\text{估计值} - \text{H}_0\text{ 下的值}}{SE} \qquad \text{例：}\; z = \frac{(\bar x_1 - \bar x_2) - 0}{SE(\bar x_1 - \bar x_2)}$$

读法：“估计值离零假设有几个标准误那么远”。离得越远，在 H₀ 下越“意外”，p 越小。|z| > 1.96 ⇔ 双侧 p < 0.05 ⇔ 95% CI 不包含 0，这三句话说的是同一件事。R 的 summary(lm()) 里 “t value = Estimate / Std. Error” 就是这个公式（2.5 课）。

p 值的定义

$$p = P\big(\,|Z| \ge |z_{\text{观测}}| \;\big|\; H_0 \text{ 为真}\big)$$
\(P(\cdot)\)
概率。
竖线 \(\mid\)
读作“在……的条件下”。p 值是条件概率：条件是 H₀ 为真。
\(|Z| \ge |z_{\text{观测}}|\)
“至少和观察到的一样极端”（双侧：两个方向都算）。

微积分视角：p 值就是正态曲线下两条尾巴的面积，即概率密度函数的积分 \(2\int_{|z|}^{\infty} \varphi(u)\,du\)，其中 \(\varphi\) 是标准正态的密度函数。

Cohen's d

$$d = \frac{\bar x_1 - \bar x_2}{s_p}, \qquad s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}$$

\(s_p\) 是合并标准差（pooled SD）：两组方差的加权平均再开根号。课程数据：\(d = (4.21-3.41)/s_p \approx 0.235\)，可反推 \(s_p \approx 3.37\)。

③ R 代码t 检验、效应量与多重比较模拟

对应脚本：R/L1-6.R。

1. t 检验：女性与男性的抑郁总分是否不同？
source("R/_setup.R")
dat <- read_course_data()
dat$dep_sum_t1 <- rowSums(dat[, paste0(dep_items, "_t1")])
t.test(dep_sum_t1 ~ gender, data = dat)     # ~ 读作“按……分组”
输出（R/output/L1-6_log.txt）
	Welch Two Sample t-test

data:  dep_sum_t1 by gender
t = -3.3345, df = 796.39, p-value = 0.0008939
alternative hypothesis: true difference in means between group 0 and group 1 is not equal to 0
95 percent confidence interval:
 -1.2601649 -0.3262758
sample estimates:
mean in group 0 mean in group 1
       3.412869        4.206089

逐项读：

  • Welch Two Sample t-test：不假设两组方差相等的 t 检验（R 的默认，较稳妥）。
  • t = -3.3345：检验统计量。负号是因为 R 用“组 0（男）减组 1（女）”。
  • df：自由度，决定 t 分布的形状；Welch 检验的自由度可以是小数。
  • p-value = 0.0008939：p ≈ 0.0009 < 0.05。
  • 95 percent confidence interval: -1.26 -0.33：（男 − 女）均值差的 95% CI，不包含 0，与 p < 0.05 一致。
2. 效应量 Cohen's d
m <- tapply(dat$dep_sum_t1, dat$gender, mean)    # 按性别分组求均值
s <- tapply(dat$dep_sum_t1, dat$gender, sd)
n <- table(dat$gender)
sp <- sqrt(((n[1] - 1) * s[1]^2 + (n[2] - 1) * s[2]^2) / (sum(n) - 2))   # 合并标准差
cat("Cohen's d =", round((m[2] - m[1]) / sp, 3), "（0.2 小 / 0.5 中 / 0.8 大）\n")
输出（R/output/L1-6_log.txt）
Cohen's d = 0.235 （0.2 小 / 0.5 中 / 0.8 大）
3. 多重比较：20 个毫无关系的变量 → 190 个相关检验
set.seed(1)
noise <- matrix(rnorm(200 * 20), 200, 20)        # 200 人 × 20 个纯噪声变量
pv <- c()
for (i in 1:19) for (j in (i + 1):20) pv <- c(pv, cor.test(noise[, i], noise[, j])$p.value)
cat("纯噪声中，190 个相关里 p < .05 的有", sum(pv < .05), "个（期望约 9.5 个假阳性 false positives）\n")
cat("Bonferroni 校正后显著的有", sum(p.adjust(pv, "bonferroni") < .05), "个\n")
输出（R/output/L1-6_log.txt，节选）
纯噪声中，190 个相关里 p < .05 的有 15 个（期望约 9.5 个假阳性 false positives）
Bonferroni 校正后显著的有 0 个

这次碰巧出现了 15 个假阳性（期望值 9.5，每次模拟会有波动）。p.adjust(pv, "bonferroni") 把每个 p 值乘以 190（上限为 1），等价于把 α 除以 190。

完整例题：从均值差到 p 值

干预组与对照组各 50 人，干预后孤独均值分别为 5 和 6，两组 SD 都是 2。

  1. 效应量 Cohen's d = (6 − 5) / 2 = 0.5，属于“中等”。
  2. 均值差的标准误 = 2 × √(1/50 + 1/50) = 2 × 0.2 = 0.4。
  3. t = 1 / 0.4 = 2.5，自由度 98，双侧 p ≈ .014。

同样 d = 0.5，如果每组只有 10 人：SE = 2 × √(0.2) ≈ 0.894，t ≈ 1.12，p ≈ .28，“不显著”。效应没变，变的只是证据的多少。所以论文要同时报告效应量和 p 值。

常见错误
  • 试了很多分析，只报告显著的那个（p-hacking）。换协变量、换子样本、换计分方式，每试一次都是一次新的检验；多重比较模拟说明，做 190 次检验平均会有 9.5 个“碰巧显著”。只报告显著的那个，读者就无从知道背后试过多少次。对策是事先写好分析计划（10.1 项目设计、数据准备与分析计划），并报告所有做过的分析。

④ 理解检查即时测验

p = 0.03 是不是说“零假设为真的概率是 3%”？

  • 这是本课列出的第一种误读：p 值以 H₀ 为真为前提计算，不能反过来给出 H₀ 为真的概率。
  • 这是同一种误读换了个说法；p 值不给出任何假设为真的概率。
  • 正确。p 值的“条件”是 H₀ 为真，它不能反过来给出 H₀ 为真的概率。
类比：“如果被告无罪，出现这些证据的概率很低”不等于“被告无罪的概率很低”。

样本量非常大时（如 n = 100,000），为什么很小的效应也会“显著”？

  • 数据质量不随样本量自动提高；显著是因为 SE 变小了。
  • 正确。所以要报告效应量。
  • α 是研究者事先定的，不随样本量改变。
  • 效应大小是总体的性质，不随样本量改变；变的只是估计的精度。
例如 r = 0.02 在 n = 100,000 时 p 远小于 0.001，但 r = 0.02 几乎没有实际意义。

一个有 20 个节点的网络，逐条检验 190 条边（α = 0.05，且所有真实边都为 0），平均会出现多少条假阳性的边？

每条边犯 I 类错误的概率是 α。
190 × 0.05 = 9.5。这就是多重比较问题，也是网络分析采用正则化的原因之一。

一项小样本研究（n = 30）发现社区干预对抑郁“无显著效果”（p = 0.20）。最恰当的结论是？

  • “不显著”不等于“证明无效”；小样本功效低，可能漏掉真实效应。
  • 正确。还应报告效应量和置信区间。
  • p 值本身不提供方向，而且不显著的结果也不支持任何方向的结论。
  • 看到结果后再改 α 是 p-hacking 的一种；α 必须事先定好。
报告效应量和 95% CI 能让读者看到“效应可能有多大”的范围。

男女抑郁差异 p ≈ 0.0009、Cohen's d = 0.235。哪种解读最好？

  • d = 0.235 是小效应；本课也没有和其他预测因素比较。
  • 这是本课点名的误读：p 小主要是因为样本大（n = 800），效应量 d 才描述效应大小。
  • 正确。
永远同时看 p 值和效应量。

判断：“|z| > 1.96”、“双侧 p < 0.05”、“95% CI 不包含 0”说的是同一件事。

  • 正确：在基于正态近似的检验中，这三者等价。
  • 95% CI = 估计值 ± 1.96 × SE；估计值离 0 超过 1.96 个 SE，等价于区间不包含 0，也等价于双侧 p < 0.05。
若估计值离 0 超过 1.96 个 SE，那么“估计值 ± 1.96 SE”这个区间就不会包含 0。

⑤ 练习动手练习

练习 1.6-A：p 值表述找错

判断下面 6 句话是否正确；错的请改写。

  1. “p = 0.01，说明研究假设有 99% 的概率是正确的。”
  2. “p = 0.04，因此在零假设为真的情况下，得到至少如此极端结果的概率为 4%。”
  3. “p = 0.12，说明孤独感与抑郁无关。”
  4. “干预组比对照组的效果显著更好（p < .001），说明干预效果非常大。”
  5. “A 研究 p = 0.04，B 研究 p = 0.06，所以两项研究的结论相互矛盾。”
  6. “结果显著（p = 0.02），效应量 d = 0.15，属于小效应。”
参考答案
  1. p 值不是假设为真的概率。改：“若零假设为真，观察到至少如此极端结果的概率为 1%。”
  2. 正确。
  3. 不显著 ≠ 无关。改：“未发现统计显著的关联（p = 0.12）；结合置信区间看，数据与无关联或较小的关联都相容。”
  4. p 值不反映效应大小。改：“差异统计显著（p < .001），效应量 d = …（需报告）。”
  5. 两个 p 值都在 0.05 附近，证据强度几乎相同；应比较效应量与置信区间，而不是看是否跨过 0.05。
  6. 正确，而且这是规范的做法：同时报告显著性与效应量。

练习 1.6-B：思考（150 字）

一个有 20 个节点的网络有 190 条可能的边，逐条做显著性检验会出现什么问题？有哪些可能的应对方法？

要点
  • 问题：多重比较 → 即使所有真实边为 0，期望也有约 9.5 条假阳性边；网络图会“看起来很丰富”但很多边是噪音。
  • 应对：(1) 校正 α（Bonferroni 等），但功效会大幅下降；(2) 正则化估计（LASSO / graphical lasso），把弱边压为 0，这是网络分析的主流做法（模块 3.5、6.3），但它本身不控制假阳性率；(3) 用 bootstrap 评估边的稳定性（模块 8）；(4) 在独立样本中复现。

提示

每次的个数会在 9.5 附近上下波动。参考答案 R/solutions/L1-6_solution.R：种子 2–6 分别得到 11、8、12、9、12 个假阳性，平均 10.4。更进一步：把整个模拟包进 replicate(200, {...})，200 个种子的平均是 9.29，非常接近理论值 9.5；单次结果最少 0 个、最多 19 个，中间 90% 落在约 5 到 15 之间。

练习 1.6-D：用“法庭”走一遍检验

以本课的男女抑郁差异（t = −3.33，p ≈ 0.0009）为例，按三步写出：(1) H₀ 和 H₁；(2) p 值在说什么；(3) 你的决策（α = 0.05）。再回答：这个决策如果错了，会是哪一类错误？如果换成一项 n = 30、p = 0.20 的研究，又可能犯哪一类错误？

参考答案

(1) H₀：总体中男女的平均抑郁总分相同；H₁：不同。(2) 如果 H₀ 为真，抽到至少这么大差异的概率约为 0.0009。(3) p < 0.05，拒绝 H₀，差异统计显著（同时报告 d = 0.235，效应小）。拒绝了 H₀，如果错了就是 I 类错误（假阳性）。n = 30、p = 0.20 时不拒绝 H₀，如果真实效应存在，就是 II 类错误（假阴性）；样本小、功效低，这种错误很容易发生。

小结带走三句话

  • p 值 = 若 H₀ 为真，得到至少如此极端结果的概率；它不是 H₀ 为真的概率，也不衡量效应大小。
  • 永远同时报告效应量（d、r、β）与置信区间；大样本中微小效应也会显著。
  • 边很多时逐条检验会产生大量假阳性。网络分析常用正则化把弱边压成 0，但正则化本身也不保证没有假阳性。M1 到此结束，配合 2.1 安装 R 与 RStudio，运行第一行代码–2.6 ggplot2 绘图与 Quarto / R Markdown 可复现报告 完成 R 基础后，下一统计模块进入回归分析 3.1 简单线性回归：用一条直线做预测。
