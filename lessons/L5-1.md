### 核心概念

- **交叉滞后面板模型** cross-lagged panel model, CLPM

- **自回归路径** autoregressive path

- **交叉滞后路径** cross-lagged path

- **路径图** path diagram

- **结构方程模型** structural equation modeling, SEM

- **同期相关** contemporaneous / within-wave correlation

- **残差协方差** residual covariance

## ① 直觉 先建立画面

### 一个社工场景

你在社区服务中心工作，三次（每次相隔半年）请同一批社区居民填写孤独感量表和抑郁量表。机构负责人问你：“到底是孤独让人抑郁，还是抑郁让人越来越孤独？”这类“谁先谁后”的问题，就是 交叉滞后面板模型 （cross-lagged panel model, CLPM） 想回答的问题。

CLPM 的想法可以拆成三句话：

1. **人是有惯性的。**半年前很孤独的人，半年后大概率仍然比较孤独。这条“自己预测自己”的箭头叫 自回归路径 （autoregressive path, AR），它代表个体差异的稳定性。

2. **在扣除惯性之后，再看对方能不能多说明一点。**如果知道了一个人半年前的抑郁水平之后，再知道他半年前的孤独水平，还能更好地预测他现在的抑郁，那么“孤独 T1 → 抑郁 T2”这条 交叉滞后路径 （cross-lagged path, CL） 就不为 0。

3. **同一时间点两者本来就会一起波动。**同一次测量中，孤独和抑郁之间的相关（以及 T2、T3 时“没被前一波解释掉的部分”之间的相关）用 同期相关 / 残差协方差 （within-wave correlation / residual covariance） 表示，画成双向弯箭头。

**关键直觉：**

交叉滞后系数回答的不是“孤独和抑郁有没有关系”，而是“在已知你过去的抑郁水平的前提下，你过去的孤独能否额外预测你未来的抑郁”。这就是“控制自回归”的含义。

### 路径图：SEM 的图示语言

CLPM 属于 结构方程模型 （structural equation modeling, SEM）。SEM 习惯用 路径图 （path diagram） 表达模型，符号约定只有几条：

| 符号 | 含义 | 在 CLPM 中 |
| --- | --- | --- |
| 方框 □ | 观测变量（直接测到的分数） | 孤独 T1、抑郁 T2……（这里用量表总分） |
| 椭圆 ○ | 潜变量（不能直接测到） | 5.3 课的“随机截距”就是潜变量 |
| 单向箭头 → | 回归（预测）路径 | 自回归 a、b；交叉滞后 c、d |
| 双向弯箭头 ↔ | 相关 / 协方差 | 同一波次内的（残差）相关 |

### 为什么交叉滞后一定要“控制”自回归？

设想孤独与抑郁在 T1 就有很强的相关（例如 r = .5），而且两者各自都非常稳定。即使孤独对抑郁完全没有额外的预测作用，“孤独 T1”和“抑郁 T2”之间也会有不小的相关，因为孤独 T1 与抑郁 T1 相关，而抑郁 T1 又强烈预测抑郁 T2。如果不把抑郁 T1 放进方程，“孤独 T1 → 抑郁 T2”这条路径就会把这份“借来的”相关错当成自己的功劳。这和 M3 中的“遗漏变量偏差”（漏掉一个既与预测变量相关、又影响结果的变量，系数就会把它的作用“吸收”进来；这里是偏大）是同一个道理（复习 [3.2 多元回归与“控制其他变量”](L3-2.html)）。

### c 显著、d 不显著，能说明什么？

假设“抑郁 T1 → 孤独 T2”（c）显著，而“孤独 T1 → 抑郁 T2”（d）不显著。最谨慎的说法是：*在这个样本、这个时间间隔下，T1 抑郁较高的人，在控制了 T1 孤独之后，T2 时的孤独也较高；反方向的预测关系没有得到支持。*注意三点：（1）“不显著”不等于“没有”，可能只是样本量或间隔不合适；（2）两条路径一显著一不显著，并不等于两者“有显著差异”，比较它们需要专门的检验（例如在 lavaan 里把 c、d 约束相等后做模型比较）；（3）这仍是时间上的预测，不是因果（见 [5.4 从预测到因果：纵向模型能说什么、不能说什么](L5-4.html)）。

### CLPM 与 CLPN：变量从“总分”变成“题目”

传统 CLPM 中，每个方框是一个构念的总分（如孤独 4 题相加）。于是我们只能说“孤独整体”预测“抑郁整体”。但社工实务中我们更想知道：是“无人理解”这种感受，还是“缺少陪伴”这种处境，更能预测之后的“兴趣丧失”？CLPN 就是把 CLPM 的方框换成每一道题，于是 2 个变量的 4 条路径，变成 9 个题目的 81 条路径（9 条自回归 + 72 条交叉滞后）。路径太多，就需要 LASSO 来“挑选”（M3 的 [3.5 过拟合与正则化：岭回归、LASSO 与交叉验证](L3-5.html) 与 M7）。

**小提醒：**

本课的 R 脚本先用普通回归 `lm()` 来“近似”CLPM 的一个时间段（T1→T2），帮助你看清“每个 T2 变量就是一个回归方程”；下一课 5.2 再用 lavaan 一次性拟合整个三波模型。

## ② 最少数学 把直觉写成式子

CLPM 的数学就是两条（每个时间段）多元回归方程。设所有变量都已标准化（z 分数，均值 0、标准差 1，见 M1）：

\[\text{孤独}_{t+1} = a\cdot \text{孤独}_{t} + c\cdot \text{抑郁}_{t} + e^{L}_{t+1}\]

\[\text{抑郁}_{t+1} = b\cdot \text{抑郁}_{t} + d\cdot \text{孤独}_{t} + e^{D}_{t+1}\]

| 符号 | 读法 / 含义 |
| --- | --- |
| \(t,\ t+1\) | 两个相邻的测量时间点（波次 wave），例如 T1 和 T2 |
| \(a,\ b\) | 自回归系数：控制对方后，“自己的过去”对“自己的现在”的预测强度。标准化后通常在 0.3–0.8 之间 |
| \(c,\ d\) | 交叉滞后系数：控制自己的过去后，“对方的过去”对“自己的现在”的额外预测。c = 抑郁→孤独，d = 孤独→抑郁 |
| \(e^{L}_{t+1},\ e^{D}_{t+1}\) | 残差（residual）：方程没能解释的部分。上标 L、D 只是标签，分别表示孤独和抑郁的方程 |
| \(\mathrm{Cov}(e^{L}_{t+1}, e^{D}_{t+1})\) | 同一波次两个残差之间的协方差，即路径图中 T2、T3 的双向弯箭头，代表“同时发生、但不能被上一波解释的共同变化” |

#### 如何读一个标准化系数？

若 \(d = 0.13\)，读作：*在 T1 抑郁相同的两个人中，T1 孤独高 1 个标准差的人，T2 抑郁的预测值平均高 0.13 个标准差。*“在……相同的两个人中”就是“控制”的通俗说法。

#### 三波数据有几条路径？

两个变量、三波：T1→T2 有 2 条自回归 + 2 条交叉滞后，T2→T3 同样 4 条，共 8 条回归路径；再加上 T1 的相关和 T2、T3 的残差相关共 3 条双向箭头。推广：k 个变量、每个时间段需要 k 个方程，每个方程有 k 个预测变量，所以每段 \(k \times k\) 个系数，这就是 CLPN 中 \(p\times p\) 系数矩阵的来源。

**与微积分的联系：**

如果你还记得偏导数，交叉滞后系数 \(d\) 就是 \(\partial\,\mathbb{E}[\text{抑郁}_{t+1}] / \partial\,\text{孤独}_t\)：把 \(\text{抑郁}_t\) 固定不动，只让 \(\text{孤独}_t\) 变化一个单位时，预测值变化多少。不记得也没关系，“控制其他变量不变”就是全部含义。

## ③ R 代码 在 R 中实现

课程所有脚本都先运行 `source("R/_setup.R")`：它会把工作目录设到课程文件夹、定义题目名 `lone_items`（孤独 4 题）、`dep_items`（抑郁 5 题），以及读取数据的函数 `read_course_data()`。数据 `data/clpn_sim_wide.csv` 是 N = 800 的三波模拟面板，变量名形如 `lone1_t1`（孤独第 1 题、第 1 波）。

R/L5-1.R 的核心部分（逐行注释）

```r
source("R/_setup.R")            # 公共准备：路径、题目名、字体、辅助函数
dat <- read_course_data()       # 读入 data/clpn_sim_wide.csv（N = 800）
z <- function(x) as.numeric(scale(x))   # 标准化为 z 分数
for (t in 1:3) {                # 计算每一波的构念总分，并标准化
  dat[[paste0("lone", t)]] <- z(rowSums(dat[, paste0(lone_items, "_t", t)]))
  dat[[paste0("dep", t)]]  <- z(rowSums(dat[, paste0(dep_items, "_t", t)]))
}
# 每个 T2 变量 = 一个回归方程
coef(lm(lone2 ~ lone1 + dep1, data = dat))   # a（lone1）与 c（dep1）
coef(lm(dep2  ~ dep1 + lone1, data = dat))   # b（dep1）与 d（lone1）
```

**怎么读：**`paste0(lone_items, "_t", t)` 生成 `"lone1_t1" "lone2_t1" …` 这样的列名；`rowSums()` 把每个人的 4 道孤独题相加；`lm(y ~ x1 + x2)` 是 M3 学过的多元回归，波浪号 `~` 读作“被……预测”。

**在课程数据上的实际结果：**`lone2 ~ lone1 + dep1` 得到 a ≈ 0.607、c ≈ 0.016；`dep2 ~ dep1 + lone1` 得到 b ≈ 0.539、d ≈ 0.128。也就是说，在这份模拟数据中“孤独 T1 → 抑郁 T2”明显大于反方向。（这些数字与下一课 lavaan 的标准化结果完全一致，因为一个时间段的 CLPM 回归部分就等于两条回归。）

## ④ 理解检查 即时测验

在 CLPM 中，“抑郁 T1 → 抑郁 T2”这条路径叫什么？

- A. 交叉滞后路径

- 交叉滞后连接的是不同变量、不同时间；这条路径是同一个变量自己预测自己。

- B. 自回归路径（正确）

- 自回归 = 变量自己预测自己，代表稳定性。

- C. 同期相关

- 同期相关连接的是同一波次的两个变量，是双向箭头。

- D. 残差

- 残差是方程没解释的部分，不是一条路径。

为什么交叉滞后路径必须控制自回归路径？

- A. 为了让模型拟合更好看

- 控制自回归是为了排除“借来的”关联，与拟合指标好不好看无关。

- B. 因为 T1 时两变量相关、且各自稳定，不控制会让交叉路径“借走”稳定性带来的关联（正确）

- 正确：这本质上是“遗漏变量偏差”。

- C. 因为 lavaan 规定必须这样写

- lavaan 允许不写自回归；必须控制是统计逻辑的要求，不是软件规定。

- D. 为了让系数变成标准化系数

- 标准化只改变单位，与方程里控制了哪些变量无关。

c（抑郁→孤独）显著、d（孤独→抑郁）不显著，最恰当的结论是？

- A. 抑郁导致孤独

- CLPM 只能提供时间上的预测证据，不能直接说“导致”。

- B. 孤独不会影响抑郁

- 不显著 ≠ 不存在：可能只是样本量或间隔不合适。

- C. 在本样本与间隔下，T1 抑郁能额外预测 T2 孤独；反方向未得到支持，且两者差异需另行检验（正确）

- 正确：措辞谨慎、并注意“一显著一不显著”不等于“差异显著”。

- D. 两个方向的效应存在显著差异

- 一条显著、一条不显著，并不说明两者差异显著；需要专门的约束检验才能下此结论。

路径图中的双向弯箭头 ↔ 表示什么？

- A. 回归

- 回归（预测）是单向箭头。

- B. 相关 / 协方差（正确）

- 正确。

- C. 因果

- 路径图里没有专门的“因果”符号，单向箭头也只表示回归。

- D. 潜变量

- 潜变量用椭圆表示，不是一种箭头。

CLPM 与 CLPN 最主要的区别是？

- A. CLPM 不需要纵向数据

- 两者都需要同一批人的面板数据。

- B. CLPM 的变量是构念总分，CLPN 的节点是单个题目/症状（正确）

- 正确：CLPN 把 CLPM “拆到题目层面”。

- C. CLPN 不包含自回归

- CLPN 也包含自回归：系数矩阵的对角线就是自回归边。

- D. CLPN 只能用两个时间点

- CLPN 可以用多波数据（7.5 课）。

## 小结 本课小结与延伸阅读

- CLPM = 每个后一波变量一条多元回归方程；自回归代表稳定性，交叉滞后代表“控制自身过去后对方过去的额外预测”。

- 路径图符号：方框 = 观测变量，椭圆 = 潜变量，单箭头 = 回归，双箭头 = 相关。

- 交叉滞后必须控制自回归，否则会混入 T1 相关与稳定性带来的“借来的”关联。

- CLPN 把 CLPM 的总分方框拆成题目节点：p 个题目 → p × p 个系数。
