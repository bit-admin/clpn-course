## ① 直觉 R 是什么？为什么要学写代码？

**一份会“自己重做”的分析**

小周用 SPSS 点菜单做完了毕业论文的分析。答辩前一周，小周发现有 12 份问卷录入错了，改正后必须重新跑一遍。他不记得三个月前点过哪些菜单、勾过哪些选项，只好从头摸索，熬了两个通宵。同组的小林用 R 写了一个脚本：改正数据后，按一下“运行”，一分钟后所有表格和图都更新了。代码就是一份完整、精确、可以重复执行的分析记录。

R （R language） 是一门专门为统计分析设计的免费、开源的编程语言。CLPN 所需的工具（`glmnet`、`qgraph`、`bootnet` 等）都是 R 的扩展包，在 SPSS 里没有对应的菜单。这是本课程使用 R 的直接原因。

RStudio / Posit （IDE） 是写 R 代码的“工作台”（集成开发环境，Integrated Development Environment）。RStudio 现由 Posit 公司开发（该公司 2022 年由 RStudio 更名为 Posit），软件仍叫 RStudio Desktop，有免费版本。关系可以这样理解：R 是发动机，RStudio 是汽车的仪表盘和方向盘。必须先装 R，RStudio 才能工作。

### 安装步骤

1. **安装 R**：访问 CRAN（R 的官方发布网站 `https://cran.r-project.org`），选择你的系统（Windows / macOS），下载最新版本并按默认选项安装。国内下载慢时，可以在 CRAN 镜像列表中选择国内高校镜像（如清华大学 TUNA 镜像）。

2. **安装 RStudio Desktop**：访问 Posit 官网（`https://posit.co/download/rstudio-desktop/`），下载免费版本并安装。

3. **打开 RStudio**（不是打开 R）。在左下方的窗口输入 `1 + 1` 回车，看到 `[1] 2` 就说明成功了。

**最常见的安装坑**

- **中文用户名 / 中文路径**：如果 Windows 用户名是中文（如 `C:\Users\张三`），某些包的安装可能出问题。建议把课程文件夹放在纯英文路径下（如 `D:\clpn-course`）。

- 先装 R 再装 RStudio；如果 RStudio 提示找不到 R，重新安装 R 后重启电脑。

- Mac 用户注意选择与芯片对应的 R 版本（Apple Silicon 为 arm64，Intel 为 x86_64）。

本课程脚本在 R 4.5 和 R 4.6 下测试过；你安装的版本更新也没关系。

### RStudio 的四个窗格

（交互图示：panes）

- **脚本编辑器**（左上）：写代码、保存代码的地方，像 Word 文档。

- **控制台 （console）**（左下）：真正执行代码的地方，显示结果。`>` 是提示符，表示“R 在等你输入”。

- **环境**（右上，Environment）：列出你创建过的所有对象，例如 `age`、`scores`。

- **文件 / 图形 / 包 / 帮助**（右下）：浏览文件、看画出的图、查看帮助页面。

### 控制台 vs 脚本：草稿纸 vs 笔记本

在控制台直接输入代码，回车就执行，但关掉 RStudio 就没了，像在草稿纸上算题。脚本 （script）是一个 `.R` 文本文件，代码可以保存、修改、注释、重复运行、发给合作者，像一本记录完整的笔记本。**原则：除了临时试一下，所有分析代码都写在脚本里。**

在脚本里运行代码：把光标放在某一行（或选中几行），按 Ctrl + Enter（Mac：Cmd + Enter），这一行就被送到控制台执行。新建脚本：菜单 File → New File → R Script（快捷键 Ctrl+Shift+N）；保存：Ctrl+S，文件名建议只用英文、数字和下划线，例如 `week02.R`。

### 对象与赋值：给盒子贴标签

R 里的一切数据都存在对象 （object）里。`age <- 21` 的意思是：“创建一个名叫 `age` 的盒子，把 21 放进去”。箭头 `<-` 叫赋值 （assignment, <-）（RStudio 快捷键 Alt + -）。之后写 `age`，R 就会取出盒子里的 21。

**类比：贴标签的储物盒**

赋值就像往储物盒里放东西并贴上标签。`age <- 22` 会把盒子里原来的 21 换成 22（旧值被覆盖，R 不会提醒你）。右上角的“环境”窗格就是你的储物架，列出所有盒子和里面的东西。

**命名规则**：名字可以包含字母、数字、点和下划线，必须以字母或点开头；以点开头时，点后面不能紧跟数字（`.2x` 不合法，R 会把 `.2` 读成数字 0.2）；不能有空格；不能用 `if`、`TRUE`、`NA` 等保留字；**区分大小写**（`Age` 和 `age` 是两个不同的对象；逻辑值只能写成 `TRUE`/`FALSE`，写成 `true` 会报 object not found）。推荐用小写字母加下划线，例如 `dep_sum_t1`。避免用 `mean`、`c`、`data` 这样与常用函数同名的名字。

`=` 在大多数情况下也能赋值（`age = 21`），但 R 社区的惯例是用 `<-` 赋值，`=` 留给函数参数（如 `mean(x, na.rm = TRUE)`）。而 `==` 是“比较是否相等”，返回 `TRUE` 或 `FALSE`：`x <- 5` 是“把 5 放进 x”，`x == 5` 是“问：x 等于 5 吗？”。

### 函数：会做事的“机器”

函数 （function）是“输入 → 处理 → 输出”的机器，写法是函数名加圆括号，括号里放输入（参数）。例如 `mean(scores)` 计算平均数，`sqrt(16)` 开平方，`round(3.14159, 2)` 四舍五入到两位小数。`c()` 是最常用的函数之一：把多个值“组合”（combine）成一个向量。

### 求助的三种方式

1. **帮助页面**：在控制台输入 `?mean`，右下窗格会打开 `mean` 的说明书。重点看 Usage（怎么写）、Arguments（每个参数是什么）、Examples（例子，可以直接复制运行）。不知道函数名时用 `??"standard deviation"` 模糊搜索。

2. **读报错 （error message）**：红色的 `Error` 不是“电脑坏了”，而是 R 在告诉你哪里不对。遇到报错，第一步是读完报错信息，找出它提到的函数名或对象名。常见报错和读法见 R 代码部分。

3. **向别人提问**（同学、同事或网上论坛）：提供一个最小可复现例子 （minimal reproducible example），即别人复制粘贴就能重现你的问题的最短代码。“我的代码跑不了”几乎没法回答，提问要按下面的模板准备材料。

**提问模板**

1. 我想做什么（目标）。

2. 我运行的代码：最短的、能重现问题的几行，包括 `library()` 和数据。数据不要写“我的数据”，而要让别人也能运行：可以现造几行（例如 `dat <- data.frame(x = c(1, 2, NA))`），也可以用 `dput(head(d))` 把你自己数据的前几行转成可复制的代码。

3. 完整的报错信息（复制文字，不要只发截图）。

4. 我已经尝试过什么。

5. `sessionInfo()` 的输出（R 和包的版本）。

很多时候，在准备最小例子的过程中你自己就找到了问题。

**社会工作者学编程**

你不需要成为程序员。你需要的是能读懂、修改、运行别人写好的分析脚本，并在出错时知道去哪里找原因。这和社会工作者阅读政策文件很像：不必会写法律，但要能读懂条款、找到适用的部分。

## ② 最少数学 R 作为计算器

本课几乎没有新数学，只需知道 R 里的运算符号：

| 数学 | R 写法 | 例子 → 结果 |
| --- | --- | --- |
| \(a+b,\ a-b\) | `+ -` | `1 + 1` → 2 |
| \(a\times b\) | `*` | `21 * 365` → 7665 |
| \(a\div b\) | `/` | `10 / 3` → 3.333333 |
| \(a^b\) | `^` | `2^10` → 1024 |
| \(\sqrt{a}\) | `sqrt()` | `sqrt(16)` → 4 |
| \(e^{a},\ \ln a\) | `exp()`, `log()` | `exp(0.134)` → 1.143（3.4 课的 OR） |
| \(\bar x=\frac{1}{n}\sum x_i\) | `mean()` | `mean(c(3, 5, 2, 4))` → 3.5 |

\(a, b\)任意数字或存有数字的对象。\(e\)自然常数，约 2.718。\(\ln\)自然对数；R 的 `log()` 默认就是 \(\ln\)，以 10 为底用 `log10()`。\(\bar x\)平均数（1.2 课）。

运算顺序与数学一致：先乘方，再乘除，后加减；用圆括号改变顺序。输出前面的 `[1]` 不是结果的一部分，它表示“这一行从第 1 个元素开始”，因为 R 把所有结果都看作向量（2.2 课）。

### 最常见的报错，以及怎样修好

初学 R 时，大部分时间都花在报错上。下面把最常见的几类报错放在一起，每行故意写错一处。以下是英文界面下的报错原文（中文界面会显示中文翻译，例如“错误: 找不到对象'score'”）。

故意写错（逐行运行）

```r
Mean(scores)             # 大小写错了
mena(scores)             # 函数名拼错了
mean(score)              # 对象名拼错了（少了 s）
"a" + 1                  # 字符不能做加法
mean(scores) sd(scores)  # 一行里写了两条命令
mean(scores              # 少了右括号
```

报错信息与含义（示意：英文界面下的报错原文，每条下面的 → 是解释）

```text
Error in Mean(scores) : could not find function "Mean"
  → 找不到名为 Mean 的函数：R 区分大小写，应为 mean。
Error in mena(scores) : could not find function "mena"
  → 同一类报错：函数名拼错；或者函数属于某个还没有 library() 加载的包（2.4 课）。
Error: object 'score' not found
  → 找不到对象 score：拼写错误，或者忘了先运行创建它的那一行。
Error in "a" + 1 : non-numeric argument to binary operator
  → 对非数字做了数学运算：检查变量是不是被读成了字符（2.2 课）。
Error: unexpected symbol in "mean(scores) sd"
  → R 读到一个不该出现的符号：两条命令之间缺少换行或分号。中文逗号、括号、引号会引发类似的 unexpected input。
+
  → 控制台出现 + 而不是 > ：R 认为命令还没写完（缺括号或引号）。补上 ) 回车，或按 Esc 取消。
```

“object not found”最常见的修法是回头运行创建对象的那一行，再重新运行出错的代码：

修好“object not found”

```r
scores <- c(3, 5, 2, 4)  # 先运行创建它的那一行（注意拼写：Scores 与 scores 是两个名字）
mean(scores)
```

**读报错的三步**

1. 看报错的**最后一行**，找关键词：`could not find function`、`object ... not found`、`unexpected`……

2. 找它点名的对象或函数，回到出错的那一行，核对拼写、大小写、括号和引号是否成对，以及是否已运行过创建对象的代码。

3. 还看不懂，就把报错原文（英文）复制到搜索引擎，几乎所有初学者的报错都有人问过。可以用 `Sys.setenv(LANGUAGE = "en")` 把报错切换成英文，方便搜索。仍然解决不了，再按上面的提问模板向别人求助。

**常见错误**

- **输入法停在中文状态。**中文逗号“，”、中文括号“（）”和中文引号“”都会导致 unexpected input。写代码时把输入法切换成英文，只在引号里面写中文。

- **把文件存在桌面或“下载”文件夹里。**路径一乱，`read.csv()` 就找不到文件。从第一天起就用本课程的文件夹结构（2.4 课会讲 RStudio 项目）。

## ④ 理解检查 即时测验

脚本和控制台有什么区别？为什么要写在脚本里？

- 控制台的代码会自动存进 .R 文件，所以两者一样可以复现

- 控制台只留下零散的历史记录（History），不是一份按顺序整理、带注释、可以直接重跑的分析文件。

- 控制台执行后不保存；脚本可以保存、修改、注释、重复运行和分享，分析才可复现（正确）

- 正确。

- 脚本运行得更快

- 速度一样：脚本里的代码也是送到控制台执行的。

脚本是你分析的完整记录；数据改了，重新运行一遍就行。

x <- 5 和 x == 5 有什么区别？

- 前者把 5 赋值给 x；后者比较 x 是否等于 5，返回 TRUE/FALSE（正确）

- 正确。

- 两者都是赋值，== 只是更严格的写法

- == 不改变 x，它只返回 TRUE 或 FALSE；赋值用 <- （或 =）。

- 前者比较，后者赋值

- 正好反了：<- 是赋值箭头，== 才是比较。

= 可以赋值，== 才是比较。

运行 Mean(c(1, 2, 3)) 后出现 could not find function "Mean"。最可能的原因？

- 需要先运行 install.packages("Mean") 安装这个函数

- mean() 是 R 自带的函数，不用安装；问题在于 Mean 的大写 M。

- R 区分大小写，函数名应为 mean（正确）

- 正确。

- c(1, 2, 3) 里有对象还没有创建

- 那样的报错是 object ... not found；这里 R 说的是找不到函数。

另一种常见原因是函数来自某个包，而你忘了 library() 加载它。

遇到报错，第一步应该做什么？

- 立刻截图发给别人求助

- 应先自己读报错；即使求助，也要复制报错文字，而不是只发截图。

- 用 Sys.setenv(LANGUAGE = "en") 切换成英文再运行

- 切换语言只是方便搜索，报错的内容不变；第一步仍是读懂它说了什么。

- 完整读一遍报错信息，找到它点名的函数或对象，回到代码核对（正确）

- 正确。

读不懂再搜索英文原文，最后带着最小可复现例子去问人。

在 R 中输入 2^3 + 4 / 2，结果是多少？

检查

2^3 = 8，4/2 = 2，8 + 2 = 10。

- 2nd_score

- dep sum

- 不能有空格。

- dep_sum_t1（正确）

- 正确：小写字母加下划线，清楚易读。

- `<-` 赋值，`==` 比较；对象名区分大小写；函数 = 名字 + 圆括号。
