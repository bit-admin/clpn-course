标准化系数与结果解释

课文学习 1 小时先修：3.2 多元回归与“控制其他变量”、1.3 标准化与 z 分数配套脚本：R/L3-3.R

本课学习目标

  1. 区分非标准化系数 b 与标准化系数 β
  2. 在不同量尺的预测变量间比较相对大小
  3. 写出一句规范的回归结果报告

核心概念

  • 标准化回归系数standardized coefficient, β
  • 非标准化系数unstandardized coefficient, b
  • APA 格式APA style

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉“哪个因素更重要？”先统一单位

社会支持和睡眠，谁对抑郁的预测更强？

3.2 课的模型 m2 给出：社会支持的系数 −0.252，睡眠时长的系数 −0.371。能说“睡眠比社会支持更重要”吗？不能直接这么说。社会支持是 1–5 分的量表均分，睡眠是“小时”。社会支持高 1 分是很大的变化（全样本标准差才 0.79 分），睡眠多 1 小时也差不多是 1 个标准差（1.02 小时）。再看一个例子：如果把睡眠改用“分钟”记录，它的系数会变成 −0.0062，数字小了 60 倍，但睡眠和抑郁的关系一点也没变。

这种带着原始单位的系数叫非标准化系数（unstandardized coefficient, b）：“x 每多 1 个原始单位，y 平均多 b 个原始单位”。它的大小依赖于单位，所以不同单位的变量之间不能直接比较。

解决办法：先把所有变量（包括结果变量）都变成 z 分数（1.3 课），再做回归。此时每个变量的单位都是“1 个标准差”，得到的系数叫标准化回归系数（standardized coefficient, β）：“x 每高 1 个标准差，y 平均高 β 个标准差（其他预测变量不变）”。

（组件里的“月收入”是一个虚构的例子，课程数据中没有收入变量；它只用来演示换单位时 b 与 β 的变化。）

β 的单位取自本样本

β 用“1 个标准差”作统一单位，所以不同单位的预测变量之间可以比大小。但这个标准差是本样本的标准差：同一个效应，在一个睡眠时长差异很大的样本里，β 会比在一个大家都睡得差不多的样本里更大。β 适合在同一模型内比较，跨样本比较时要小心。

标准化后，m2 的结果变为：孤独 β = 0.26，睡眠 β = −0.11，社会支持 β = −0.06（不显著）。这时可以说：在这个样本和这个模型里，T1 孤独感对 T2 抑郁的独特预测最强；睡眠时长较弱；控制前两者后社会支持的独特预测接近零。

β 怎么读

“β = 0.25” 读作：在其他预测变量保持不变时，x 每高 1 个标准差，y 平均高 0.25 个标准差。不要读成“x 解释了 25% 的 y”（那是 R² 的语言，而且 β² 也不等于独特解释比例，除非只有一个预测变量），也不要读成“x 增加 25%”。

只有一个预测变量时，β 正好等于相关系数 r。有多个预测变量时，β 是“偏”的：它是控制了其他变量后的值，可以和 r 差别很大，甚至符号相反。

什么时候报告 b，什么时候报告 β？

非标准化 b标准化 β
单位原始单位（分、小时、岁）标准差
适合单位本身有实际意义时：“每多睡 1 小时，抑郁分平均低 0.37 分”；做预测；跨研究比较同一量表比较同一模型中不同单位的预测变量；单位没有直观意义的量表分
缺点不同单位之间不可比依赖本样本的标准差：样本变异小，β 就小（1.4 课的范围限制）；不同样本间的 β 不一定可比
二分类预测变量（如性别 0/1）很好读：“女性比男性平均高 b 分”“性别高 1 个标准差”没有意义，通常不标准化

许多期刊建议两者都报告，或报告 b 及其置信区间，同时给出效应量。

CLPN 的边为什么通常基于标准化变量？

CLPN 网络图中，所有边画在同一张图上，用线的粗细比较“哪条边更强”。若不标准化，不同量尺的题目（孤独题 1–4 分，抑郁题 0–3 分）之间的系数不可比：两类题目的标准差不同，标准差大的题目系数会显得小（只是起点不同不会影响系数）。因此常见做法是先把所有题目标准化（课程脚本里的 clpn_estimate() 就是这么做的）。另外，3.5 课的 LASSO 惩罚的是系数绝对值的大小，如果变量单位不同，惩罚就不公平，这也要求先标准化。

注意：“边权重”仍然不是“效应大小”的绝对标准

标准化系数依赖于样本的方差结构；不同样本（例如社区样本 vs 临床样本）题目方差不同，β 不能直接比较。比较两组网络要用专门的方法（如网络比较检验 Network Comparison Test），本课程不展开。

写出规范的结果报告

心理学和社会工作期刊大多采用 APA 格式（APA style）（美国心理学会出版手册）。一个回归结果的报告通常包含：效应方向与大小（b 或 β）、95% 置信区间、检验统计量或 p 值，以及模型的 R²。规范要点：

  • 统计符号用斜体（b、p、t、R²），标准化系数用希腊字母 β（正体，不用斜体），中文论文里也直接写 β，不译成汉字；未标准化系数写作斜体 b（或 B），两者不要混用。
  • p 值报告精确值（如 p = .019），小于 .001 写 p < .001；不可能大于 1 的统计量（如 p、r，以及通常小于 1 的 β）小数点前一般不写 0（APA 习惯）。
  • 先写变量关系，再在括号里附上统计量；用“预测”“相关”，观察数据不写“导致”“影响”。
  • 说明控制了什么变量。
一个示例（基于本课 R 输出）

以 T2 抑郁总分为因变量，以 T1 孤独感和 T1 抑郁为自变量进行多元线性回归（所有变量已标准化）。控制 T1 抑郁后，T1 孤独感仍正向预测 T2 抑郁，β = .13，95% CI [.07, .19]，p < .001；T1 抑郁的自回归效应较强，β = .54，95% CI [.48, .60]，p < .001。模型共解释 T2 抑郁 35% 的方差（R² = .35）。

同样的结果写成英文 APA 句式：Controlling for T1 depression, T1 loneliness positively predicted T2 depression, β = .13, 95% CI [.07, .19], p < .001.

报告中的常见错误

  1. 只报告星号或只报告 p：读者不知道效应有多大。p 值只说明“如果真实效应为 0，看到这么极端结果的概率有多小”（1.6 课），它不是效应大小。样本量很大时，极小的效应也会 p < .001。
  2. “显著”=“重要”：β = .05、p = .01 在统计上显著，但实际意义可能很小。社会工作者关心的是：这个差异在服务对象身上能不能被感受到？
  3. 不显著 = 没有关系：社会支持 p = .109 只说明这个样本不足以排除 0；其 95% CI [−.13, .01] 同时包含“小的负效应”和“几乎为零”。应写“未发现显著的独特预测作用”，而不是“社会支持与抑郁无关”。
  4. 比较两个 β 的大小就下结论“A 比 B 更重要”：两个系数的置信区间若大量重叠，差异可能只是抽样误差；β 还受预测变量之间的相关和各自测量信度的影响（信度低的变量，β 会被低估）；而且“重要”还取决于变量能否被干预、改变的成本等实际因素。
  5. 忘记说明控制变量和样本：同一个变量在不同模型中的系数不同（3.2 课），读者必须知道你控制了什么。
  6. 因果措辞：“孤独感影响/导致抑郁”应改为“孤独感预测/与……相关”。即使是纵向的交叉滞后系数，也只是“时间上领先的预测”（第 5 模块会详细讨论）。
社会工作视角：把 β 翻译给一线同事

机构同事未必理解“标准差”。可以这样翻译：“在 T1 抑郁程度相同的两位服务对象里，孤独感处于平均水平以上一个‘典型差距’的那位，半年后的抑郁分平均会高出约 0.13 个典型差距。效应不大；在本样本中，95% CI 不包含 0。” 如果需要更直观，可以回到原始单位：“孤独量表每高 1 分，半年后抑郁平均高约 0.14 分（满分 15 分）。”

② 最少数学b 与 β 的换算

$$\beta_j = b_j \times \frac{s_{x_j}}{s_y}$$
\(b_j\)
第 \(j\) 个预测变量的非标准化系数。
\(s_{x_j}\)
该预测变量的样本标准差。
\(s_y\)
结果变量的样本标准差。
\(\beta_j\)
标准化系数。

为什么？\(x\) 增加 1 个标准差 = 增加 \(s_x\) 个原始单位，于是 \(y\) 增加 \(b\cdot s_x\) 个原始单位 = \(b\cdot s_x / s_y\) 个 \(y\) 的标准差。

验证：m3 中孤独的 \(b = 0.1398\)，\(s_{\text{孤独}} = 3.082\)，\(s_{\text{T2抑郁}} = 3.365\)：\(\beta = 0.1398\times 3.082/3.365 \approx 0.128\)，四舍五入为 0.13，与 L3-3.R 的输出一致。

单位变化：睡眠改用分钟后 \(s_x\) 变为 60 倍，\(b\) 变为 1/60，乘积 \(\beta\) 不变。

置信区间

$$95\%\ CI \approx b \pm 1.96\times SE(b)$$

（样本大时 \(t\) 分布临界值约为 1.96；R 的 confint() 使用精确 \(t\) 值。）区间不含 0 ⇔ 在 .05 水平显著。

③ R 代码标准化、置信区间与报告

对应脚本：R/L3-3.R。

R/L3-3.R（核心部分）
source("R/_setup.R")
dat <- read_course_data()
d <- data.frame(dep2  = rowSums(dat[, paste0(dep_items, "_t2")]),
                lone1 = rowSums(dat[, paste0(lone_items, "_t1")]),
                dep1  = rowSums(dat[, paste0(dep_items, "_t1")]))
dz <- as.data.frame(scale(d))                     # 所有变量先标准化 → 系数即 β
fit <- lm(dep2 ~ lone1 + dep1, data = dz)
ci <- confint(fit)                                # 95% 置信区间
s <- summary(fit)$coefficients
for (v in c("lone1", "dep1")) {
  cat(sprintf("%s: β = %.2f, 95%% CI [%.2f, %.2f], p %s\n", v, s[v, 1], ci[v, 1], ci[v, 2],
              ifelse(s[v, 4] < .001, "< .001", sprintf("= %.3f", s[v, 4]))))
}
输出（R/output/L3-3_log.txt）
lone1: β = 0.13, 95% CI [0.07, 0.19], p < .001
dep1: β = 0.54, 95% CI [0.48, 0.60], p < .001

说明：scale() 返回矩阵，所以用 as.data.frame() 转回数据框；sprintf() 按模板格式化数字，%.2f 表示保留两位小数，%% 输出一个百分号。

比较 m2 的 b 与 β（不同单位的预测变量）
d$support <- dat$social_support_t1
d$sleep   <- dat$sleep_hours_t1
f_b    <- lm(dep2 ~ lone1 + support + sleep, data = d)
f_beta <- lm(dep2 ~ lone1 + support + sleep, data = as.data.frame(scale(d)))
round(cbind(b = coef(f_b), beta = coef(f_beta)), 3)
输出（R/output/L3-3_log.txt，节选）
              b   beta
(Intercept)  4.672  0.000
lone1        0.282  0.258
support     -0.252 -0.059
sleep       -0.371 -0.112

标准化后截距为 0（所有变量均值都是 0）。社会支持的 b（−0.252）与睡眠的 b（−0.371）看起来接近，换成 β 后，睡眠（−0.112）的点估计约是社会支持（−0.059）的两倍。但只能说“点估计约两倍”：练习答案里会看到，两者的 95% CI 分别是 [−0.18, −0.05] 和 [−0.13, 0.01]，大量重叠。两个 β 是否真的不同，要对差值本身做检验（例如比较受约束与不受约束的模型），不能凭两个点估计的比值下结论。

round(coef(f_b)["lone1"] * sd(d$lone1) / sd(d$dep2), 3)    # 等于上表的 β
d$sleep_min <- d$sleep * 60                                 # 睡眠改用分钟
round(coef(lm(dep2 ~ lone1 + support + sleep_min, data = d))["sleep_min"], 4)
输出（R/output/L3-3_log.txt，末尾）

手算的 0.258 与上表的 β 相同。睡眠改用分钟后，b 从 −0.371 变成 −0.0062（= −0.371 / 60）：单位缩小 60 倍，系数就缩小 60 倍，但模型的拟合、t 值和 p 值都不变，β 也不变。这就是“b 的大小取决于单位”的意思。

④ 理解检查即时测验

多元回归中孤独感 β = 0.25，怎么读最准确？

  • 那是 R² 的含义，且 β² 也不等于独特解释比例。
  • 单位都弄错了：β 的两端都以标准差为单位，不是百分比，也不是原始分。
  • 正确。
  • 那是非标准化系数 b 的读法；β 的单位是标准差，不是原始分。
β 的单位是“标准差”，并且是控制其他预测变量后的值。

以下哪种情况更适合报告非标准化系数 b？

  • 两者单位不同，比较相对强弱正需要 β。
  • 正确：原始单位有直接实际意义。
  • 孤独题与抑郁题量尺不同，网络图通常用标准化系数。
当单位本身有意义（次数、小时、元、量表原始分）时，b 更好沟通；二分类预测变量也通常报告 b。

某回归中 b = 0.5，\(s_x = 2\)，\(s_y = 4\)。β 是多少？

β = b × s_x / s_y。
0.5 × 2 / 4 = 0.25。

把睡眠从“小时”换成“分钟”记录后，它的 b 和 β 会怎样？

  • β 不变：s_x 同时变为 60 倍，b × s_x 保持不变。
  • 正确。
  • 方向反了：每分钟的效应比每小时小。
β 用标准差作单位，与原始单位无关。

CLPN 的边权重通常基于标准化变量，主要原因是？

  • 正确。
  • 标准化只是换单位，不改变数据的观察性质，也排除不了混杂。
  • 抽样误差来自样本本身，换单位不会改变它；8 模块的 bootstrap 才用来评估它。
  • 这是本课提醒的误读：β 依赖本样本的标准差，跨样本比较网络要用专门方法（如网络比较检验）。
标准化解决的是“单位不可比”，不解决因果与抽样误差。

以下哪句结果报告最规范？

  • 观察数据不能写“导致”，且 p 不能报告为 0.000。
  • 正确：方向、大小、区间、p、控制变量都齐了。
  • 只给星号，读者看不到效应方向、大小和区间。
  • 数字齐了一部分，但“影响”是因果措辞，而且缺少 95% CI。
报告应包含方向、效应量、置信区间、p 值以及控制了什么。

⑤ 练习动手练习

练习 3.3-A：标准化后重跑 3.2 的模型并写报告

把 3.2 的模型 m2（孤独 + 社会支持 + 睡眠预测 T2 抑郁）在标准化后重跑，按 APA 格式写 2–3 句结果报告（含 β、95% CI、p）。

参考代码与示例报告 
fz <- lm(dep2 ~ lone1 + support + sleep, data = as.data.frame(scale(d[, c("dep2","lone1","support","sleep")])))
round(cbind(beta = coef(fz), confint(fz), p = summary(fz)$coefficients[, 4]), 3)
summary(fz)$r.squared

参考结果：孤独 β = .26，95% CI [.19, .33]，p < .001；社会支持 β = −.06，95% CI [−.13, .01]，p = .109；睡眠 β = −.11，95% CI [−.18, −.05]，p < .001。

示例报告：以 T2 抑郁为因变量的多元回归显示（所有变量已标准化），T1 孤独感正向预测 T2 抑郁，β = .26，95% CI [.19, .33]，p < .001；T1 睡眠时长负向预测 T2 抑郁，β = −.11，95% CI [−.18, −.05]，p < .001；控制前两者后，社会支持的预测作用不显著，β = −.06，95% CI [−.13, .01]，p = .109。模型解释了 T2 抑郁约 10% 的方差（R² = .10）。注意这个模型没有控制 T1 抑郁，不能解释为“交叉滞后”效应。

练习 3.3-B：手算与解释

(1) 用公式 β = b·sx/sy 从 m3（未标准化）手算 T1 抑郁的 β（b = 0.534，sT1抑郁 = 3.398，sT2抑郁 = 3.365）。(2) 有人说“性别的 β = 0.12，所以女性比男性抑郁高 0.12 个标准差”，这样说对吗？

参考答案

(1) 0.534 × 3.398 / 3.365 ≈ 0.539，与输出 0.54 一致。(2) 不够准确：β 是“性别变量高 1 个标准差”的效应，而 0/1 变量的标准差约 0.5，所以“女性 vs 男性（差 1 个原始单位）”约等于 β / s性别 ≈ 0.12/0.5 = 0.24 个 y 的标准差。对二分类变量，更清楚的做法是只标准化 y、不标准化性别，或直接报告 b。

小结带走三句话

  • b 带原始单位，β 以标准差为单位；β = b·sx/sy。
  • 比较不同单位的预测变量用 β；单位有实际意义或预测变量是二分类时用 b。
  • 规范报告：方向 + β/b + 95% CI + p + 控制变量 + R²，用“预测”不用“导致”。下一课：3.4 逻辑回归简介（二分类结果）。
