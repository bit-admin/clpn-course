模块 4 · Longitudinal / Panel Data · 第 4.2 课

宽格式与长格式：数据整形

课文学习 1 小时 30 分钟先修：4.1 纵向设计的语言：波次、时间间隔、被试内与被试间、2.3 数据框与 tidyverse 入门配套脚本：R/L4-2.R

本课学习目标

  1. 区分宽格式（每人一行）与长格式（每人每波一行）
  2. 用 tidyr::pivot_longer() / pivot_wider() 互相转换
  3. 为 CLPN 准备“T1 题目矩阵 + T2 题目矩阵”，并保证个案一一对齐

核心概念

  • 宽格式wide format
  • 长格式long format
  • 数据整形reshaping
  • 个案 IDparticipant ID
  • 变量命名规范naming convention, e.g. sleep_t1

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉同一份数据，两种摆法

两种登记本

社区中心记录小组成员三次活动的出勤和心情评分。社工小陈用的是“一人一行”的登记本：每位成员占一行，第 1 次、第 2 次、第 3 次的评分依次排在同一行的不同列里。社工小吴用的是“一次一行”的流水账：每位成员每参加一次就记一行，有“成员编号”“第几次”“评分”三列。两本记录的信息完全一样，只是摆放方式不同。

小陈的是宽格式（wide format）：每人一行，不同波次的同一变量放在不同列（lone1_t1、lone1_t2、lone1_t3）。课程数据 clpn_sim_wide.csv 就是宽格式：800 行。

小吴的是长格式（long format）：每人每波一行，用一列 wave 标明波次，同一变量只占一列（lone1）。课程数据转成长格式后是 800 × 3 = 2400 行。

在两者之间转换叫数据整形（reshaping）。不同的分析需要不同的格式：

分析需要的格式原因
lavaan 拟合 CLPM / RI-CLPM（第 5 模块）宽格式SEM 把每个“变量 × 波次”看作一个单独的变量（lone2 ~ lone1 + dep1）
CLPN（第 7 模块）宽格式，再拆成 d1（T1 题目）和 d2（T2 题目）两个矩阵每个 T2 题目对全部 T1 题目回归
多层模型（lme4）、ggplot 画轨迹图长格式“波次”是一个变量；每个观测是一行
按波次汇总（每波均值）长格式更方便group_by(wave) |> summarise()

两种格式没有好坏之分，取决于下一步用什么工具。一个实用的工作流程：原始数据保持宽格式（与问卷系统导出的一致）；需要画图或做多层模型时临时转成长格式，用完即可，不必另存。

变量命名规范：让电脑也读得懂的名字

宽格式数据能被自动整形，靠的是统一的变量命名规范（naming convention, e.g. sleep_t1）：题目名_t波次。好处：

  • 一眼就懂：dep3_t2 是第 3 道抑郁题、第 2 波。
  • 能被程序拆开：pivot_longer(names_sep = "_t") 按 _t 把列名切成“题目名”和“波次”两部分。
  • 能被程序选择：paste0(题目, "_t", 1) 生成 T1 的全部列名；ends_with("_t2") 选出所有 T2 变量。
  • 不容易错位：每个 T1 变量都有一个名字可预测的 T2 对应变量。

问卷平台导出的列名常是“Q1、Q2……Q27”或一长串中文题干，拿到数据第一件事就是按数据字典重新命名。

个案 ID（participant ID）：对齐的生命线

为什么拆分 T1/T2 时必须按 ID 对齐？

CLPN 用“第 37 行的 T1 题目”去预测“第 37 行的 T2 题目”，前提是两行是同一个人。如果 T1 和 T2 来自两个文件、排序不同（例如 T2 文件按提交时间排序），直接把两张表并排拼在一起，第 37 行的 T1 可能是小王、T2 却是小李。结果是：所有跨时间的关系都被打乱成随机噪音。本课 R 代码中的演示：故意打乱 T2 的顺序后，情绪低落 T1–T2 的相关从 0.432 掉到 0.008，自回归和交叉滞后效应全部“消失”，而且 R 不会报任何错。

解决办法：合并时永远用 left_join(t1, t2, by = "id") 之类按 ID 匹配的函数，而不是按行号并排；拆分后用 identical(d1$id, d2$id) 检查。

类比：配袜子

洗衣机里拿出一堆袜子，按“第几只拿出来”配对，多半配错。要按花色（ID）配对。数据整形和合并也是一样。

宽 ↔ 长 的“配方”

宽 → 长：pivot_longer()（tidyr 包）。告诉它：哪些列要“拉长”（除 id 以外的所有列：-id），列名怎么拆（names_sep = "_t"），拆出来的两部分分别是什么（names_to = c(".value", "wave")）。".value" 是一个特殊的写法，意思是“拆出来的第一部分（如 lone1）就作为新的列名，值放在这一列里”；第二部分（1、2、3）放进名为 wave 的新列。

长 → 宽：pivot_wider()。告诉它：新列名从哪一列来（names_from = wave），值从哪些列来（values_from = 题目列），拼接时用什么分隔（names_sep = "_t"）。

整形之后一定要检查：行数是否等于“人数 × 波次数”；转回去是否和原数据完全相同（all.equal()，本课脚本就这样检验）；ID 是否对齐；再抽查一个人（如 filter(long, id == first(id))）的值是否与宽格式一致。

② 最少数学两个矩阵，一一对应

CLPN 需要两个矩阵：

$$\mathbf{D}_1 = \begin{pmatrix} x_{1,1}^{(1)} & \cdots & x_{1,p}^{(1)}\\ \vdots & & \vdots\\ x_{n,1}^{(1)} & \cdots & x_{n,p}^{(1)}\end{pmatrix},\qquad \mathbf{D}_2 = \begin{pmatrix} x_{1,1}^{(2)} & \cdots & x_{1,p}^{(2)}\\ \vdots & & \vdots\\ x_{n,1}^{(2)} & \cdots & x_{n,p}^{(2)}\end{pmatrix}$$
\(x_{i,j}^{(t)}\)
第 \(i\) 个人在第 \(j\) 道题、第 \(t\) 波的得分。
\(n\)
人数（行数），两个矩阵必须相同。
\(p\)
题目数（列数）；两个矩阵的第 \(j\) 列必须是同一道题。

两个对齐条件：行对齐（\(\mathbf{D}_1\) 的第 \(i\) 行和 \(\mathbf{D}_2\) 的第 \(i\) 行是同一个人）与列对齐（第 \(j\) 列是同一道题）。CLPN 的第 \(j\) 个方程是用 \(\mathbf{D}_1\) 的所有列预测 \(\mathbf{D}_2\) 的第 \(j\) 列；行没对齐，方程就失去意义；列没对齐，你会把“T1 情绪低落 → T2 睡眠问题”误读为自回归。

长格式行数 = \(n\times T\) = 800 × 3 = 2400；长格式列数 = id + wave + 题目数 = 2 + 9 = 11。

③ R 代码pivot_longer、pivot_wider 与 d1/d2

对应脚本：R/L4-2.R。

R/L4-2.R（核心部分）
source("R/_setup.R")
library(tidyverse)
wide <- read_csv("data/clpn_sim_wide.csv", show_col_types = FALSE) |>
  select(id, all_of(c(vars_t(1), vars_t(2), vars_t(3))))   # 只保留 id + 27 个题目列

# 宽 → 长：列名 "lone1_t2" 按 "_t" 拆成 题目名(.value) 和 波次(wave)
long <- wide |>
  pivot_longer(-id, names_to = c(".value", "wave"), names_sep = "_t")
print(head(long)); cat("长格式行数 =", nrow(long), "（= 800 人 × 3 波）\n")

# 长 → 宽：再变回来，并检查与原数据一致
wide2 <- long |> pivot_wider(names_from = wave, values_from = all_of(items), names_sep = "_t")
wide2 <- wide2[, names(wide)]                               # 列顺序排回原样
cat("转回宽格式后与原数据完全相同？", isTRUE(all.equal(as.data.frame(wide), as.data.frame(wide2))), "\n")

# 拆出 d1 与 d2 —— 用 vars_t() 保证题目顺序一致
d1 <- wide |> select(all_of(vars_t(1)))
d2 <- wide |> select(all_of(vars_t(2)))
stopifnot(nrow(d1) == nrow(d2),
          identical(sub("_t1", "", names(d1)), sub("_t2", "", names(d2))))  # 检查顺序
cat("d1、d2 行数与题目顺序检查通过 ✔\n")

代码要点
  • vars_t(1)（定义在 _setup.R）返回 T1 的 9 个题目列名，顺序固定：lone1–lone4、dep1–dep5。all_of() 告诉 select()：“按这个字符向量里的名字选列，一个都不能少”（缺了会报错，以免漏选而不自知）。
  • wave 列是字符型 <chr>（"1"、"2"、"3"）。需要做数值运算（如以时间为预测变量）时，用 mutate(wave = as.integer(wave))，或在 pivot_longer() 中加 names_transform = list(wave = as.integer)。
  • stopifnot()：条件不成立就立即报错停止。把检查写进脚本，比“肉眼看一下”可靠得多。
  • sub("_t1", "", names(d1))：把列名中的 "_t1" 删掉，得到 lone1 … dep5，再与 d2 去掉 "_t2" 后的名字逐一比较。

陷阱 2：按行号拼接两个排序不同的文件

t2 <- wide |> select(id, ends_with("_t2")) |> slice_sample(prop = 1)   # 模拟“T2 文件顺序不同”

课程数据中还有不随时间变化的变量（如性别、年龄），需要单独处理（见下）。

不随时间变化的变量怎么办？

性别、年龄只测一次，列名里没有 “_t1”。如果直接 pivot_longer(-id, ...)，names_sep 切不开 “gender”，会报错或产生错误的列。两种做法：①先用 select() 只保留 id 和各波题目，整形之后再用 left_join(by = "id") 把人口学变量接回来；②在 pivot_longer 中写 -c(id, gender, age)，这些列会在每一行自动重复。

长格式的一个典型用途：个人均值中心化

4.1 课把分数拆成“个人平均水平（被试间）+ 这一波偏离个人平均的部分（被试内）”。在长格式中，这只需要两步：long |> group_by(id) |> mutate(dep_pm = mean(dep1), dep_dev = dep1 - dep_pm) |> ungroup()。dep_pm 是每人三波的平均分，同一个人的三行取值相同；dep_dev 是每一波相对自己平均水平的高低，每人三行加起来等于 0。在宽格式中做同样的事，要对每道题、每一波分别写公式，既麻烦又容易出错。讨论被试内问题（5.3、7.5 课）时会反复用到这种拆分。

常见错误
  • pivot_wider 出现 list 列和警告 “Values are not uniquely identified”。说明同一个 id × wave 有不止一行，通常是 id 重复录入，或者漏了某个区分变量。先用 count(long, id, wave) |> filter(n > 1) 找出重复项。
  • 列名不规范，切不开。lone1_T1、lone1.t1、t1_lone1 混在一起时，names_sep 无能为力。先用 rename() 或 names(d) <- ... 统一命名规则，再整形。

小练习：判断数据格式

下面三种情况分别需要什么格式？①用 lavaan 拟合两波的 CLPM；②画 800 人三波孤独总分的轨迹图；③计算每人三波抑郁的平均分。参考答案：①宽格式；②长格式（每人每波一行，group = id）；③两种都行。宽格式下用 rowMeans() 对三列求平均；长格式下用 group_by(id) |> summarise(m = mean(dep))。同一个问题有两种解法时，选你写起来最不容易出错的那种。

④ 理解检查即时测验

lavaan 跑 CLPM 通常需要哪种格式？

  • 正确。
  • 长格式适合多层模型和画轨迹图；SEM 需要“孤独 T1”“孤独 T2”各占一列。
  • lavaan 不会识别波次：它把每一列当作一个变量，而长格式的 lone1 一列混合了三波的分数。
CLPN 同样从宽格式出发，拆成 d1、d2。

为什么拆分 T1/T2 时必须按 ID 对齐？

  • 恰恰相反：按行号拼接不会报任何错，错位的结果照样算得出来，所以必须自己按 ID 对齐并检查。
  • 正确。
  • R 不要求排序；left_join() 按 ID 匹配，两个文件顺序不同也能正确合并。
用 left_join(by = "id") 合并，用 identical(d1$id, d2$id) 检查。

变量名 sleep_t1、sleep_t2 这种命名有什么好处？

  • 正确。
  • sleep_t1 并不比 Q12 更短；好处在于名字有规律，人和程序都能读懂。
  • R 对命名格式没有要求；这是一种约定，names_sep = "_t" 能据此拆分列名。
这是 pivot_longer(names_sep = "_t") 能工作的前提。

一份宽格式数据有 500 人、4 波、每波 6 道题（另有 id 列）。转成长格式（id、wave + 6 个题目列）后有多少行？

长格式每人每波一行。
500 × 4 = 2000 行，8 列。

在 pivot_longer(names_to = c(".value", "wave"), names_sep = "_t") 中，".value" 的作用是？

  • 那是 names_to = "name" 加 values_to 的情形。
  • 正确。
  • pivot_longer() 默认保留缺失值（values_drop_na = FALSE）；.value 只决定新列名从哪里来。
所以长格式有 lone1、lone2 …… dep5 这 9 列，外加 id 和 wave。

用 select(ends_with("_t1")) 从课程原始数据中拆 d1，会出什么问题？

  • 正确。
  • 演示中选出了 12 列，而 T2 的题目只有 9 列，两边无法一一对应。
  • dep1_t1–dep5_t1 都以 _t1 结尾，都会被选中；问题是多选了，而不是漏选。
用明确的列名清单（vars_t()）+ all_of() 更安全。

练习 4.2-A：3 波 × 6 题的整形与对齐

把一份 3 波 × 6 题的宽格式数据转成长格式再转回来；最后拆出 d1（T1 的 6 题）和 d2（T2 的 6 题），检查行数与 ID 是否完全对应。（用课程数据中的 lone1–lone3、dep1–dep3 作为 6 道题。）

参考代码 
library(tidyverse)
wide <- read_csv("data/clpn_sim_wide.csv", show_col_types = FALSE)
six  <- c("lone1", "lone2", "lone3", "dep1", "dep2", "dep3")
w6 <- wide |> select(id, all_of(paste0(rep(six, 3), "_t", rep(1:3, each = 6))))   # 1 + 18 列

l6 <- w6 |> pivot_longer(-id, names_to = c(".value", "wave"), names_sep = "_t")
dim(l6)                                     # 2400 行 × 8 列

w6b <- l6 |> pivot_wider(names_from = wave, values_from = all_of(six), names_sep = "_t")
isTRUE(all.equal(as.data.frame(w6), as.data.frame(w6b[, names(w6)])))   # TRUE

d1 <- w6 |> select(id, all_of(paste0(six, "_t1")))
d2 <- w6 |> select(id, all_of(paste0(six, "_t2")))
stopifnot(nrow(d1) == nrow(d2), identical(d1$id, d2$id))
X <- as.matrix(d1[, -1]); Y <- as.matrix(d2[, -1])   # 去掉 id，得到 CLPN 用的两个矩阵

要点：rep(six, 3) 把 6 个题名重复 3 次，rep(1:3, each = 6) 生成 1,1,1,1,1,1,2,…；paste0() 把它们拼成 18 个列名。检查三件事：长格式行数 = 800 × 3；转回后与原数据相同；d1、d2 行数相同且 ID 完全一致。

练习 4.2-B：长格式画均值图

用长格式数据 long，计算每一波 9 道题各自的均值，并用 ggplot 画出 9 条“均值随波次变化”的折线（横轴 wave，纵轴均值，颜色区分题目）。提示：先 pivot_longer() 一次把题目也拉长。

参考代码 
long |>
  pivot_longer(lone1:dep5, names_to = "item", values_to = "score") |>
  group_by(wave, item) |>
  summarise(m = mean(score), .groups = "drop") |>
  ggplot(aes(x = wave, y = m, colour = item, group = item)) +
  geom_line() + geom_point() +
  labs(x = "波次", y = "题目均值")

你会看到 9 条几乎水平的线：孤独题均值约 2.2（1–4 分），抑郁题约 0.75（0–3 分）。平均水平稳定，但这不代表个人没有变化（4.1 课的意大利面图）。group = item 告诉 ggplot 按题目把点连成线。

小结带走三句话

  • 宽格式每人一行（lavaan、CLPN 用），长格式每人每波一行（多层模型、轨迹图用）；pivot_longer() / pivot_wider() 互转。
  • 统一的 题目_t波次 命名让整形和选列可以自动化；用明确的列名清单比模式匹配更安全。
  • 合并按 ID（left_join），拆分后检查行数、ID、题目顺序；错位不会报错，但会毁掉结果。下一课：4.3 缺失数据与样本流失。
