安装包、导入数据与项目管理

课文学习 1 小时 30 分钟先修：2.3 数据框与 tidyverse 入门配套脚本：R/L2-4.R

本课学习目标

  1. 区分 install.packages()（安装一次）与 library()（每次加载）

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉工具箱、书架和“找得到的文件”

“在我电脑上明明能运行！”

小林把分析脚本发给合作者，对方一运行就报错：cannot open file 'C:/Users/小林/Desktop/论文/数据最终版2.csv': No such file or directory。对方的电脑上当然没有“小林的桌面”。接着又报错：there is no package called 'qgraph'，因为对方没装这个包。本课解决这两件事：包从哪里来、怎么加载；文件放在哪里、怎么让别人的电脑也能找到。

包：给 R 添加新工具

R 安装后自带的函数（如 mean()、lm()）只是基础工具。别人编写好的额外工具打包成包（package），放在 CRAN（Comprehensive R Archive Network）（R 的官方包仓库）上供免费下载。CLPN 需要的 glmnet（LASSO）、qgraph（画网络）、bootnet（稳定性分析）都是包。

类比：买书 vs 把书从书架上拿下来

install.packages("qgraph") 是买书：从 CRAN 下载并装到你的电脑上，每台电脑只需做一次。例外是升级 R：包按 R 的“主版本.次版本”分开存放，所以不只是大版本（4.x → 5.0），次版本升级（如 4.4 → 4.5）后也要重装包；只有补丁版本升级（如 4.5.0 → 4.5.1）可以继续用原来的包。library(qgraph) 是把书从书架上拿到桌面：每次打开 R（每个新会话），想用这本书里的函数，都要先拿下来一次。所以包装好了，下次打开 R 仍要 library()。两种报错也由此区分：there is no package called 'bootnet' 表示还没买（没安装），运行 install.packages("bootnet")；could not find function "cv.glmnet" 往往表示书在书架上却没拿下来（装了但没有 library(glmnet)）。

  • install.packages() 里的包名要加引号；library() 里一般不加。
  • 不要把 install.packages() 写进每次都要运行的分析脚本（每次都会重新下载）。课程脚本用“只安装缺少的”写法（见 R 代码）。
  • 只想用一次某个函数而不加载整个包，可以写 包名::函数名，例如 psych::describe(dat)。这也能避免两个包有同名函数时的混淆（例如 dplyr::filter() 与 stats::filter()）。
  • 加载包时出现的红色文字不一定是报错：很多包会打印启动信息或“某某函数被遮蔽（masked）”的提示。真正的错误以 Error 开头。

工作目录与路径：R 在哪里找文件？

R 读写文件时，从一个“当前所在的文件夹”出发，叫工作目录（working directory），用 getwd() 查看。

  • 绝对路径：从磁盘根部写起，例如 C:/Users/小林/Desktop/论文/data.csv。只在你自己的电脑上有效。
  • 相对路径（relative path）：从工作目录写起，例如 data/clpn_sim_wide.csv（“工作目录下的 data 文件夹里的这个文件”）。只要别人的工作目录也是项目文件夹，就能找到。

Windows 的路径用反斜杠 \，但在 R 字符串里 \ 是转义符，所以要写成正斜杠 / 或双反斜杠 \\。

为什么不建议写 setwd("C:/Users/...")？

setwd() 用绝对路径改变工作目录：换一台电脑、换一个用户名、把文件夹挪个位置，脚本就失效了；而且它依赖于你个人电脑的目录结构，别人无法复现。更好的方法是使用 RStudio 项目。

RStudio 项目：一个文件夹 = 一个分析

项目（RStudio Project）就是一个带有 .Rproj 文件的文件夹。双击 .Rproj 打开 RStudio 时，工作目录会自动设为这个文件夹，于是所有相对路径都能直接使用。本课程文件夹里已经有 clpn-course.Rproj。新建项目：File → New Project → New Directory（或 Existing Directory）。

推荐的文件夹结构（也就是本课程文件夹 clpn-course/ 的结构，只列出与 R 有关的部分；解压 clpn-course.zip 后就是这样）：

clpn-course/
├── clpn-course.Rproj     ← 双击它打开项目
├── data/                 ← 原始数据（只读，永远不要手动修改）
└── R/                    ← 分析脚本（本课程：R/L2-4.R 等）
    ├── solutions/        ← 练习解答
    └── output/           ← 脚本生成的结果、图、日志

原则：原始数据只读；所有清理、计算都在脚本里完成，结果写到 output/。这样任何人拿到整个文件夹，打开 .Rproj，按编号运行脚本，都能从原始数据重现全部结果（9.3 课“可被复核的报告”以此为基础）。你自己做项目时，照这个结构新建一个 RStudio 项目即可。

每个课程脚本的第一行都是 source("R/_setup.R")。这是一个相对路径，所以它本身要求工作目录已经是 clpn-course 文件夹；通过 clpn-course.Rproj 打开 RStudio 就能保证这一点。_setup.R 载入后会再确认一次：先检查当前工作目录，再逐级往上找（最多往上 3 级，即共检查 4 个文件夹）含有 data/clpn_sim_wide.csv 的文件夹，找到就把它设为工作目录（并在 R/output/ 存放结果）；找不到就停下并报错。

如果看到 cannot open file 'R/_setup.R' 或“找不到课程文件夹”：先在 Console 运行 getwd() 看看当前在哪里；然后关掉 RStudio，双击 clpn-course.Rproj 重新打开（或用菜单 Session → Set Working Directory → Choose Directory… 选中 clpn-course 文件夹）；同时检查打开的是解压后的 clpn-course 文件夹，data/clpn_sim_wide.csv 是否存在。

导入不同格式的数据

格式包与函数注意
CSV（逗号分隔文本）readr：read_csv()；基础 R：read.csv()最通用，推荐；注意文件编码
Excel（.xlsx / .xls）readxl：read_excel("文件", sheet = 1)合并单元格、多行表头、颜色标注都会造成问题；最好整理成“一行一人、第一行是变量名”
SPSS（.sav）haven：read_sav()会保留变量标签和值标签（如 1 = 女），用 as_factor() 转为因子
Stata（.dta）、SAShaven：read_dta()、read_sas()

导入后第一件事是检查。glimpse() 或 str() 看行数、列数、每列类型；summary() 看范围是否合理（0–3 分的题出现 9 可能是“缺失”代码，需要改为 NA）；head() 看前几行。

中文乱码：编码问题

计算机用编码（encoding, UTF-8）规则把文字存成数字。国际通用的是 UTF-8；而中文 Windows 上的 Excel 另存 CSV 时，常常使用 GBK（也叫 GB2312 / CP936）编码。用 UTF-8 去读 GBK 文件，中文就会变成乱码（例如“鐢锋€�”），有时还会报错 invalid multibyte string。解决办法：

  • 读入时指明编码：read_csv("文件.csv", locale = locale(encoding = "GBK"))，或 read.csv("文件.csv", fileEncoding = "GBK")。
  • 在 Excel 中另存为“CSV UTF-8（逗号分隔）”格式。
  • RStudio 中脚本本身也要用 UTF-8 保存（File → Save with Encoding → UTF-8），否则脚本里的中文注释和标签会乱码。长期的做法是数据和脚本一律存成 UTF-8。
社会工作情境：从问卷星到 R

很多社工研究用问卷星、腾讯问卷等平台收集数据，导出的 Excel / CSV 常有中文列名、选项文字（“非常同意”而不是 4）和合计行。好习惯：(1) 原始导出文件原样放进 data/；(2) 在脚本中重命名列（如 lone1_t1）、把文字选项重编码为数字；(3) 写一份数据字典（课程的 data/data_dictionary.csv 就是例子），记录每个变量的含义和取值。

② 最少数学本课无新公式

本课是“工程”课，没有新的统计公式。只需记住一个“等式”：

$$\text{可复现的结果} = \text{原始数据} + \text{脚本} + \text{软件版本}$$

三者都确定，任何人都能得到相同结果。软件版本可以用 sessionInfo() 或 packageVersion("glmnet") 记录；结果涉及随机过程（交叉验证、bootstrap）时，还要用 set.seed() 固定随机种子（3.5 课）。

na = c("", "NA", "999") 告诉 R：空格子、"NA" 和 999 都当作缺失值。很多问卷平台和 SPSS 文件用 999、99 或 −9 表示“未作答”，不处理的话它们会被当成真实分数，拉高均值，扭曲相关和网络边。

完整例题：导入一份新数据后的“五步体检”

假设合作机构发给你一份 survey.csv。不要急着跑模型，先做下面五步，每一步都能抓出一类常见问题：

d <- read.csv("data/survey.csv")      # 1. 导入（路径相对于项目根目录）
dim(d)                                  # 2. 行数 = 人数？列数 = 问卷题数 + 人口学变量？
str(d)                                  # 3. 每列类型对吗？题目分应为 int/num，不应是 chr
summary(d)                              # 4. 范围对吗？1–4 分的题出现 9、99、-9 吗？
colSums(is.na(d))                       # 5. 每列缺失多少？
# 若用 99 / -9 表示缺失，只在题目列里改成 NA（不要对整张表替换：0–100 分的变量里 99 可能是真实分数）
item_cols <- grep("^(lone|dep)", names(d), value = TRUE)
for (v in item_cols) d[[v]][d[[v]] %in% c(99, -9)] <- NA

替换时只动题目列：像生活满意度这样 0–100 分的变量，99 可能是真实回答，要按问卷的编码手册逐列处理。

SPSS 值标签的进一步处理

带值标签的 .sav 文件用 read_sav() 读入后，相应的列是 haven_labelled 类型，打印时显示 “1 [从不]” 之类的标签。做统计计算前，通常用 haven::zap_labels() 去掉标签、只保留数值；分类变量用 haven::as_factor() 转为因子。另外要检查 SPSS 中定义的“用户缺失值”（如 99）是否已经转成 NA。

脚本开头的固定结构

本课程每个脚本都以相同的方式开头：先用注释写明脚本的用途和对应的课，再 source("R/_setup.R") 做共用的准备工作（找到课程根目录、建好 R/output 文件夹、设置中文字体、定义 read_course_data() 等共用函数），接着用 library() 加载本脚本要用的包，然后读入数据。你自己的脚本也建议固定这个顺序：用途注释 → 加载包 → 读数据 → 分析 → 保存输出。这样任何人打开脚本，都能在前 10 行内知道它依赖什么、读的是哪份数据。

④ 理解检查即时测验

为什么不建议在脚本里写 setwd("C:/Users/...")？

  • 读取速度没有区别；问题在于绝对路径只在你自己的电脑上存在。
  • 正确。
  • setwd() 只影响当前会话；真正的问题是这个路径换一台电脑就不存在。
用 RStudio 项目 + 相对路径代替。

包装好后，为什么下次打开 R 还要 library()？

  • 正确。
  • 包仍在电脑上，不用重装；新会话只是还没有把它加载进来。
  • 装好的包仍要用 library() 加载，或用 包名::函数名 调用其中的函数。
install.packages() 一次；library() 每个会话一次。

导入中文数据出现乱码时，可能是什么原因？

  • 缺失值会读成 NA 或空字符串，不会让中文变成乱码。
  • 正确：用 locale(encoding = "GBK") 或另存为 UTF-8。
  • R 支持中文；同一份文件按正确的编码读入就能正常显示。
中文 Windows 版 Excel 另存的 CSV 常为 GBK 编码。

工作目录是 /home/learner/clpn-course。相对路径 "data/clpn_sim_wide.csv" 指向哪里？

  • 相对路径从工作目录出发，不是从根目录。
  • 正确。
  • R 不会去桌面找；相对路径总是从工作目录出发。
相对路径 = 工作目录 + 相对部分。

导入后发现 dep1_t1（应为 0–3 分）的最大值是 999。最可能是什么？如何处理？

  • 0–3 分的题不可能得 999。
  • 正确。
  • R 读入时不会改动数值；999 是问卷平台或 SPSS 用来表示“未作答”的编码约定。
导入后先用 summary() 检查每个变量的范围。

install.packages(qgraph) 报错 object 'qgraph' not found。怎么改？

安装时包名是一个字符串。
没有引号时，R 以为 qgraph 是一个对象并去找它。

练习 2.4-B：找出路径问题

下面这段代码在合作者的电脑上失败了。指出两个问题并改正：

setwd("C:\Users\小林\Desktop\论文")
install.packages("glmnet")
dat <- read.csv("数据最终版2.csv")
fit <- cv.glmnet(X, y)
参考答案

(1) setwd() 绝对路径（而且反斜杠没有转义，这一行本身就会报错）→ 删掉，改用 RStudio 项目；数据放进 data/，写 read.csv("data/survey_final.csv")（文件名最好用英文）。(2) 每次都运行 install.packages() 不必要，却漏了 library(glmnet)，cv.glmnet 会报 could not find function → 安装命令移到单独的安装脚本，这里写 library(glmnet)。另外 X、y 没有定义。

小结带走三句话

  • install.packages("包") 每台电脑一次，library(包) 每个会话一次。
  • 用 RStudio 项目 + 相对路径，不写 setwd("C:/...")；原始数据只读，结果由脚本生成。
  • 导入后先检查类型、范围和缺失代码；乱码多半是编码（GBK vs UTF-8）问题。下一课：2.5 用 R 做描述统计、相关与回归。
