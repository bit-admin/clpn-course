模块 10 · Capstone Mini-Project · 第 10.3 课

撰写结果部分并进行汇报

课文学习 3 小时先修：10.2 完整分析：估计、可视化、中心性与稳定性配套脚本：R/L10-3.R

本课学习目标

  1. 按 APA 风格写出 800–1200 字的“方法（分析部分）+ 结果”，并列报告主分析与完整流程敏感性分析的结果
  2. 写一段诚实的局限性讨论（被试内/被试间、因果、样本、测量）
  3. 用 10 分钟讲清楚自己的分析，并能回答读者或审稿人可能提出的质疑

核心概念

  • 结果部分results section
  • 局限性limitations
  • 学术汇报academic presentation
  • 实务意义practice implications

最后一步：把分析变成别人能读懂、能检验的文字，并用 10 分钟讲清楚。本课提供一个结果部分模板（自动填数）、一份局限性写作指南和一份汇报清单。

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉先建立画面

原则：每个数字都能在代码输出中找到

结果部分最常见的错误是“抄错数”：表格改过一版，正文还停在旧版本。最好的办法是让代码来填数字。R/L10-3.R 读取 L10-2 保存的结果（L10-2_results.rds），自动生成一份结果草稿 R/output/L10-3_results_draft.md（见下方实际输出）。你在草稿基础上改写语言，但不手动改数字；数字一变，就重新运行脚本。

结果部分（results section）的结构（APA 风格）

  1. 网络结构：边数（占可能边数的比例）、自回归范围、最强的几条交叉滞后边、两个方向的边权和。
  2. 中心性：out-EI / in-EI / 桥接 EI 最高的节点（指出表与图）。
  3. 准确性与稳定性：bootstrap 区间的总体情况、CS 系数和判断标准。
  4. 敏感性：替代分析与主分析的一致程度，以及主要结论是否改变。
  5. 完整流程敏感性分析：模型选择（等值检验、AIC、BIC）、修剪后保留的边、与主分析的逐边一致程度（见下文“怎样写两种分析”）。

结果部分只陈述发现，不展开解释；解释、与文献比较、局限和实务意义放在讨论部分。

结果部分模板（填空生成）

输入框里的灰色提示就是课程数据的实际结果（来自 L10-2 / L10-3 输出），你可以照着填；如果用自己的数据，换成你的数字即可。

填完以后必须改的两处

① 课程数据中 out-EI 的 CS = 0.20 < 0.25，所以“出期望影响最高的节点为‘无人理解’”这一句后面要加上“但该指标稳定性不足，此排序不予解释”。② 避免“影响”“导致”等因果动词：“A → B 的边”应写成“T1 的 A 预测 T2 的 B”。

怎样写两种分析：方法、结果与讨论

主分析（仅 LASSO）和必做的敏感性分析（完整流程，10.2 课）要在三个地方各出现一次，分工不同：方法部分说清两种分析各自怎么做、怎样判读；结果部分并列陈述两种结果；讨论部分解释一致与不一致的含义。

方法部分（分析部分）的写法

两种分析的设置都要写到别人能照着重做的程度（9.3 课）。可以参考下面这段，把括号里的内容换成你的设置：

“主分析采用仅 LASSO 的交叉滞后面板网络：以 T2 的每个题目为结果、T1 的全部 9 个题目为预测变量，分别做 LASSO 回归（glmnet，10 折交叉验证，lambda.min，随机种子 2026），题目事先 z 标准化，非零系数构成网络的边。按分析计划，另以 Wysocki 等人（2025）推荐的完整流程作为敏感性分析：对 T1→T2 与 T2→T3 分别做同样的 LASSO，两段都为 0 的交叉滞后路径固定为 0，其余交叉滞后路径与全部自回归路径在 lavaan（版本号）中做无惩罚的路径模型估计；同一波内的残差两两相关，缺失值用 FIML 处理。用嵌套 χ² 检验和 AIC、BIC 比较跨时间等值约束模型与不约束模型，三者都不反对等值时采用约束模型。最终模型中 p < .01 的交叉滞后路径视为保留，并计算各节点的 in-prediction 与 out-prediction。两种分析都保留的边作为主要发现，只在一种分析中出现的边作为探索性发现。”

注意最后一句：判读规则也是方法的一部分，要写在方法里，而不是等到讨论时才提出来。

结果部分的写法

完整流程单独成段，放在其他敏感性分析之后。R/L10-3.R 自动生成的草稿（本页下方“实际输出”中的 L10-3_results_draft.md）已经包含这一段，按顺序交代五件事：

  1. 做了什么（一句话回顾设置，细节在方法部分）；
  2. 模型选择：等值检验的 Δχ²、自由度、p 值，AIC 与 BIC 的方向，最终采用哪个模型及其拟合指标；
  3. 修剪后保留了几条交叉滞后边，按方向分别是几条；
  4. 与主分析的一致程度：主分析的边有几条保留，最强的几条中哪些没有保留（给出两种估计值和 p 值）；
  5. 构念层面：两个方向的边权和在两种分析中各是多少。

课程数据上，这一段的核心数字是：进入 SEM 的交叉滞后路径 67 条；等值检验 Δχ²(76) = 84.69，p = 0.232，采用约束模型；修剪后保留 16 条；主分析最强的 10 条边中保留 8 条。结果部分只陈述这些，不解释“为什么”。

讨论部分的写法

情形结果部分讨论部分
两种分析都保留列出这些边及两种估计值作为主要发现解释；说明它们不依赖估计方法。效应大小引用无惩罚估计
只在主分析中非零说明它们在完整流程中未保留（给出 p 值）写成“对估计方法敏感”，只作探索性解释；不作为实务建议的依据。若它只在一段数据中出现，指出这一点
只在完整流程中保留说明它们在主分析中为 0同样只作探索性报告；说明它来自两段数据的合并
构念层面的方向两个方向的边权和，两种分析各一组方向一致时可以写进摘要；不一致时只能说“方向依赖于估计方法”

课程数据的一段讨论可以这样写（数字来自 L10-2b 的输出）：

“两种估计方法得到的网络整体相似（72 个交叉滞后位置上的系数相关 r = 0.842），但完整流程保留的边少得多（16 条，主分析为 52 条）。两种分析都保留的孤独 → 抑郁边有“缺少陪伴 → 兴趣丧失”（0.114）、“与人隔绝 → 情绪低落”（0.095）、“无人理解 → 无价值感”（0.094）；抑郁 → 孤独边有“疲乏 → 被冷落”（−0.117）、“兴趣丧失 → 与人隔绝”（0.079）。主分析中较强的‘无人理解 → 疲乏’在完整流程中没有保留：它只在 T1→T2 一段中出现，T2→T3 段的 LASSO 估计为 0.000，两段合并后不显著（p = 0.264）。因此，本研究不把它作为孤独通向抑郁的主要途径。两种分析中，孤独 → 抑郁方向的边权和都大于反方向，这一构念层面的模式不依赖估计方法。”
写两种分析时的常见错误
  • 只在一致时才提完整流程。它是必做的，不一致时更要写。
  • 写“完整流程证实了……”。敏感性分析只能说明结果是否依赖估计方法，不能“证实”一条边，更不能证明因果。
  • 数字张冠李戴。p 值和标准误只来自完整流程（LASSO 不给 p 值）；CS 系数和 bootstrap 区间只来自主分析。每个数字都要说清来自哪一种分析。
  • 把两种分析的系数混在一张排序表里。LASSO 系数被收缩，无惩罚估计没有，两者不能放在一起比大小。
  • 以为两种分析一致就没有局限了。两种分析都基于观测得分，都混合了被试间与被试内效应（10.2 课“两种分析一致，也不等于被试内过程”）。

局限性（limitations）

局限性告诉读者结果可以推广到哪里、不能推广到哪里。CLPN 研究至少要讨论以下五点：

方面要说什么可参考的写法
被试间 / 被试内标准 CLPN 基于观测得分，混合了稳定的个体差异与被试内变化（5.2–5.3 课）“本研究的交叉滞后边可能部分反映了被试间的稳定差异，而非被试内的动态过程；未来研究可采用分离被试间效应的模型（如 RI-CLPM 的网络扩展）。”
因果边是时间上的预测关系，可能受未测量的第三变量影响“交叉滞后边不能解释为因果效应。”
测量单题信度较低；题目内容可能重叠；测量间隔可能不是过程发生的最佳时间尺度（5.4 课）“每个节点由单个题目测量……6 个月的间隔可能……”
估计方法主分析的 LASSO 系数被收缩、含假阳性；完整流程更保守，会漏掉弱边；两者都基于观测得分“主分析的部分边在完整流程中未能保留，这些边的解释是探索性的；完整流程在 p < .01 下可能漏掉较弱的真实边。”
样本样本来源、代表性、流失“样本来自……，结论能否推广到……尚待检验。”

如果你用的是模拟数据，还可以说明：“由于真实结构已知，本研究评估了方法表现：估计边与真实边的相关为 0.65，提示……”

实务意义（practice implications）：怎样对社工同事说

想象你要向一位没学过统计的社工同事解释主要发现。可以这样说：

“我们追踪了 800 人半年。孤独感较强的人，半年后的抑郁症状往往也多一些；反过来，抑郁对之后孤独感的预测要弱得多（这个差别经过了 bootstrap 检验，8.3 课练习 1）。至于具体是哪一种孤独感起作用，这次的数据说不准：排在前面的几道题换一批人就可能变。而且这只是预测关系，不能证明减轻孤独以后抑郁就会减轻。如果要设计小组，可以把减轻孤独整体作为目标来试一试，并评估效果。”

这段话有三个要素：发现（用日常语言）、限度（非因果、单题排序不稳定）、可检验的行动建议。

为什么不推荐“以‘被理解’为重点”

样本里“无人理解”的 out-EI 和桥接出 EI 都最高，“无人理解 → 疲乏”也是最强的边之一，很容易写成“应优先帮助服务对象感到被理解”。但 out-EI 的 CS 只有 0.20，排序不能解释；而对照课程数据的两种真值（10.2 课“与真实结构逐条对照”），“无人理解 → 疲乏”在总体中只有 0.005，两种真值中最强的孤独 → 抑郁边是“与人隔绝 → 情绪低落”（0.118）。必做的完整流程敏感性分析也没有保留这条边（10.2 课：SEM 重估 0.031，p = 0.264）。如果按样本里最亮眼的那道题设计干预，就会选错重点。实务建议只能建立在稳定、整体、而且两种分析一致的模式上。

学术汇报（academic presentation）：10 分钟

读者或审稿人可能的提问（准备你的答案）

“为什么不用 RI-CLPM？”

参考回答：RI-CLPM 能分离被试间与被试内效应，但目前主要用于少数几个变量（总分）；CLPN 的优势在于题目层面的网络结构。两者回答的问题不同。我在局限中说明了 CLPN 混合了被试间与被试内效应。

“CS = 0.20 意味着什么？”

意味着只要删掉一小部分被试，out-EI 的排序就可能明显改变，因此我不解释 out-EI 排序，只报告数值。

“Wysocki 等人推荐完整流程，你为什么还用仅 LASSO 作主分析？”

参考回答：为了与已发表的 CLPN 研究直接对照，也为了做边权 bootstrap 和 CS 系数，这两项都建立在 LASSO 估计之上。完整流程在分析计划中列为必做的敏感性分析，结果并列报告；主要发现只取两种分析都保留的边。

“两种分析不一致时，你信哪一个？”

参考回答：两个都不“信”到底。LASSO 偏向多报，完整流程偏向少报。按事先写好的规则，两者都保留的边是主要发现；只在一种分析中出现的边，我写成“对估计方法敏感”，只作探索性解释。课程数据是模拟的，可以看到这条规则的代价：完整流程漏掉了不少弱的真实边。

“这能说明因果吗？”

不能。交叉滞后边是控制 T1 所有题目后的时间预测关系，仍可能受未测量变量或被试间差异影响。

“如果再做一次研究，你会改变什么？”

例如：增加波次，让分离被试内效应的模型（RI-CLPM 及其网络扩展）估计得更稳定（3 波时 RI-CLPM 刚好可以识别，但估计很不精确，见 5.3 课）；根据过程的时间尺度选择更合适的间隔；用多题目测量关键节点；预注册；扩大样本以提高中心性稳定性。

② 最少数学把直觉写成式子

结果部分要报告的几个汇总数，都可以从估计矩阵 \(\hat B\) 直接算出来。

\[\text{密度}=\frac{E}{p(p-1)}=\frac{52}{72}\approx 0.72\]
符号读法 / 含义
\(E\)非零交叉滞后边数
\(p\)节点数，\(p(p-1)\) 为可能的交叉滞后边数

密度 0.72 很高，这是 lambda.min 的典型表现（偏向保留边，包括一些假阳性；7.2 课）。在结果中报告密度，可以提醒读者网络有多“稠密”。

\[S_{L\to D}=\sum_{k\in L}\sum_{j\in D}\hat\beta_{kj}=0.56,\qquad S_{D\to L}=\sum_{k\in D}\sum_{j\in L}\hat\beta_{kj}=0.08\]
符号读法 / 含义
\(L,\ D\)孤独题目集合（lone1–4）与抑郁题目集合（dep1–5）
\(S_{L\to D}\)所有从孤独指向抑郁的交叉滞后边的权重之和

注意：两个方向的非零边数可能不同，但可能的边都是 4 × 5 = 20 条，所以两个总和可以直接比较。不过它们只是描述性的汇总，本身没有显著性检验；要说“孤独→抑郁方向更强”，需要检验这一差值在 bootstrap 中的分布（8.3 课练习 1 用 L8-2_boot.rds 做了这一检验）。

APA 数字格式

小数点前是否写 0、保留几位小数，按 9.3 课“报告精度”的规则，全文保持一致。

“交叉滞后网络中共有 52 条非零交叉滞后边〔L10-2_log；或 table2 的 61 行减去 9 条自回归〕。最强的交叉滞后边为 T1 睡眠问题 → T2 疲乏（β = 0.135）和 T1 被冷落 → T2 无人理解（β = 0.127）〔table2〕。跨构念方面，T1‘无人理解’对 T2 抑郁症状的预测最强（桥接出 EI = 0.347），其中 T1 无人理解 → T2 疲乏为 0.108〔table3、table2〕。在构念层面，孤独 → 抑郁的边权之和为 0.557，而抑郁 → 孤独为 0.079〔L7-4_log〕。入 EI 的 CS 系数为 0.52，出 EI 为 0.20〔table5〕，因此……”

最后一句怎样写，取决于 CS 是否达到 0.25：达到时可以描述排序；没达到时，就写“出 EI 的排序不够稳定，下文不作解释”。不要因为结论好看就省略这一句。

10 分钟汇报的结构

汇报和论文的顺序相同，但比例不同：问题与意义 1.5 分钟（为什么社工要关心孤独与抑郁的关系）；数据与方法 2 分钟（只讲 N、波数、间隔、估计方法和稳定性检验）；结果 4 分钟（一张网络图、一张中心性图，再加一句稳定性结论）；局限与意义 2 分钟（稳定特质、因果、样本代表性，以及对实务的谨慎启示）；留 0.5 分钟作为缓冲。每张幻灯片只讲一个信息，标题直接写结论，而且只写数据支持的那一层，如“孤独 → 抑郁方向的边权和较大（0.56 对 0.08，未做差异检验）”，而不是“结果 2”；如果你用 bootstrap 检验了这个差值，才可以写成“……显著大于反方向”。

撰写与汇报中的常见错误
  • 结果部分混入讨论。结果只写“发现了什么”，“这意味着什么”留到讨论部分。
  • 汇报时把整张 9 × 9 矩阵放上幻灯片。听众看不清。只放图和最重要的 3–5 个数字，完整表格留给提问环节或补充材料。
  • 回避局限。主动讲出稳定特质和因果推断的局限，比被听众问出来要好得多。

  • 完整流程敏感性分析：方法里写清两种分析的设置和判读规则；结果里单独成段；讨论里主要发现只取两种分析都保留的边。
  • 局限：被试间/内混合、非因果、测量与间隔、估计方法、样本与流失。
  • 实务表述：日常语言的发现 + 限度 + 可检验的行动建议；10 分钟汇报每张幻灯片一个要点。
