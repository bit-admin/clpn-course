模块 5 · Cross-Lagged Panel Models · 第 5.3 课

RI-CLPM：把“稳定的个人特质”与“被试内变化”分开

课文学习 2 小时先修：5.2 用 lavaan 拟合 CLPM 并评估模型拟合配套脚本：R/L5-3.R

本课学习目标

  1. 理解 Hamaker, Kuiper & Grasman (2015) 的核心批评：CLPM 混淆了被试间与被试内效应
  2. 理解随机截距（random intercept）代表稳定的、类特质的个体差异
  3. 比较 CLPM 与 RI-CLPM 结果，并解释差异
  4. 知道 RI-CLPM 至少需要 3 波数据

核心概念

  • 随机截距交叉滞后面板模型random-intercept CLPM, RI-CLPM
  • 随机截距random intercept
  • 类特质稳定性trait-like stability
  • 被试内效应within-person effect
  • 被试间效应between-person effect
  • 中心化centering

这一课区分被试间与被试内两类问题，并介绍能把两者分开的 RI-CLPM。CLPN 论文的局限部分需要讨论这一点，审稿人也常问：“你的结果是被试间还是被试内？”

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉先建立画面

两个听起来很像、其实完全不同的问题

  • 被试间（between-person）问题：“比别人更孤独的人，是否也比别人更抑郁？”比较的是不同的人。
  • 被试内（within-person）问题：“当一个人比他自己平时更孤独时，他之后是否会比自己平时更抑郁？”比较的是同一个人在不同时间。

社工干预真正关心的往往是第二个问题：如果我们帮助某位居民减少孤独（相对于他自己），他的抑郁会不会随之改善？但 CLPM 的系数混合了这两种信息。

下面的演示中，12 个人、每人 6 次测量。你可以分别设定“被试间”与“被试内”的相关。默认设置是：孤独特质高的人抑郁特质也高（ρB = 0.7），但对同一个人来说，孤独比平时高的时候抑郁反而略低（ρW = −0.4）。切换三种视图看看。

你会发现：把所有点混在一起算出的相关，主要由“人与人之间的差异”决定，和“每个人内部的关系”可能方向相反。这种现象在统计学中与辛普森悖论（Simpson's paradox）和生态谬误（ecological fallacy）同源。

Hamaker 等人（2015）的批评

Hamaker、Kuiper 和 Grasman 指出：许多心理特征都有 类特质稳定性（trait-like stability）：有些人就是长期比别人更孤独。CLPM 的自回归路径会把这种“稳定的个体差异”当成“从 T1 到 T2 的延续”，于是：

  1. 自回归被高估（看起来很稳定，其实是“人不同”而不是“状态延续”）；
  2. 交叉滞后可能被高估、低估，甚至方向相反，因为它掺杂了“特质之间的相关”；
  3. 研究者以为得到了被试内的动态过程，其实很大部分是被试间差异。

RI-CLPM 的解决办法：给每个人一个“个人基线”

随机截距交叉滞后面板模型（random-intercept CLPM, RI-CLPM） 把每个观测分数拆成两部分：

分解：

观测分数 = 总体均值 + 个人稳定的偏离（随机截距（random intercept），跨时间不变）+ 这一次相对于个人基线的偏离（被试内成分（within-person component），随时间变化）

然后自回归和交叉滞后只放在“被试内成分”之间。于是交叉滞后的含义变成：某人在 T1 比他自己平时更孤独，他在 T2 是否比他自己平时更抑郁。这才是更接近“过程”的问题。两个随机截距之间的相关，则单独表示被试间关系（“长期孤独的人也长期抑郁”）。

这张表说明：
  1. 自回归变小是对的。被试内自回归的大样本值是 0.332，而 CLPM 在样本无限大时也会给出 0.605：CLPM 的“稳定性”确实被稳定特质抬高了。
  2. 真实的方向和 CLPM 一样，课程样本却把两个方向都估大了。被试内的大样本值是孤独 → 抑郁约 0.093、抑郁 → 孤独约 0.012，与 CLPM 的方向一致（孤独 → 抑郁更强）。课程样本的“孤独 T1 → 抑郁 T2 = 0.265”比 200 份重复样本的估计都大，“抑郁 T2 → 孤独 T3 = 0.245”也比 200 份重复样本的估计都大；同时随机截距相关 0.200 在 200 份重复样本中只有 1 份不比它大。这几个数是一起偏的：随机截距少吸收了一部分孤独与抑郁之间的被试间关联，这部分关联就转到了被试内交叉滞后上。课程数据恰好是一份不太典型的样本。
  3. 3 波、N = 800 时，RI-CLPM 的被试内交叉滞后很不精确。一份样本的估计可以落在上表第四列那么宽的范围里，只看点估计比较两个方向，很容易得出相反的结论。

所以 RI-CLPM 的价值在于去掉被试间混杂，代价是精度。报告时一定要给出置信区间；要比较两个方向，应检验它们的差值，而不是比较两个点估计。

对 CLPN 的直接含义：

CLPN（无论是本课程主线的“仅 LASSO”简化版，还是 Wysocki 等人 2025 年的完整流程）用的都是观测题目分数，没有随机截距，所以和 CLPM 一样混合了被试间与被试内信息。课程数据中，data/true_B_within.csv（被试内真值：生成数据时用的被试内结构）与 data/true_B_population.csv（总体目标值：CLPN 在无限大样本中会收敛到的答案）明显不同，后者多了许多由稳定特质造成的小正边。7.2 课起两者会并列出现，7.5 课专门讨论。

RI-CLPM 的条件与局限

  • 至少需要 3 波数据：2 波时无法把“稳定部分”和“变化部分”分开（模型不可识别）。
  • 它假设特质部分跨时间完全不变；若存在长期趋势，可能需要更复杂的模型（例如加入随机斜率或线性趋势；Mulder 和 Hamaker（2021）讨论的三种扩展则是加入不随时间变化的预测变量与结果变量、多组比较和多指标模型）。
  • 它仍然只是“被试内的时间预测”，不能自动变成因果（5.4 课）。

常见问题与误区

CLPM 不是已经用自回归控制了 T1 吗，为什么稳定特质还会漏进交叉滞后？

因为 CLPM 控制的是 T1 的观测分数，而观测分数 = 稳定特质 + 这一次的状态（再加测量误差）。控制一个只部分反映特质的分数，只能吸收特质的一部分，就像用一道有噪声的题目去“控制”一个构念。剩下没被吸收的特质部分仍然同时影响 T2 的孤独和 T2 的抑郁；如果孤独特质与抑郁特质相关，T1 孤独就会借着这条通道预测 T2 抑郁，表现为一条交叉滞后路径。状态成分占观测分数的比例越大、特质之间的相关越强，漏进来的就越多。RI-CLPM 的随机截距把特质单独建模，交叉滞后只放在被试内成分之间，这个通道就被切断了（前提是特质跨时间不变）。

② 最少数学把直觉写成式子

以孤独为例，对个体 \(i\) 在时间 \(t\) 的观测分数：

\[\text{孤独}_{it} = \mu_t + \kappa_i + w_{it}\]
\[w^{L}_{i,t+1} = \alpha\, w^{L}_{it} + \gamma\, w^{D}_{it} + u^{L}_{i,t+1}\]
符号读法 / 含义
\(i,\ t\)下标：第 i 个人，第 t 次测量
\(\mu_t\)希腊字母 mu：第 t 波的总体均值（所有人的平均）
\(\kappa_i\)希腊字母 kappa：第 i 个人的随机截距 = 他稳定地高于/低于平均多少（跨时间不变）
\(w_{it}\)被试内成分：这一次相对于他自己基线的偏离（within）
\(w^{L},\ w^{D}\)上标 L = 孤独，D = 抑郁的被试内成分
\(\alpha\)alpha：被试内自回归（比自己平时更孤独的状态会延续多少）
\(\gamma\)gamma：被试内交叉滞后（比自己平时更抑郁 → 下一次比自己平时更孤独）
\(u_{i,t+1}\)被试内方程的残差（新冲击，innovation）

为什么 CLPM 会出偏差？一个两行推导

若忽略 \(\kappa_i\)，用 \(\text{孤独}_t\) 预测 \(\text{孤独}_{t+1}\)，两者的协方差为

\[\mathrm{Cov}(\text{孤独}_t,\text{孤独}_{t+1}) = \underbrace{\mathrm{Var}(\kappa)}_{\text{被试间}} + \underbrace{\mathrm{Cov}(w_t, w_{t+1})}_{\text{被试内}}\]

第一项与时间过程毫无关系，却被 CLPM 当成“稳定性”。同理，孤独与抑郁两个随机截距的协方差 \(\mathrm{Cov}(\kappa^L,\kappa^D)\) 会混入交叉滞后。RI-CLPM 通过把 \(\kappa\) 作为潜变量单独估计，把这两部分分开。

在 lavaan 中怎么实现：

随机截距 = 一个潜变量，它到三波观测分数的因子载荷全部固定为 1（RI_lone =~ 1*lone1 + 1*lone2 + 1*lone3）；每个观测分数再有一个被试内潜变量（载荷 1），观测变量自身的误差方差固定为 0。

③ R 代码在 R 中实现

R/L5-3.R 的核心部分（结构参照 Mulder & Hamaker 的 lavaan 示例）
riclpm <- '
  # 1) 随机截距：每个人稳定的“特质水平”，载荷固定为 1
  RI_lone =~ 1*lone1 + 1*lone2 + 1*lone3
  RI_dep  =~ 1*dep1  + 1*dep2  + 1*dep3
  # 2) 被试内成分
  wl1 =~ 1*lone1; wl2 =~ 1*lone2; wl3 =~ 1*lone3
  wd1 =~ 1*dep1;  wd2 =~ 1*dep2;  wd3 =~ 1*dep3
  # 3) 被试内自回归与交叉滞后
  wl2 ~ wl1 + wd1;  wd2 ~ wd1 + wl1
  wl3 ~ wl2 + wd2;  wd3 ~ wd2 + wl2
  # 4) 同期相关与（残差）方差
  wl1 ~~ wd1; wl2 ~~ wd2; wl3 ~~ wd3
  wl1 ~~ wl1; wd1 ~~ wd1; wl2 ~~ wl2; wd2 ~~ wd2; wl3 ~~ wl3; wd3 ~~ wd3
  RI_lone ~~ RI_lone; RI_dep ~~ RI_dep; RI_lone ~~ RI_dep
  # 5) 随机截距与 T1 被试内成分不相关；观测变量误差固定为 0
  RI_lone ~~ 0*wl1 + 0*wd1;  RI_dep ~~ 0*wl1 + 0*wd1
  lone1 ~~ 0*lone1; lone2 ~~ 0*lone2; lone3 ~~ 0*lone3
  dep1 ~~ 0*dep1;   dep2 ~~ 0*dep2;   dep3 ~~ 0*dep3
'
fit_ri <- lavaan(riclpm, data = wide, missing = "fiml",
                 meanstructure = TRUE, int.ov.free = TRUE)
summary(fit_ri, standardized = TRUE, fit.measures = TRUE)
anova(fit_c, fit_ri)    # 与 CLPM 比较（CLPM 嵌套在 RI-CLPM 中）

逐块理解：第 1 块定义两个随机截距；第 2 块给每个观测分数配一个被试内潜变量；第 3 块是我们关心的被试内动态；第 4 块是同期相关和方差；第 5 块是识别所需的固定约束。wide 与 fit_c 来自脚本前面部分（与 5.2 相同的总分与 CLPM）。

读结果时看什么：

（1）RI_lone ~~ RI_dep 的标准化值 = 被试间相关；（2）随机截距方差是否明显大于 0（若接近 0，RI-CLPM 与 CLPM 结论相近）；（3）wl2 ~ wd1 等被试内交叉滞后；（4）anova() 的模型比较。

  # 1) 随机截距（random intercepts）：每个人稳定的“特质水平”，因子载荷固定为 1
  RI_lone =~ 1*lone1 + 1*lone2 + 1*lone3
  RI_dep  =~ 1*dep1  + 1*dep2  + 1*dep3
  # 2) 被试内成分（within-person components）
  wl1 =~ 1*lone1; wl2 =~ 1*lone2; wl3 =~ 1*lone3
  wd1 =~ 1*dep1;  wd2 =~ 1*dep2;  wd3 =~ 1*dep3
  # 3) 被试内的自回归与交叉滞后
  wl2 ~ wl1 + wd1;  wd2 ~ wd1 + wl1
  wl3 ~ wl2 + wd2;  wd3 ~ wd2 + wl2
  # 4) 同期相关与（残差）方差
  wl1 ~~ wd1; wl2 ~~ wd2; wl3 ~~ wd3
  wl1 ~~ wl1; wd1 ~~ wd1; wl2 ~~ wl2; wd2 ~~ wd2; wl3 ~~ wl3; wd3 ~~ wd3
  RI_lone ~~ RI_lone; RI_dep ~~ RI_dep; RI_lone ~~ RI_dep
  # 5) 随机截距与 T1 被试内成分不相关；观测变量的测量误差固定为 0
  RI_lone ~~ 0*wl1 + 0*wd1;  RI_dep ~~ 0*wl1 + 0*wd1
  lone1 ~~ 0*lone1; lone2 ~~ 0*lone2; lone3 ~~ 0*lone3
  dep1 ~~ 0*dep1;   dep2 ~~ 0*dep2;   dep3 ~~ 0*dep3
'
fit_ri <- lavaan(riclpm, data = wide, missing = "fiml", meanstructure = TRUE, int.ov.free = TRUE)
print(summary(fit_ri, standardized = TRUE, fit.measures = TRUE))   # print()：用 source() 或 run_all.R 运行时也写进日志

         lone1 ~~ dep1; lone2 ~~ dep2; lone3 ~~ dep3'
fit_c <- sem(clpm, data = wide, missing = "fiml")

  setNames(round(pe$est.std, 3), paste(pe$rhs, "→", pe$lhs)) }

# 把题目得分加成三波总分（与 L5-3.R 相同）
to_sums <- function(X) {
  out <- list()
  for (t in 1:3) {
    lik <- sim$to_likert(X[[t]])
    out[[paste0("lone", t)]] <- rowSums(lik[, 1:4])
    out[[paste0("dep", t)]]  <- rowSums(lik[, 5:9])
  }
  as.data.frame(out)
}

riclpm <- '
  RI_lone =~ 1*lone1 + 1*lone2 + 1*lone3
  RI_dep  =~ 1*dep1  + 1*dep2  + 1*dep3
  wl1 =~ 1*lone1; wl2 =~ 1*lone2; wl3 =~ 1*lone3
  wd1 =~ 1*dep1;  wd2 =~ 1*dep2;  wd3 =~ 1*dep3
  wl2 ~ wl1 + wd1;  wd2 ~ wd1 + wl1
  wl3 ~ wl2 + wd2;  wd3 ~ wd2 + wl2
  wl1 ~~ wd1; wl2 ~~ wd2; wl3 ~~ wd3
  wl1 ~~ wl1; wd1 ~~ wd1; wl2 ~~ wl2; wd2 ~~ wd2; wl3 ~~ wl3; wd3 ~~ wd3
  RI_lone ~~ RI_lone; RI_dep ~~ RI_dep; RI_lone ~~ RI_dep
  RI_lone ~~ 0*wl1 + 0*wd1;  RI_dep ~~ 0*wl1 + 0*wd1
  lone1 ~~ 0*lone1; lone2 ~~ 0*lone2; lone3 ~~ 0*lone3

clpm <- 'lone2 ~ lone1 + dep1; dep2 ~ dep1 + lone1; lone3 ~ lone2 + dep2; dep3 ~ dep2 + lone2
         lone1 ~~ dep1; lone2 ~~ dep2; lone3 ~~ dep3'

# 取出标准化路径；RI-CLPM 的被试内变量名 wl/wd 改写成 lone/dep，便于与 CLPM 对齐
paths <- function(fit) {
  pe <- standardizedSolution(fit)
  pe <- pe[pe$op == "~" | (pe$op == "~~" & pe$lhs == "RI_lone" & pe$rhs == "RI_dep"), ]
  nm <- ifelse(pe$op == "~", paste(pe$rhs, "→", pe$lhs), "RI_lone ~~ RI_dep")
  nm <- gsub("wl", "lone", gsub("wd", "dep", nm))
  setNames(pe$est.std, nm)
}
# 注意：lavaan 0.7 拟合前后会保存并恢复随机数状态。若把 to_sums(gen_panel(...)) 直接作为参数传入，
# 数据要到 lavaan 内部才生成，随机数状态随后被恢复，每次都会抽到同一份样本。
# 所以先用 force(d) 在 lavaan 之外生成数据。
fit_both <- function(d, ...) {
  force(d)
  list(
    CLPM    = paths(sem(clpm, data = d, ...)),
    RICLPM  = paths(lavaan(riclpm, data = d, meanstructure = TRUE, int.ov.free = TRUE, ...)))
}

④ 理解检查即时测验

“一个人比他自己平时更孤独时，之后会比自己平时更抑郁”描述的是？

  • 被试间比较的是不同的人；这句话的参照点是他自己。
  • 正确：参照点是“他自己平时”。
  • 同期相关描述同一时刻的共同变化，不涉及“之后”。
  • 测量误差是分数中的随机噪声，不是一种关于“之后”的关系。

RI-CLPM 中的随机截距代表什么？

  • 每波的总体均值是 μ_t，所有人共用；随机截距是每个人自己的稳定偏离。
  • 正确。
  • 交叉滞后放在被试内成分之间，不在随机截距上。
  • 模型中观测误差固定为 0；随机截距是跨时间稳定的部分，不是误差。

为什么 RI-CLPM 至少需要 3 波数据？

  • 这是统计识别问题，换任何软件都一样。
  • 正确。
  • 两波就有一个时间段，CLPM 照样能估计交叉滞后；RI-CLPM 需要 3 波是为了分开稳定部分与变化部分。
  • 等值约束是可选的；不加约束时，2 波的 RI-CLPM 同样不可识别。

在课程数据中，从 CLPM 换到 RI-CLPM 后，自回归系数明显变小。最合理的解释是？

  • RI-CLPM 的拟合明显更好（Δχ²(3) = 67.65）；系数变小是因为稳定的个体差异被随机截距分走了。
  • 正确。
  • 被试内自回归仍为正（如 0.348），只是比 CLPM 小：惯性存在，但没有 CLPM 显示的那么强。
  • 恰恰相反：被试内自回归更小，说明状态的延续比 CLPM 显示的弱。

标准 CLPN 是否已经区分了被试间与被试内？

  • 这是常见误解：CLPN 用的是观测分数，没有随机截距。
  • 正确：这是 CLPN 论文“局限性”里必须写的一点。
  • λ 只决定压缩掉多少边，不会把稳定特质从分数中分离出来。
  • 标准化只改变单位，不能去除稳定特质。

⑤ 练习动手练习

练习 1：被试间与被试内各举一例基础

以“社会参与”和“孤独感”为例，各写一句被试间和被试内的研究问题，并想象二者方向可能相反的情境。

查看参考答案 / 思路

被试间：“社会参与多的居民是否比参与少的居民更不孤独？”（可能为负相关）。被试内：“当一位居民某段时间比自己平时参与更多活动时，他是否比自己平时更孤独？”可能为正：例如刚搬到新社区的居民被邀请参加大量活动，正处于适应期，反而感到孤独。这说明两层关系可以方向相反。

练习 2：看懂表格并写 200 字解释写作

根据上面的 CLPM vs RI-CLPM 对照表，写一段 200 字左右的解释，供给“没学过统计的社工同事”阅读。

查看参考答案 / 思路

参考要点：① 普通模型（CLPM）显示孤独和抑郁“很稳定”，并且主要是孤独预测抑郁；② 但这份数据里，有些人长期就比别人更孤独、更抑郁，这种“长期差异”被普通模型误当成了变化过程；③ 把每个人的长期水平扣除后（RI-CLPM），我们看到的是“比自己平时更孤独/更抑郁”的波动之间的关系：这份样本里两个方向的估计都不小，但对照大样本值（本页“与大样本值对照”一节）可以看到，3 波、N = 800 时这些被试内交叉滞后波动很大，不能据此判断哪个方向更强；④ 因此，若干预目标是改变个人状态，应该看去掉长期差异以后的结果，同时承认这类估计不精确，而且仍是统计预测而非因果。

练习 3：动手：随机截距方差动手

运行 R/L5-3.R，在 summary(fit_ri) 中找到 RI_lone ~~ RI_lone、RI_dep ~~ RI_dep 与 RI_lone ~~ RI_dep 的标准化估计，回答：被试间相关有多大？与模拟设定的 0.50 接近吗？

查看参考答案 / 思路

在 Covariances: 部分找 RI_lone ~~ RI_dep 的 Std.all，它就是两个随机截距的相关。模拟中的特质相关设定为 0.50，但观测分数是由“特质 + 题目特异成分 + 被试内状态”再切成李克特等级得来的，所以估计值不一定等于 0.50。本数据的实际结果（R/solutions/L5-3_solution.R）是：随机截距相关 = 0.20，95% CI [−0.02, 0.42]，明显低于 0.50，而且区间很宽。主要原因是抽样误差：在同一个生成模型下，样本无限大时随机截距相关应为 0.459（R/L5-3b.R），200 份 N = 800 样本的 90% 范围是 [0.325, 0.588]，课程样本的 0.200 在 200 份重复样本中只有 1 份不比它大。只有 3 波数据时，RI-CLPM 刚好能识别，“稳定部分”与“被试内部分”很难分清，所以估计很不精确。大样本值本身也略低于 0.50，那是次要原因：每道题还有自己独立的稳定成分，女性在抑郁题上有稳定偏移，李克特等级化也会削弱相关。另外，随机截距方差（孤独 3.40、抑郁 4.35）约占观测总分方差（每波方差的平均：孤独 9.07、抑郁 11.52）的 38%。这比 4.1 课用多层模型算出的抑郁 ICC（0.53）小：多层模型把跨波的全部协方差都归给稳定的个人差异，RI-CLPM 则把其中一部分归给被试内偏离的延续（详见 4.1 课“为什么 5.3 课说稳定成分约占 38%”一段）。只有 3 波时这两种来源很难分开，所以 0.38 和随机截距相关一样不精确。即使模型“结构正确”，在 3 波、N = 800 的条件下，被试间参数的估计也可能离大样本值较远，报告时要附上置信区间。

小结本课小结与延伸阅读

  • 被试间：人与人比较；被试内：一个人与自己平时比较。二者可以方向相反。
  • Hamaker 等人（2015）：CLPM 把稳定特质混进自回归和交叉滞后。
  • RI-CLPM = 随机截距（稳定部分）+ 被试内成分（动态部分），至少 3 波。
  • 课程数据：RI-CLPM 的自回归大幅下降，模型拟合显著更好；被试内交叉滞后在 3 波、N = 800 时很不精确，单份样本不能用来判断方向（大样本值见 L5-3b.R）。
  • 标准 CLPN 没有随机截距，解读和写局限时必须说明这一点。
