多元回归与“控制其他变量”

课文学习 2 小时先修：3.1 简单线性回归：用一条直线做预测配套脚本：R/L3-2.R

本课学习目标

  1. 解释偏回归系数“在其他变量保持不变时”的含义
  2. 理解为什么控制变量后系数会变化（混杂、重叠信息）
  3. 识别多重共线性及其影响

核心概念

  • 多元回归multiple regression
  • 偏回归系数partial regression coefficient
  • 控制变量covariate / control variable
  • 多重共线性multicollinearity
  • 交互作用interaction

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉“在其他条件相同的情况下”

孤独感到底“额外”预测了多少？

你用 T1 孤独总分预测 T2 抑郁总分，得到斜率 0.32：T1 孤独每高 1 分，T2 抑郁平均高 0.32 分。督导追问：“孤独的人往往睡得也不好、社会支持也少，这 0.32 里有多少其实是睡眠和社会支持的‘功劳’？还有，T1 就抑郁的人到了 T2 多半还抑郁，而 T1 抑郁的人往往也孤独，你看到的会不会只是‘本来就抑郁’？”要回答这些问题，需要把多个预测变量同时放进模型：多元回归（multiple regression）。

偏回归系数：“保持其他变量不变”

多元回归给每个预测变量一个系数，叫偏回归系数（partial regression coefficient）。它的含义是：在其他预测变量都相同的人之间比较，这个变量高 1 个单位，结果平均差多少。被一起放进模型、用于“保持不变”的变量叫控制变量（covariate / control variable）。

类比：只比较“条件相同”的人

想象把 800 个人按“睡眠时长”和“社会支持”分成很多小组，每组内的人睡眠和社会支持都几乎一样。在每个小组内部看孤独和 T2 抑郁的关系，再把各组的结果综合起来，就是“控制了睡眠和社会支持之后”孤独的系数。多元回归用数学一次完成了这件事，不需要真的分组。

课程数据（R/L3-2.R）中，孤独的系数随模型变化：

模型预测 T2 抑郁的变量T1 孤独的系数
m1只有 T1 孤独0.324
m2T1 孤独 + 社会支持 + 睡眠时长0.282
m3T1 孤独 + T1 抑郁0.140

加入社会支持和睡眠后，系数只小了一点；加入 T1 抑郁后，系数降到不到一半。解释：T1 孤独与 T1 抑郁相关（r = 0.31），而 T1 抑郁是 T2 抑郁最强的预测因素（人的抑郁状态相当稳定）。在 m1 里，孤独的系数“借用”了一部分本属于 T1 抑郁的预测力；m3 把这部分还了回去。剩下的 0.14 才是“在 T1 抑郁相同的人之间”孤独对 T2 抑郁的额外预测。

为什么控制之后系数会变？

上面的模拟展示了一个规律（变量都已标准化）：

$$\text{简单回归中孤独的系数} = \text{孤独的独特效应} + \text{睡眠的效应} \times \rho(\text{孤独},\text{睡眠})$$

如果漏掉了一个与孤独相关、又影响抑郁的变量（这里是睡眠问题），孤独的系数就会“吸收”它的一部分影响。这叫遗漏变量偏差（omitted variable bias），就是 1.4 课“混杂”的回归版本。把它放进模型（控制它），这部分偏差就消失了。拖动 ρ 到 0，两个系数一样：如果两个预测变量不相关，控制与否不改变系数。

控制不是越多越好

“控制”只能处理测量到了并放进模型的变量；没测到的混杂仍然存在。另外，如果控制了一个处在因果链中间的变量（例如孤独 → 睡眠变差 → 抑郁，控制睡眠），会把孤独通过睡眠起作用的那部分也“控制掉”，系数变小并不说明孤独不重要。该控制什么，要根据研究问题和理论来定，而不是把能找到的变量全部放进去。

与 CLPN 的联系：一条边 = 一个“控制了所有其他 T1 变量”的系数

模型 m3 就是一个“迷你 CLPM”：

$$\text{抑郁}_{T2} = b_0 + \underbrace{0.534}_{\text{自回归}}\times\text{抑郁}_{T1} + \underbrace{0.140}_{\text{交叉滞后}}\times\text{孤独}_{T1}$$

CLPN 把它放大到题目层面：例如预测 T2 的“情绪低落”时，右边同时放进全部 9 道 T1 题目（包括 T1 的情绪低落本身）。于是“T1 与人隔绝 → T2 情绪低落”这条边的含义是：在 T1 时其他 8 道题（包括情绪低落本身）都相同的人之间，与人隔绝高 1 个单位，T2 情绪低落平均高多少。这个“控制了所有其他 T1 节点”的性质，是 CLPN 边与简单相关的根本区别：它排除了已测量的其他 T1 题目带来的混杂。

但这并不意味着 CLPN 的边就“干净”了。有一类混杂，控制再多 T1 题目也排除不掉：每个人身上长期稳定的特质（stable trait）。例如有的人一贯比别人更孤独、也一贯更容易情绪低落，这种稳定的个体差异会让“T1 孤独高的人 T2 抑郁也高”，哪怕在同一个人身上，孤独的升降并不会带来之后抑郁的升降。T1 题目只是这个特质的不完美测量，把它们放进回归只能吸收一部分特质的影响，剩下的仍然会混进交叉滞后系数。课程数据正是这样生成的：data/true_B_within.csv 是生成数据时用的被试内效应，data/true_B_population.csv 是标准 CLPN 在总体中实际会估计到的值（总体目标值），两张表不一样，差别就来自稳定特质。5.3 课（RI-CLPM）会专门讲怎样把被试间和被试内的变异分开。

多重共线性：当两个预测变量几乎一样

如果两个预测变量高度相关，模型很难分清“功劳是谁的”，这叫多重共线性（multicollinearity）。系数本身不一定有偏，但会变得非常不稳定：标准误变大，系数可能忽大忽小甚至变号。极端例子（下方 R 代码）：把孤独总分复制一份、只加一点点噪音（相关 0.995），两者一起放进模型，孤独的系数从 0.32 变成 1.28，副本的系数是 −0.96，标准误从 0.04 膨胀到 0.37。两个系数之和（≈ 0.32）倒是没变：模型知道“孤独这类东西”的总贡献，只是没法分给两个几乎一样的变量。

常用诊断指标是方差膨胀因子 VIF（见数学部分）。经验上 VIF > 5 或 10 值得警惕（不同教材的界值不同）。课程数据 m2 中孤独的 VIF ≈ 1.23，没有问题。CLPN 里题目常常内容相近、彼此高度相关，这是 LASSO 正则化有帮助的原因之一（3.5 课），也是“节点选择”需要慎重的原因（9.2 课）。

交互作用（简介）

交互作用（interaction）指一个变量的效应取决于另一个变量的水平。例如，孤独对抑郁的预测作用在男性和女性中可能不同。在 R 中写作 y ~ x1 * x2（等价于 x1 + x2 + x1:x2），交互项的系数表示“x2 每高 1 个单位，x1 的斜率变化多少”。标准 CLPN 不包含交互项，这里只需知道这个概念存在。

② 最少数学多元回归方程与 VIF

$$\hat y = b_0 + b_1x_1 + b_2x_2 + \cdots + b_px_p$$
\(x_1,\dots,x_p\)
\(p\) 个预测变量。
\(b_j\)
第 \(j\) 个预测变量的偏回归系数：其他 \(x\) 不变时，\(x_j\) 每增 1，\(\hat y\) 变化 \(b_j\)。微积分视角：\(b_j = \partial \hat y / \partial x_j\)，正是“只让一个变量动”的偏导数。

求解方法和简单回归一样：让 \(\sum (y_i-\hat y_i)^2\) 最小，对每个 \(b_j\) 求偏导令其为 0，得到 \(p+1\) 个方程（用矩阵一次解出，R 替你完成）。

“控制”的另一种理解：先剔除重叠，再做回归

Frisch–Waugh 定理：\(b_1\) 等于这样两步的结果。(1) 用其他预测变量去预测 \(x_1\)，取残差（\(x_1\) 中不能被其他变量解释的部分）；(2) 用这个残差去预测 \(y\)。所以偏回归系数只用到了 \(x_1\) 的“独特部分”。课程数据中，用“T1 孤独对 T1 抑郁回归后的残差”去预测 T2 抑郁，斜率正好是 0.1398，与 m3 中孤独的系数完全相同。

方差膨胀因子

$$VIF_j = \frac{1}{1 - R_j^2}$$

\(R_j^2\) 是“用其他所有预测变量预测 \(x_j\)”的 R²。\(x_j\) 越能被其他变量解释，它的独特部分越少，\(R_j^2\) 越接近 1，VIF 越大，\(b_j\) 的方差（SE²）被放大 VIF 倍。例：\(R_j^2 = 0.9\) 时 VIF = 10，SE 放大 \(\sqrt{10}\approx 3.2\) 倍。

④ 理解检查即时测验

为什么加入 T1 抑郁作为控制变量后，T1 孤独对 T2 抑郁的系数从 0.32 降到 0.14？

  • 样本量没有变化（都是 800 人，没有缺失）。
  • 正确：这是遗漏变量偏差被消除。
  • 控制后仍有 0.14 的显著系数（p < .001）。
  • 两者相关只有 r = 0.31，VIF 很小；系数下降是因为单独模型里孤独“借用”了 T1 抑郁的预测力，不是共线性的不稳定。
所以交叉滞后路径必须控制自回归路径。

两个预测变量完全不相关（ρ = 0）。在多元回归中控制其中一个，另一个的系数会怎样？

  • 正确：没有重叠，就没有什么可以“分走”的。
  • 控制只会分走与之重叠的部分；没有重叠，系数原样保留。
  • 只有当两个预测变量相关时才会分走；ρ = 0 时没有重叠。如果它也预测结果，加入它还能减小残差、让 SE 变小。
公式“简单系数 = 独特效应 + 另一个效应 × ρ”中，ρ = 0 时两者相等。

多重共线性主要会让系数的什么变得不稳定？

  • 共线性本身通常不让系数有偏；它影响的是精确度。
  • 正确。
  • 共线性不一定降低 R²；演示中加入副本后，模型的整体预测力几乎不变。
演示中 SE 从 0.037 膨胀到约 0.37，相差约 10 倍（VIF 约 100 → SE 放大约 10 倍）。

某变量 x₃ 被其他预测变量解释的 R² = 0.75，它的 VIF 是多少？

VIF = 1 / (1 − R²)。
1 / 0.25 = 4：它的系数方差被放大 4 倍，SE 放大 2 倍。

CLPN 中“控制了所有其他 T1 变量”这一点为什么重要？

  • 未测量的混杂仍然存在；本课还指出，稳定特质这类混杂控制再多 T1 题目也排除不掉。
  • 正确。
  • 这是本课提醒的误读：T1 题目只是特质的不完美测量，只能吸收一部分特质的影响，所以总体目标值与被试内真值不同（5.3 课）。
包括目标题目自己的 T1 水平（自回归）在内，所以交叉滞后边是“超出稳定性之外”的预测。

研究者想知道孤独对抑郁的“总预测作用”，却控制了“睡眠问题”（假设孤独 → 睡眠变差 → 抑郁）。会发生什么？

  • 控制中介变量会切断孤独 → 睡眠 → 抑郁这条路径，得到的不再是总效应。
  • 正确：不要控制处在因果链中间的变量（中介变量），除非你想看“直接效应”。
  • 孤独与睡眠相关、睡眠又预测抑郁，控制睡眠一定会改变孤独的系数。
  • 睡眠在这里是孤独起作用的通道，不是噪音；控制它会把这部分预测作用拿走，系数变小。
选择控制变量需要理论依据。

⑤ 练习动手练习

练习 3.2-A：系数的变化

运行 R/L3-2.R。分别用“孤独感”单独、以及“孤独感 + 社会支持 + 睡眠”预测 T2 抑郁，比较孤独感系数的变化，写一段 150 字的解释；再加一个模型：“孤独感 + 社会支持 + 睡眠 + T1 抑郁”，系数又变成多少？

参考代码与要点 
m4 <- lm(dep_sum_t2 ~ lone_sum_t1 + social_support_t1 + sleep_hours_t1 + dep_sum_t1, data = dat)
round(coef(m4), 3)

要点：0.324 → 0.282 只是小幅下降。按公式“简单系数 = 独特效应 + 其他效应 × 相关”，被分走的量取决于两件事：社会支持与孤独相关较强（r = −0.42），但控制后它对 T2 抑郁的系数不显著；睡眠的系数显著（−0.37），但它与孤独只弱相关（r = −0.12）。两者都没有“又强相关、又强效应”，所以分走得不多。加入 T1 抑郁后（m4），孤独系数降到约 0.128，与 m3 的 0.140 接近：真正“分走”预测力的是 T1 抑郁。写作时避免“孤独导致抑郁”，可用“在控制……之后，T1 孤独感仍独特地预测 T2 抑郁”。

练习 3.2-B：CLPN 的一条边就是一个偏回归系数

用题目层面的数据写一个回归：以 T2 的 dep1_t2（情绪低落）为结果，以全部 9 道 T1 题目为预测变量（dep1_t2 ~ lone1_t1 + … + dep5_t1）。哪个 T1 孤独题的系数最大？它与 data/true_B_population.csv（总体目标值）中 dep1 那一列的值相比如何？最后算一下 lone4_t1 的 VIF（用其他 8 道 T1 题预测它），判断这 9 道题之间的共线性是否严重。

参考代码与提示 
source("R/_setup.R")
dat <- read_course_data()
d <- as.data.frame(scale(dat[, c(vars_t(1), "dep1_t2")]))     # 先标准化，便于和总体目标值比较
f <- lm(dep1_t2 ~ ., data = d)                               # “.” 表示其余所有列
round(coef(f), 3)
round(true_B()[, "dep1"], 3)                                 # 总体目标值

结果（标准化系数）：孤独题中 OLS 估计最大的是 lone4_t1（0.090），其次 lone3_t1（0.081）。而总体目标值中 lone3 → dep1 约 0.118 才是唯一明显的孤独 → 情绪低落边，lone4 → dep1 约为 0（−0.003）。这说明：即使 N = 800，题目层面的单个系数仍有不小的抽样误差，而且 9 道题彼此相关（共线性）会让“功劳”在相近的题目之间转移（与人隔绝 vs 无人理解）。其他孤独题的系数接近 0 但不正好是 0。3.5 课的 LASSO 和第 8 模块的 bootstrap 稳定性分析处理的就是这类问题。这个回归就是 CLPN 中“预测 T2 情绪低落”的那个方程（7.1 课）。

VIF：X1 <- dat[, vars_t(1)]; 1 / (1 - summary(lm(lone4_t1 ~ ., data = X1))$r.squared) ≈ 1.65；9 道题的 VIF 都在 1.45–1.65 之间，远低于 5 的警戒线。所以这里的共线性并不严重；系数在 lone3 与 lone4 之间“转移”，主要来自抽样误差，题目间的中等相关只是让它更容易发生。

练习 3.2-C：画出因果图

为“孤独 → 抑郁”的研究画一张小图，标出：一个混杂变量（应该控制）、一个中介变量（研究总效应时不应控制）、一个只影响抑郁的变量（控制它可以提高精确度）。

参考示例

混杂：慢性疾病（同时导致孤独和抑郁）；中介：睡眠问题（孤独 → 睡眠 → 抑郁）；只影响抑郁：家族抑郁史（与孤独无关时，控制它不改变孤独的系数，但能减小残差、缩小 SE）。

小结带走三句话

  • 偏回归系数 = 其他预测变量相同的人之间比较；预测变量相关时，加入控制变量会改变系数（遗漏变量偏差）。
  • 多重共线性让系数不稳定、SE 变大；VIF = 1/(1 − R²ⱼ)。
  • CLPN 的每条边就是一个“控制了所有其他 T1 节点（含自回归）”的偏回归系数。下一课：3.3 标准化系数与结果解释。
