深入两个新概念

拓扑重叠（topological overlap / item redundancy）

如果两道题问的几乎是同一件事（例如“我感到孤独”与“我觉得很寂寞”），它们之间的边会非常强，而且它们与其他节点的连接模式也高度相似。这不是“两个症状互相作用”，而是“同一个东西测了两次”。后果：（1）这对节点的边被误读为动态关系；（2）它们的中心性被人为抬高。networktools 包的 goldbricker() 函数可以找出“与其他节点的相关模式高度相似”的题目对，帮助判断是否需要合并或删除。

研究者自由度（researcher degrees of freedom）

CLPN 有很多“可以这样也可以那样”的决定：lambda.min 还是 1se？γ 取几？种子是多少？是否加协变量？用哪些题目？如果研究者尝试了很多组合，只报告最“好看”的一种，结果就可能是偶然的。解决办法：事先写好分析计划（10.1），并报告 敏感性分析（sensitivity analysis）：换一种合理的决定，主要结论是否不变。

三种 λ 规则下 out-EI 最高都是 lone4，看起来很“稳健”，但 8.3 课的 CS 只有 0.20，而且在总体目标值矩阵和被试内真值矩阵中 lone4 都不突出（7.4 课）。敏感性分析中“结论不变”不等于“结论正确”：不同 λ 规则用的是同一份样本，抽样误差是共享的。所以敏感性分析与 bootstrap 稳定性检验要一起看。

Fried & Cramer（2017）：网络方法的大问题

Fried 与 Cramer 系统讨论了心理病理网络理论与方法面临的挑战，包括节点如何定义与选择、网络结果能否在不同样本中复现、统计网络与理论“因果系统”之间的距离等。读这篇文章能帮助你把 CLPN 放在更大的背景下：CLPN 是一个有用的描述和假设生成工具，但它不是“读出因果网络”的机器。（具体论点请以原文为准。）

写审稿意见的结构

  1. 总体评价（2–3 句）：研究问题、方法、主要贡献。
  2. 优点（2 条）：具体而真诚，例如“报告了 T2→T3 复现”“共享了代码”。
  3. 主要问题（3 条）：每条包括“问题是什么 → 为什么重要 → 具体建议”。
  4. 次要问题：措辞、图表、引用。
  5. 语气：对事不对人；用“作者可以考虑……”而不是“作者错误地……”。

② 最少数学把直觉写成式子

1. 题目冗余为什么会抬高中心性？

设题目 A 与 A′ 几乎相同：\(A' = A + e\)，\(e\) 很小。网络中 A—A′ 的边（偏相关或交叉滞后）会很大，A 与 A′ 的强度/EI 都因此增加约 \(|w_{AA'}|\)。如果把两题合并成一个节点，这条“自己连自己”的边就消失了。

2. 种子敏感性的度量

\[\pi_{kj}=\frac{1}{S}\sum_{s=1}^{S}\mathbb{1}\big[\hat\beta^{(s)}_{kj}\neq0\big]\]
符号读法 / 含义
\(S\)尝试的种子个数（R/L9-2 中 S = 20）
\(\hat\beta^{(s)}_{kj}\)用第 s 个种子估计的边
\(\pi_{kj}\)该边在不同种子下非零的比例：1 = 始终保留，0 = 始终为 0，介于其间 = 时有时无

3. 敏感性分析的一致性指标

\[r=\mathrm{cor}\big(\hat\beta^{\text{主分析}}_{\text{CL}},\ \hat\beta^{\text{替代分析}}_{\text{CL}}\big),\qquad \text{Jaccard}=\frac{|E_1\cap E_2|}{|E_1\cup E_2|}\]
符号读法 / 含义
\(E_1, E_2\)两种分析中非零边的集合
\(|E_1\cap E_2|\)两者都有的边数
\(\text{Jaccard}\)杰卡德相似系数：0 = 完全不同，1 = 完全相同

报告“主要结论（最强边、中心性排序、构念方向）在替代分析中是否保持”比报告一个抽象的相关更有意义。

4. 一个关于“重复 CV”的提示

交叉验证误差 \(\mathrm{CV}(\lambda)\) 本身是随机分折的结果。重复 R 次分折并取平均，\(\overline{\mathrm{CV}}(\lambda)=\frac1R\sum_r \mathrm{CV}_r(\lambda)\)，可以降低选 λ 的随机性（代价是计算量 × R）。

③ R 代码在 R 中实现

R/L9-2.R 的核心部分
source("R/_setup.R")
suppressPackageStartupMessages(library(networktools))
dat <- read_course_data()
X <- dat[, vars_t(1)]; Y <- dat[, vars_t(2)]
off <- matrix(TRUE, 9, 9); diag(off) <- FALSE
# 1) λ 规则敏感性
rules <- c("lambda.min", "lambda.1se", "ebic")
Bs <- lapply(rules, function(r) { set.seed(2026); clpn_estimate(X, Y, rule = r) })
names(Bs) <- rules
sapply(Bs, function(B) sum(cl_only(B) != 0))            # 各规则的 CL 边数
sapply(Bs, function(B) names(which.max(rowSums(cl_only(B)))))   # out-EI 第一名
# 2) 随机种子敏感性
arr <- sapply(1:20, function(s) { set.seed(s); clpn_estimate(X, Y)[off] })
nz  <- rowMeans(arr != 0)
table(cut(nz, c(-.01, 0, .99, 1), labels = c("始终为0", "时有时无", "始终非零")))
# 3) 题目冗余
gb <- goldbricker(dat[, vars_t(1)], p = 0.05, method = "hittner2003",
                  threshold = 0.25, corMin = 0.5)
gb$suggested_reductions

goldbricker 参数：corMin = 0.5 只检查相关 ≥ 0.5 的题目对；threshold = 0.25 表示：若两题与其他题目的相关中，显著不同的比例低于 25%，就提示“可能冗余”（数值越小越相似）。这只是一个提示工具，是否合并要看题目内容与理论。

节点少时，goldbricker 的区分力有限

看一下课程数据的实际输出（R/output/L9-2_log.txt）：goldbricker 一共提示了 9 对题目，5 对孤独题、4 对抑郁题，全是同一构念内部的题目对，没有一对跨构念。这不说明这 9 对题目都“问的是同一件事”，而是方法本身在只有 9 个节点时分辨不出来。

原因在于它的比较方式：对一对题目，它只拿“这两道题各自与其余题目的相关”来比，9 个节点时其余题目只有 7 道，所以“显著不同的比例”只能取 0、1/7（≈ 0.14）、2/7（≈ 0.29）……这几个值。阈值 0.25 意味着 7 次比较里最多 1 次显著就会被提示。同一构念的题目本来就和其余题目有相似的相关模式（它们共享同一个潜在特质），于是几乎每一对都会过线。节点越少，可比较的“其余题目”越少，每次比较的功效也越低，这个工具就越容易把“同属一个构念”误报成“内容冗余”。

所以在 9 节点的 CLPN 里，goldbricker 的结果只能作为一个起点：把被提示的题目对拿回去读题目原文，看是不是真的在问同一件事（例如“我感到孤独”与“我觉得很寂寞”），再结合理论决定是否合并。读论文时也一样：节点很少的研究报告“goldbricker 未发现冗余”或“发现大量冗余”，都要先想想这个方法在那么少的节点下能不能分辨。

完整例题：把一个问题写成一条审稿意见

发现问题只是第一步，写成对方能采纳的意见才有用。以“十个常见问题”中的“中心性过度解读”为例，按“问题—原因—建议”三段来写：

问题：“讨论部分将出 EI 最高的‘睡眠问题’称为‘核心症状’，并建议优先干预。”原因：“补充表 S3 显示出 EI 的 CS 系数为 0.21，低于常用的 0.25 标准，说明删去少量被试后排序就可能改变；此外，出 EI 反映的是预测关系，而非干预效果。”建议：“建议删除‘核心症状’的表述，改为描述出 EI 的数值及其不确定性；如作者希望讨论干预含义，请将其表述为有待干预研究检验的假设。”

这样写，作者知道哪里有问题、为什么有问题、怎样改，审稿意见就不再只是批评。语气上始终针对论文，而不针对作者。例子中的数字是虚构的。

④ 理解检查即时测验

两道题目内容几乎相同时，它们之间的强边意味着什么？

  • 这是本课点名的常见误读：同一件事测了两次，不是两个症状在互相作用。
  • 正确。
  • 估计本身可能没错：两题在数据里确实高度相关，问题在于怎样解释这条边。
  • λ 只控制惩罚强度；内容重叠造成的强边在合理的 λ 下都会保留。

为什么说中心性“不等于”干预靶点？

  • 把中心性当成严重程度是常见误读：中心性衡量的是与其他节点的关联，不是症状的平均水平，两者可以完全不同。
  • 正确。
  • 介数在心理网络中更不稳定（6.5 课），它同样只是统计关联的汇总。
  • EI 可以为负只是计算上的性质，不是中心性不能当靶点的理由。

你会如何检验一个 CLPN 结论对 λ 选择是否敏感？

  • bootstrap 回答的是抽样不确定性，不回答“换一种 λ 规则结论是否改变”。
  • 正确。
  • λ = 0 不是一种合理的替代规则：它保留所有系数，比较的是“要不要正则化”，不是“换一种合理的选择”。
  • 似是而非：换种子检验的是交叉验证分折的随机性，λ 规则本身没有变。它也是一项有用的敏感性分析，但回答的是另一个问题。

在课程数据中换 20 个种子，有 11 条 CL 边“时有时无”。这说明？

  • 不是 bug：cv.glmnet 随机分折，不同分折选出的 λ 略有不同。
  • 正确。
  • 这正是研究者自由度的滥用：看了结果再挑种子。
  • 似是而非：确实主要影响弱边，但正因为如此，不报告种子，别人就无法复现你的边数和弱边。

三种 λ 规则下 out-EI 第一名都是 lone4，但 CS = 0.20。最恰当的结论是？

  • 规则间一致不等于抽样稳定：三种规则用的是同一份样本。
  • 正确：不同规则共享同一份样本的抽样误差。
  • 两种检查回答不同的问题，结果并不矛盾，没有理由认为 CS 算错了。
  • 看了结果再换主分析规则违反分析计划；而且 EBIC 下 out-EI 第一名也是 lone4，CS 的问题照旧。

小结本课小结与延伸阅读

  • 十大问题：因果用词、被试间/内、中心性过度解读、拓扑重叠、节点选择、单题信度、样本量、缺失、间隔、研究者自由度。
