模块 9 · Reading, Critique & Reporting · 第 9.1 课

如何读一篇 CLPN 实证论文

课文学习 2 小时先修：8.3 个案删除 bootstrap 与 CS 系数配套脚本：本课无独立脚本

本课学习目标

  1. 用结构化清单快速提取：样本、波次、间隔、节点、估计方法、λ 选择、稳定性结果
  2. 把论文图表与你学过的每个概念对应起来
  3. 区分作者的发现、作者的解释与过度推断

核心概念

  • 结构化阅读structured reading
  • 方法部分method section
  • 补充材料supplementary materials
  • 开放数据与代码open data & code

本模块转向阅读、评估与撰写实证论文。第一步是快速、系统地读懂一篇 CLPN 论文：带着结构化清单把样本、节点、估计设置和稳定性结果逐项提取出来。

本课结构：直觉 → 最少数学 → R 代码 → 理解检查 → 练习 → 小结。文中的交互图示可拖动或点击；测验答错会先给提示，答错两次可查看解析。

① 直觉先建立画面

为什么要“结构化阅读”？

第一次读方法学论文，很容易被大量术语和数字淹没，读完只记得“好像很厉害”。结构化阅读（structured reading） 的意思是：带着一张固定的清单去读，每读到一个信息就填进相应的格子；读完后，空着的格子就是论文没报告（或你没读懂）的地方。清单上的各项依次对应 M4–M8 的内容。

推荐的阅读顺序

  1. 摘要（5 分钟）：研究问题、样本、主要发现。先写下你对“作者想说什么”的一句话概括。
  2. 图和表（10 分钟）：网络图、中心性图、稳定性图。用 7.3 与 8.2–8.3 学到的方法读图：哪些边最粗？是否画了自回归？中心性有没有 CS 系数？
  3. 方法部分（method section）（20 分钟）：逐项填写清单中的“样本—波次—节点—缺失—估计—λ—协变量—中心性—稳定性”。
  4. 结果与讨论（20 分钟）：区分三种内容（见下文），标出你认为“说过头”的句子。
  5. 补充材料（supplementary materials）与开放数据与代码（open data & code）（10 分钟）：很多关键细节（完整边表、λ 规则、稳定性图）只在补充材料里。看看是否有 OSF 链接，代码能否复现。

区分三种内容：发现、解释、过度推断

类型特征例子（虚构）
发现（finding）可以在结果表/图中找到对应数字“T1 孤独感题目 X 对 T2 抑郁题目 Y 的交叉滞后系数为 0.12。”
解释（interpretation）作者对发现的含义的推测，通常带有“可能”“提示”“这可能反映了社交退缩在抑郁发展中的作用。”
过度推断（overreach）超出数据能支持的范围：因果词、干预建议、推广“因此，干预应首先针对 X 以预防抑郁。”

下一课（9.2）会系统列出最常见的过度推断类型。

本课范例：Funkhouser 等人（2021）

课程选择 Funkhouser 等人在 Journal of Child Psychology and Psychiatry 发表的 ABCD 研究作为精读范例：它用 CLPN 研究青少年心理病理症状之间的纵向关系，样本为 4,093 名青少年，并用后续时间段（T2→T3）检验结果能否复现。阅读时请带着下面的阅读卡，所有细节以原文为准（本页不复述该文的具体结果，以免先入为主）。

常见问题与误区

论文没有报告 CS 系数，也没有共享数据，怎样看它的中心性结论？

只能把它当作未经稳定性检验的结果。可以先做几项快速判断：节点数和 N/p（本课“最少数学”）、最强几条边的区间是否很宽、中心性最高的节点与第二名差得多不多。这些只能提示风险，不能代替 CS。写综述时，把这类研究的中心性结论单独标出；审稿时，请作者补做 case-dropping bootstrap 并报告 CS。

② 最少数学把直觉写成式子

本课的“数学”是读论文时最常用的几个快速核算，用来检查论文的数字是否自洽。

1. 边数核算

\[\text{最多交叉滞后边}=p(p-1),\qquad \text{密度}=\frac{\#\{\hat\beta_{kj}\neq0,\ k\neq j\}}{p(p-1)}\]

若论文说“16 个节点、估计出 300 条交叉滞后边”，你立刻知道这不可能（最多 16 × 15 = 240）。

2. 样本量与参数之比

\[\frac{N}{p}\quad(\text{每个回归中每个预测变量对应的人数})\]
符号读法 / 含义
\(N\)分析所用的样本量（注意：可能因缺失而小于招募人数）
\(p\)节点数 = 每个逐节点回归方程中的预测变量数

没有公认的“N 至少是 p 的几倍”这类硬性规则。N/p 只是读论文时快速核算用的粗略指标：它越小，每个逐节点回归的信息越少，交叉验证选出的 λ 越大，网络越稀疏，稳定性越差。课程数据 N/p = 800/9 ≈ 89；一个 N = 300、p = 20 的研究 N/p = 15，结果需要格外谨慎。一项研究到底需要多大样本，取决于真实网络的样子（边有多强、有多少条）和研究要回答的问题，要靠模拟来定：Constantin、Schuurman 与 Vermunt（2026）给出了网络模型样本量规划的一般蒙特卡罗方法，7.6 课做了一个简化版。所以读论文时，N/p 偏小只是一个提醒：要去看作者有没有做样本量规划，有没有报告 bootstrap 区间和 CS 系数。

3. 流失率

\[\text{流失率}=1-\frac{N_{\text{完成所有波次}}}{N_{\text{T1}}}\]

流失率高（如 > 20%）且未处理时，要问：流失是否与基线症状有关（复习 4.3）？

4. 读 CS 与区间

看到 CS 时，立即对照 0.25 / 0.5 两条线；看到边的 bootstrap 区间时，立即检查最强几条边的区间是否重叠、是否包含 0。

③ R 代码在 R 中实现

本课以阅读为主，没有单独的 R 脚本。但有一个很实用的 R 技能：复现论文中的数字。如果作者共享了数据与代码（OSF），你可以检查他们的 λ 规则、种子和 CS 系数。下面是一个“复现检查”模板，假设你已下载作者的宽格式数据：

复现检查模板（使用课程的 clpn_estimate()，需根据论文调整变量名与规则）
source("R/_setup.R")
paper <- read.csv("paper_data.csv")             # 作者共享的数据（示例文件名）
t1 <- grep("_t1$", names(paper), value = TRUE)  # 按作者的命名规则找 T1 题目
t2 <- sub("_t1$", "_t2", t1)                    # 对应的 T2 题目（顺序一致！）
stopifnot(all(t2 %in% names(paper)))
d  <- na.omit(paper[, c(t1, t2)])               # 若作者用了列表删除
nrow(d)                                         # 与论文报告的 N 一致吗？
set.seed(2026)                                  # 若作者报告了种子，用作者的种子
B  <- clpn_estimate(d[, t1], d[, t2], rule = "lambda.min")   # 或作者使用的规则
CL <- cl_only(B)
sum(CL != 0)                                    # 与论文报告的边数比较
head(edge_list(CL), 10)                         # 与论文的最强边表比较
sort(rowSums(CL), decreasing = TRUE)            # out-EI 排序
复现不了怎么办？

先检查 4 件事：① 样本是否相同（缺失处理）；② 变量是否标准化；③ λ 规则与折数；④ 随机种子。即使全部相同，不同 glmnet 版本或 R 版本也可能导致细微差异，所以 9.3 课要求报告软件版本。

完整例题：给一段摘要的每一句贴标签

下面是一段虚构的 CLPN 论文摘要。逐句判断它属于“发现”（数据直接支持）、“解释”（合理但需要假设）还是“过度推断”（数据无法支持）：

  1. “本研究对 612 名社区成年居民进行了间隔 6 个月的三波追踪。”（描述：设计信息，先核对 N、间隔和流失率。）
  2. “控制所有 T1 症状后，T1 的‘缺少陪伴’正向预测 T2 的‘情绪低落’。”（发现：前提是表格中确实有这条边，而且最好给出了 bootstrap 区间。）
  3. “孤独中的社交缺失成分可能是抑郁加重的早期信号。”（解释：用了“可能”，措辞得当，但它依赖于“预测关系反映了某种被试内过程”这一假设。）
  4. “‘缺少陪伴’是整个网络的驱动症状。”（过度推断：“驱动”是因果用词。即使它的出 EI 最高，也要看 CS 是否达标。）
  5. “因此，社区干预应优先针对居民的陪伴需求，这将有效预防抑郁。”（过度推断：从观察数据直接跳到干预效果。合理的写法是“提示可以在干预研究中检验……”。）

做完标签后，回到论文正文核对：第 2 句的边在表中是否存在？区间多宽？第 4 句的 CS 是多少？很多论文的问题不在于分析做错了，而在于摘要和讨论说得比结果多。

读 CLPN 论文时的常见错误
  • 只看摘要和网络图。边权表、稳定性结果和敏感性分析通常在补充材料里，而判断结论是否可信，恰恰要靠这些。
  • 默认作者的 λ 选择、协变量、节点选择都是唯一合理的。阅读时问一句：“换一种合理的选择，结论还在吗？”作者做过敏感性分析吗？
  • 把不同论文的边权直接比较。间隔（2 周还是 1 年）、正则化方法和样本都不同，边权大小不可比，只能比较模式。
  • 忽略样本是谁。大学生样本中的发现，能否推广到社区成年居民或机构的服务对象，需要单独论证。

建议为每篇读过的论文保留一张阅读卡，记下设计、节点、估计方法、稳定性和你认为的主要问题。读到第五篇时，你会开始注意到这个领域反复出现的做法和问题，它们就是写文献综述的素材。

④ 理解检查即时测验

下列哪一句是“发现”而不是“解释”？

  • 这是解释：“可能反映了……”是作者对数字含义的推测，结果表里找不到这句话。
  • 正确：可以在结果表中找到对应的数字。
  • 这是过度推断：从预测关系直接跳到了干预建议。
  • 这是过度推断：“核心驱动”带有因果含义，而且没有交代中心性的稳定性。

一篇论文的 16 节点 CLPN 报告了 280 条交叉滞后边，你应该？

  • 边数上限只取决于节点数：最多 p(p − 1) 条，与样本量无关。
  • 正确。
  • 即使加上 16 条自回归边也只有 256 条，仍不到 280。
  • λ 规则只决定保留多少，上限仍是 240 条。

读 CLPN 论文时，为什么一定要看补充材料？

  • 两者是同一项研究的结果，可信度一样；区别在于详细程度。
  • 正确。
  • 期刊没有这种要求；要读它，是因为判断结论所需的信息常常只在那里。
  • 多数补充材料只是正文篇幅放不下的细节，谈不上隐瞒；但要核对正文的结论与补充材料中的数字是否一致。

论文报告 out-EI 的 CS = 0.18，却在讨论中称某节点为“核心驱动症状”。这属于？

  • CS < 0.25 说明这个“最高”删掉少量个案就可能改变；“驱动”还带有因果暗示。
  • 正确。
  • 表中只有 out-EI 的数值；“核心驱动症状”是作者加上的解读，超出了数值本身。
  • 与复现无关：复现指在另一时间段或样本中得到相似结果。

复现他人 CLPN 结果时，以下哪项最不需要核对？

  • 需要核对：缺失处理不同，进入分析的人就不同，网络也会不同。
  • 需要核对：规则决定保留多少边，种子决定交叉验证的分折，两者都会改变弱边。
  • 需要核对：是否标准化会改变 LASSO 惩罚的相对力度，进而改变哪些边被保留。
  • 正确：编辑器只是写代码的界面，不影响计算；要核对的是 R 和各个包的版本。

⑤ 练习动手练习

练习 1：精读 Funkhouser et al. (2021)阅读

精读该文，用本页阅读卡填写全部 15 项，并准备 10 分钟讲解（建议：2 分钟研究问题、3 分钟方法、3 分钟结果、2 分钟你的评价）。

查看参考答案 / 思路

评分要点（自评用）：① 能准确说出波次、样本量与节点；② 能说出 λ 选择与稳定性检验的具体做法（以原文为准）；③ 能区分作者的发现与解释；④ 指出至少一个具体局限，例如“被试间/被试内未区分”“节点来自不同报告者/量表”“间隔较长”等，并说明为什么它会影响结论；⑤ 不把论文中的预测关系说成因果。

练习 2：自洽性核算基础

某论文：N = 450，p = 12 个节点，报告“估计出 75 条非零交叉滞后边，密度 0.57”。核算密度是否正确，并计算 N/p。

查看参考答案 / 思路

最多 12 × 11 = 132 条，75/132 ≈ 0.57，密度核算无误。N/p = 37.5，不到课程数据（≈ 89）的一半。N/p 没有硬性标准，但这个值提醒你重点看作者报告的 bootstrap 区间和 CS 系数，以及有没有做样本量规划。

练习 3：留给自己的 3 个问题思考

读完论文后，写下 3 个你仍不确定的问题（越具体越好），每个问题后面写一句：要回答它，需要原文的哪部分信息，或需要自己在 R 里做什么。

查看参考答案 / 思路

好问题示例：“作者用 lambda.min 而不是 1se，如果换成 1se，最强的跨构念边还会保留吗？”“作者的 T2→T3 复现用的是边权相关还是中心性相关？”“补充材料中的 CS 为什么没有报告桥接 EI？”避免泛泛的问题，如“这篇论文好不好”。

小结本课小结与延伸阅读

  • 结构化阅读：带着清单读，空格 = 没报告或没读懂。
  • 顺序：摘要 → 图表 → 方法 → 结果讨论 → 补充材料与代码。
  • 区分发现、解释与过度推断。
  • 快速核算：最多边数 p(p−1)、N/p、流失率、CS 阈值。
  • Funkhouser et al. (2021)：ABCD 研究，4,093 名青少年，含 T2→T3 复现；细节以原文为准。
