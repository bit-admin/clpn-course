### 第一步：提出一个好的研究问题 （research question）

好的 CLPN 研究问题有三个特征：

1. **非因果化：**CLPN 估计的是“控制了 T1 所有题目后的时间预测关系”，不是因果效应。所以别写“孤独导致抑郁”，要写“T1 孤独题目在多大程度上独特地预测 T2 抑郁题目”。

2. **题目层面：**网络分析的价值在于看到“哪一个”题目起作用。好的问题会落到具体症状上，例如“‘无人理解’是否是从孤独通向抑郁的主要桥梁？”

3. **双向：**交叉滞后设计天然能检验两个方向，研究问题应当同时包括“反之亦然”。

| 写法 | 评价 |
| --- | --- |
| 孤独感导致抑郁吗？ | 因果用语；变量层面 |
| 孤独和抑郁有关系吗？ | 太宽，横断面数据就能回答 |
| T1 孤独题目在多大程度上独特地预测 T2 抑郁题目，反之亦然？哪些题目是主要桥梁？ | 非因果、题目层面、双向 |

### 第二步：数据清理 （data cleaning）与代码本 （codebook）

数据清理必须做。一个越界值（比如把缺失编码成 99）就足以制造一条很强的假边。代码本则是一份“变量说明书”：每个变量是什么题目、怎么计分、在哪一波测量。它让读者、审稿人和几个月后的你都能看懂数据。下面这张清单对应 `R/L10-1.R` 的各个步骤，你可以边做边勾选。

### 第三步：流失分析 （attrition analysis）

纵向研究几乎总会有人中途退出。关键问题是：退出的人和留下的人一样吗？在 L10-1.R 的流失示例数据中，留存率为 0.80，而流失者的 T1 抑郁总分均值（8.78）远高于留存者（2.60）。如果只分析留下来的人，样本会系统性地“更健康”：T2 的均值会被低估，题目的方差变小（范围限制，1.4 课），标准化以后的边权、LASSO 选出的边和稳定性也会受影响。这个示例中，流失只取决于 T1 抑郁，而 T1 抑郁本身就在每个回归的预测变量里，所以未标准化的回归斜率在理论上仍是无偏的；如果流失取决于没有观测到的 T2 状态（MNAR），偏差会更大（4.3 课）。这时要报告这一差异，并考虑多重插补等方法（第 4 模块）。

### 第四步：一页分析计划 （analysis plan）

为什么要在看到结果之前写？因为 CLPN 有许多“合理的选择”：λ 规则、种子、是否加协变量、是否删除冗余题目……如果看完结果再选，人很难不被“哪个结果更好看”影响（9.2 课的“研究者自由度”）。把选择提前写下来、注明日期，就是一份简易的预注册 （preregistration）。

### 第五步：把完整流程列为必做的敏感性分析

本课程的主分析是应用文献中最常见的“仅 LASSO”CLPN：LASSO 选出并已收缩的系数直接当作边权（7.2–7.4 课）。提出 CLPN 的方法论文（Wysocki et al., 2025）并不推荐停在这一步。它推荐的完整流程（[7.5 设计选择与扩展：多波数据、协变量与被试内问题](L7-5.html)）只用 LASSO 决定哪些路径固定为 0，再在结构方程模型中不加惩罚地重新估计其余路径，检验各时间段的路径是否相等，最后按 p < .01 修剪。只做 LASSO 有三个问题：

1. **假阳性多。**交叉验证选出的 λ 偏小，会保留不少总体中接近 0 的边，而且这个假阳性率不会随样本量增大而下降。课程数据上，lambda.min 在 T1→T2 保留了 19 条总体中 |B| < 0.05 的交叉滞后边（7.2 课的找回率表用的是同一个定义）。

2. **系数被压向 0。**LASSO 的惩罚项会把保留下来的系数也缩小，所以 LASSO 系数不能直接当作效应大小。

3. **没有标准误、检验和拟合指标。**LASSO 只给出一组点估计。SEM 重估以后，才有每条路径的标准误和 p 值、整体拟合指标（χ²、CFI、TLI、RMSEA、SRMR），以及“两段时间的路径是否相等”的检验。

那为什么不直接把完整流程作为主分析？第一，你要阅读和比较的已发表研究大多用仅 LASSO 的做法，主分析与它们一致，结果才可以直接对照。第二，M8 的边权 bootstrap 和中心性稳定性（CS 系数）都建立在 LASSO 估计之上，完整流程没有现成的对应做法。第三，两种做法回答的问题不完全相同：LASSO 选的是“对预测有帮助的边”（以交叉验证误差为准），完整流程保留的是“无惩罚估计在 α = .01 下与 0 有显著差异的路径”。它们的偏向也相反：LASSO 偏向多报，灵敏度高、假阳性多；完整流程偏向少报，假阳性少，但会漏掉不少弱边。两者并列，读者才能看出哪些结论不依赖估计方法。

因此本课程的毕业项目要求：主分析保留 LASSO；完整流程作为必做的敏感性分析（`R/L10-2b.R`），事先写进分析计划，在结果部分与主分析并列报告（10.3 课）。“必做”的意思是无论结果是否一致都要报告，不能只在两者一致时才提。

#### 计划里要事先写明的完整流程设置

| 设置 | 本课程的选择 | 为什么要事先定下来 |
| --- | --- | --- |
| 选边用的 λ 规则与种子 | 与主分析相同（lambda.min，set.seed(2026)） | 换规则会改变进入 SEM 的路径，等于换了一个模型 |
| 多段数据的合并规则 | 保守规则：T1→T2、T2→T3 两段都为 0 的路径才固定为 0 | 另一种做法（任一段为 0 就固定）更稀疏；两种做法的结果会不同 |
| 同期部分 | 同一波内所有残差两两相关 | 吸收同一时间段内的同期效应和共同原因；不加就等于假定同一波各题目的残差互不相关，这几乎一定不成立，模型会严重不拟合，标准误和检验也会出错 |
| 缺失处理 | FIML（lavaan 的 missing = "ml"） | LASSO 不能处理缺失（要先删除不完整个案或插补，4.3 课），FIML 可以；两种分析用到的个案可能不同，方法部分要写明 |
| 最终模型的选择 | 等值约束的嵌套 χ² 检验 p ≥ .05，且 AIC、BIC 都不反对时用约束模型；否则用不约束模型 | 看了路径系数再挑模型，就是研究者自由度 |
| 修剪标准 | p < .01（原论文实例的标准） | 用 .05 会多保留几条边；标准不同，“保留几条”也不同 |
| 节点层面的概括 | in-/out-prediction（被解释方差比例） | 它与期望影响的单位不同，不能放在一起排序 |

#### 事先写好“两种分析不一致时怎么办”

两种分析几乎一定会有不一致的边。看到结果以后再决定信哪一个，又回到了研究者自由度的问题。所以计划里要写一条判读规则。本课程的规则是：

- 两种分析都保留、方向相同的边，作为主要发现报告；

- 只在主分析中非零、完整流程没有保留的边，写成“对估计方法敏感”，只作探索性解释，不作为实务建议的依据；

- 完整流程保留、主分析为 0 的边，同样只作探索性报告。这种情况可能出现，因为进入 SEM 的路径是两段 LASSO 结果的并集，等值模型还合并了两段的信息；

- 构念层面的结论（例如“孤独 → 抑郁方向的边权和大于反方向”）只有在两种分析中方向一致时，才写进摘要和实务意义。

规则可以有别的定法，例如把修剪标准放宽到 .05。关键是在看到结果之前定下来，在报告中照此执行；确需改动时，逐条说明改了什么、为什么改。

**社工视角**

研究问题最好来自实务中的困惑。例如你在社区服务中心接待居民时发现：有些人说“没人懂我”，有些人说“没人陪我”，哪一种更值得优先关注？这就可以转化为一个预测性的问题：“哪一个孤独题目对之后抑郁的独特预测最强（桥接出期望影响最高）？”它本身回答不了“该优先干预哪一个”（中心性不等于干预靶点，9.2 课），但可以为之后的干预研究提出假设。汇报时也可以从这个实务问题讲起。

### 常见误区

- **先跑后写计划：**这样的计划等于没有计划。

- **节点选太多：**节点越多，需要的样本量越大，而且增长得很快（系数个数是 p²）。没有公认的“几个节点配多少人”的标准；课程数据 N = 800 只用了 9 个节点。想放更多节点时，先按下面“最少数学”部分的第 3 个公式核算 N/p，再用 7.6 课的模拟检查关键的边能否找回。

- **忽略内容重叠：**“情绪低落”和“心情沮丧”几乎是同一个题目，应当合并或二选一（9.2 课）。这也是完整流程的第 1 步。

- **把完整流程当作“结果不好看时的备选”：**先看 LASSO 结果再决定做不做完整流程，或者从两种结果中挑一个好看的当主分析，敏感性分析就失去了意义。哪个是主分析、哪个是敏感性分析，计划里写定。

## ② 最少数学 把直觉写成式子

本课只有几个小公式，都与数据准备和设计检查有关。

#### 1. 反向计分

\[x^{\text{rev}} = (x_{\max}+x_{\min}) - x\]

| 符号 | 读法 / 含义 |
| --- | --- |
| \(x\) | 原始得分 |
| \(x_{\max}, x_{\min}\) | 量表的最高、最低可能分（如 1–4 分量表为 4 和 1） |
| \(x^{\text{rev}}\) | 反向计分后的得分：1↔4、2↔3 |

例：1–4 分量表，原始 1 分 → (4+1)−1 = 4 分。课程数据没有反向题，但真实量表（如 UCLA 孤独量表的部分版本）常有。

#### 2. 留存率

\[\text{留存率} = \frac{N_{t}}{N_{1}}\]

| 符号 | 读法 / 含义 |
| --- | --- |
| \(N_1\) | 第 1 波的样本量 |
| \(N_t\) | 第 \(t\) 波仍有数据的人数 |

例：640 / 800 = 0.80。再比较留存者与流失者的 T1 均值（或做 t 检验），说明流失是否与研究变量有关。

#### 3. 参数数量与样本量的粗略检查

每个 T2 节点的 LASSO 回归有 \(p\) 个预测变量（\(p\) 是节点数）。整个网络最多 \(p^2\) 个系数，其中 \(p\) 个是自回归，\(p(p-1)\) 个是交叉滞后。本课程 \(p = 9\)，共 81 个系数；N = 800，N/p ≈ 89，每个回归中样本量是预测变量数的近 90 倍。N/p 没有公认的硬性下限，它只是一个粗略的快速核算（9.1 课）。如果你只有 N = 150 却想放 20 个节点（N/p = 7.5），每个回归的信息就很少，网络会很稀疏、很不稳定。计划自己的研究时，需要多大样本要靠模拟来定：先假定一个合理的真实网络（用预实验或已发表研究的估计值，把弱边也考虑进去），再看不同 N 下能否找回关键的边。Constantin、Schuurman 与 Vermunt（2026）给出了这种蒙特卡罗方法的一般形式，7.6 课做了简化版。

#### 4. 完整流程的参数个数与等值检验的自由度

完整流程的路径模型里，每一段（T1→T2 或 T2→T3）有 \(p\) 条自回归路径和 \(K\) 条进入 SEM 的交叉滞后路径。不约束模型两段各自估计，共 \(2(p+K)\) 个路径参数；等值约束让同一条路径在两段共用一个参数，只剩 \(p+K\) 个。其余参数（T1 的方差协方差、各波的残差方差与同波残差协方差、截距）两个模型相同。所以嵌套 χ² 检验的自由度是：

\[\Delta df = 2(p+K) - (p+K) = p + K,\qquad \Delta\chi^2 = \chi^2_{\text{约束}} - \chi^2_{\text{不约束}}\]

| 符号 | 读法 / 含义 |
| --- | --- |
| \(p\) | 节点数（课程数据为 9） |
| \(K\) | 保守规则下进入 SEM 的交叉滞后路径数（每段） |
| \(\Delta\chi^2\) | 约束模型比不约束模型多出的不拟合；在等值成立时近似服从自由度为 \(\Delta df\) 的 χ² 分布 |

课程数据中 \(K\) = 67，所以 \(\Delta df\) = 9 + 67 = 76（R/L10-2b.R 的日志会打印这个数，可以用它核对模型是否写对了）。AIC 与 BIC 都是“不拟合 + 参数个数的惩罚”：

\[\mathrm{AIC} = -2\log L + 2q,\qquad \mathrm{BIC} = -2\log L + q\ln N\]

| 符号 | 读法 / 含义 |
| --- | --- |
| \(\log L\) | 模型的对数似然 |
| \(q\) | 模型的自由参数个数 |
| \(N\) | 样本量 |

数值越小越好。约束模型少了 \(p+K\) 个参数，只要它多出的不拟合不太大，AIC 和 BIC 就会偏向它；BIC 的惩罚随 \(\ln N\) 增大，比 AIC 更偏向简单模型。三个标准（χ² 检验、AIC、BIC）都不反对等值时，才用约束模型，这条规则要事先写进计划。

### 完整例题：从一个模糊的兴趣到一个可分析的问题

很多毕业项目一开始都是这样一句话：“我想研究社区居民的孤独和抑郁。”下面演示怎样把它一步步收窄成 CLPN 能回答的问题：

1. **明确对象和情境：**“某市社区的成年居民（18 岁以上）”比“社区居民”更具体。样本从哪里来？有没有现成的追踪数据？

2. **明确时间：**CLPN 至少需要两波，最好三波（一段用于主分析，一段用于复现）。间隔多长？要能对应你关心的过程：孤独影响情绪，可能需要几个月，而不是几天。

3. **明确节点：**用哪些量表的哪些题？题目数 p 不宜太多。CLPN 有 p × p 个系数，9 个节点就有 81 个。没有公认的“N 至少是 p 的几倍”这类硬性规则；N/p 只是粗略的快速核算，需要多大样本要用模拟来定（Constantin et al., 2026；7.6 课是简化版），之后再用 bootstrap 和 CS 检查稳定性。

4. **写成可检验的问题：**“在社区成年居民中，T1 孤独的各个方面在多大程度上独特地预测 6 个月后的抑郁症状，反之亦然？”注意用的是“预测”而非“导致”，也同时问了两个方向。

5. **事先写下“什么结果会让我改变想法”：**例如，“如果孤独 → 抑郁的桥接边在 T2 → T3 中无法复现，我只把它作为探索性发现报告。”

本课的 `R/L10-1.R` 会生成一份简易分析计划 `R/output/L10-1_analysis_plan.md`，内容依次是研究问题、节点、估计方法、中心性、稳定性、敏感性和缺失处理。建议先填写你自己的版本，逐项定稿后再开始分析。

**项目设计阶段的常见错误**

- **忽视伦理与数据安全。**社工研究的对象往往是弱势群体。使用二手数据也要确认授权范围，并去除可识别信息。

- **数据清理没有留下记录。**每一步删除、重新编码都写进脚本，并在 codebook 中说明（`L10-1_codebook_stats.csv` 是一个示范）。

### 一页计划书的自查问题

开始分析之前，用这五个问题检查计划书：①研究问题能否用一句话说清，而且没有因果用词？②每个节点为什么入选，有没有理论或文献依据？③样本量与节点数的比例是否合理，是否计划用 bootstrap 和 CS 检查稳定性？④主分析的每个设置（λ 规则、种子、协变量）是否都已写明？⑤哪些分析是敏感性分析，哪些是探索性分析，是否已事先区分？五个问题都能回答“是”，就可以开始动手了。

## ④ 理解检查 即时测验

下列哪个研究问题最适合 CLPN？

- A. 孤独导致抑郁吗？

- 使用了因果用语。

- B. 孤独和抑郁相关吗？

- 太宽，横断面数据就能回答。

- C. T1 孤独题目在多大程度上独特地预测 T2 抑郁题目，反之亦然？（正确）

- 正确：非因果、题目层面、双向。

- D. T1 孤独总分能否预测 T2 抑郁总分？

- 似是而非：没有因果用语，但停留在总分层面、只问一个方向，用不到 CLPN 的长处，CLPM 就能回答。

为什么要在看到结果之前写分析计划？

- A. 这是课程的形式要求

- 形式只是表面；真正的作用是防止看了结果再选分析。

- B. 限制研究者自由度，避免根据结果挑选分析（正确）

- 正确。

- C. 保证结果与预期一致

- 计划不保证结果，只保证分析不随结果改变；结果与预期不一致时照样报告。

- D. 让结果更显著

- 恰恰相反：计划的作用是防止为了显著而挑选分析。

- A. 2

- (4+1)−2 = 3。

- B. 3（正确）

- 正确。

- C. 4

- 那是原始 1 分的结果。

- D. 1

- 那是原始 4 分的结果。

流失者的基线抑郁显著高于留存者，意味着什么？

- A. 没有影响：流失者已经不在样本里了

- 正因为流失者不在样本里，留下的人才系统性地“更健康”。

- B. 只分析留存者会使样本偏“健康”，结果可能有偏，需要报告并考虑插补（正确）

- 正确。

- C. 应把流失者的缺失值用样本均值填补

- 均值填补会低估方差、扭曲相关，也没有利用“流失与基线抑郁有关”这一信息；应考虑多重插补或 FIML（4.3 课）。

- D. 只要留存率达到 80% 就可以忽略

- 似是而非：本课示例的留存率正是 0.80，流失者的基线抑郁仍远高于留存者；偏差取决于流失与变量的关系，不只取决于比例。

为什么本课程把 Wysocki 等人（2025）的完整流程列为必做的敏感性分析？

- A. 因为仅 LASSO 的结果总是错的

- 不是“错”：LASSO 偏向多报边，但主分析仍用它，以便与已有文献对照。

- B. 仅 LASSO 的做法假阳性多、系数被压向 0，方法论文推荐完整流程；两者并列，才能看出哪些结论不依赖估计方法（正确）

- 正确。

- C. 因为完整流程能把被试间与被试内效应分开

- 这是常见误解。完整流程同样基于观测得分，同样混合了被试间与被试内效应（7.5 课）。

- D. 因为完整流程保留的边更多，结果更显著

- 恰恰相反：按 p < .01 修剪后，完整流程保留的边通常比 lambda.min 少得多。

“两种分析不一致时怎么解释”的规则，应该在什么时候定？

- A. 看到两种结果之后，选更合理的那一种

- 看了结果再选，就是研究者自由度。

- B. 看到任何结果之前，写进带日期的分析计划（正确）

- 正确。

- C. 审稿人问到时再定

- 那时已经看过结果了。

- D. 不用定，不一致时一律以主分析为准

- 这也是一条规则，但要事先写明理由；而且只在主分析中出现的边应当标为“对估计方法敏感”。

课程数据中，完整流程每段有 9 条自回归路径和 K 条交叉滞后路径进入 SEM。跨时间等值约束的嵌套 χ² 检验的自由度是多少？

- A. K

- 还要算上自回归路径：它们也被约束为两段相等。

- B. 9 + K（正确）

- 正确：不约束模型有 2(9 + K) 个路径参数，约束模型有 9 + K 个，差为 9 + K。

- C. 2(9 + K)

- 这是不约束模型的路径参数个数，不是两模型之差。

- D. 72

- 72 是可能的交叉滞后位置数。

代码本至少应包含？

- A. 只要变量名

- 只有变量名，别人不知道 lone4 问的是什么。

- B. 变量名、题目原文、量表、取值与含义、所属波次（正确）

- 正确。

- C. 每个变量的均值和标准差

- 这是描述统计，是代码本的一部分；没有题目原文和计分方式，仍然看不懂变量。

- D. 变量名和取值范围就够了，题目原文写在论文里

- 似是而非：代码本要能单独使用；题目原文不在代码本里，几个月后连你自己也要回头翻论文。

## ⑤ 练习 动手练习

#### 练习 1：提出你的研究问题写作

写出 2 个候选研究问题，用本课的三个标准（非因果、题目层面、双向）自评，选出一个。

查看参考答案 / 思路

示例：“在三波社区成年居民数据中，T1 的哪些孤独题目最能独特地预测 T2 的抑郁症状，抑郁症状是否也反向预测孤独？”自评：非因果（用“预测”）；题目层面（“哪些题目”）；双向（“是否也反向预测”）。

#### 练习 2：运行 L10-1.R 并检查输出动手

运行 R/L10-1.R，回答：① 是否有越界值？② 重复 ID 和缺失值有多少？③ 流失示例中，留存者与流失者的 T1 孤独总分相差多少？④ 假如 lone2 是一道反向题（1–4 分），写出反向计分的 R 代码；如果反向题是 0–3 分的抑郁题，公式又是什么？

查看参考答案 / 思路

① 没有：所有值都在允许的取值里（孤独 1–4，抑郁 0–3，没有非整数），日志里“不在允许取值集合内的值的个数”合计为 0；② 重复 ID = 0，缺失 = 0；③ 流失者 T1 孤独均值 10.4，留存者 8.42，相差约 2 分（以你的输出为准）；④ `raw$lone2_t1_r <- 5 - raw$lone2_t1`（(4 + 1) − x）；0–3 分的题是 (3 + 0) − x，即 `3 - x`。不要把 `5 - x` 套到每个量表上。

#### 练习 3：完成一页分析计划写作

用本页的生成器写完分析计划，复制保存为 `analysis_plan.md`，在文件开头写上日期。之后正式分析中的每个设置都以它为准。

查看参考答案 / 思路

可以对照 `R/output/L10-1_analysis_plan.md`。关键是：λ 规则、种子、CS 标准和敏感性分析都已经事先确定，其中包括必做的完整流程（第 8 条）和两种分析不一致时的处理（第 9 条）。

#### 练习 4：为完整流程写计划条目写作

为你的项目写出分析计划的第 8、9 两条。第 8 条逐项写明完整流程的设置（选边的 λ 规则与种子、多段合并规则、同期部分、缺失处理、最终模型的选择规则、修剪标准、节点层面的概括指标）；第 9 条写出至少三种不一致情形各自怎样报告。再想一想：如果你的数据只有两波，第 8 条中哪几项要改？

查看参考答案 / 思路

第 8 条参照本页“计划里要事先写明的完整流程设置”表，每一项都要有具体值，不能写“按默认”。第 9 条至少区分：两种分析都保留的边；只在主分析中出现的边；只在完整流程中出现的边；构念层面的结论在两种分析中方向是否一致。

只有两波时：没有第二段，就没有多段合并规则（LASSO 为 0 的路径直接固定为 0），也做不了跨时间等值检验，最终模型就是唯一的那个路径模型，其余设置不变。这时无法用 T2→T3 检查结果能否复现，局限部分要写明。

## 小结 本课小结与延伸阅读

- 研究问题：非因果、题目层面、双向。

- 数据清理：取值范围、重复 ID、缺失、反向计分；代码本记录每个变量。

- 流失分析：比较留存者与流失者，决定缺失处理。

- 在看到结果之前写好带日期的一页分析计划（简易预注册）。

- 主分析用仅 LASSO 的 CLPN；Wysocki 等人（2025）的完整流程是必做的敏感性分析，它的设置和“两种分析不一致时怎么办”都要事先写进计划。
