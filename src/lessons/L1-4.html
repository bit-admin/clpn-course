① 直觉两个变量“一起变化”的程度

一张点点图

社工小陈把 800 位居民画在一张图上：横轴是 T1 孤独总分，纵轴是 T1 抑郁总分，每个人是一个点。她发现点云整体“向右上方倾斜”：孤独分高的人，抑郁分也倾向于高。但也有很多例外：有人很孤独却不抑郁，有人不孤独却很抑郁。“倾向于”到底有多强？我们需要一个数字来概括。

这种图叫{{T:散点图|scatter plot}}。下面是课程数据的真实散点图（R/L1-4.R 画出；为避免点重叠，给每个点加了一点随机“抖动” jitter）：

协方差：用“象限”来想

在点云中央画一个十字：竖线是孤独的均值，横线是抑郁的均值。于是每个点落在四个象限之一：

  • 右上：两者都高于平均 → 离均差 (+)(+) = 正；
  • 左下：两者都低于平均 → (−)(−) = 正；
  • 左上、右下：一高一低 → 负。

把所有人的“离均差乘积”加起来再平均，就是{{T:协方差|covariance}}。如果大多数点落在右上和左下，协方差为正；落在左上和右下居多，为负；四个象限差不多，接近 0。

在上面的模拟里勾选“显示 z 乘积的象限”，拖动 ρ（读作 rho，表示总体相关）：ρ 越接近 1，点越集中在绿色象限、越像一条直线；ρ = 0 时点云是一团圆形；ρ 为负时点集中在红色象限。再把样本量调到 10，多点几次“重新抽样”：小样本中算出的 r 会在总体 ρ 周围大幅跳动。这是下一课的主题。

从协方差到相关系数

协方差有个缺点：它的大小取决于量尺。孤独用 4–16 分还是 0–100 分，协方差会差很多倍。解决办法你已经会了：先把两个变量都变成 z 分数，再算协方差。这就是{{T:相关系数|correlation coefficient}}，最常用的版本叫{{T:皮尔逊相关|Pearson's r}}。它永远在 −1 到 1 之间：

r含义
+1完美正相关：所有点恰好在一条向上的直线上
0没有线性关系（可能有曲线关系）
−1完美负相关：所有点恰好在一条向下的直线上

方向看符号，强弱看绝对值：r = −0.6 比 r = 0.3 更强。心理学中常引用 Cohen 的粗略标准：|r| ≈ 0.1 小、0.3 中、0.5 大，但这只是参考，不同领域的“大小”标准不同。

其他相关：当数据是定序的

  • {{T:斯皮尔曼相关|Spearman's rank correlation}}：先把每个变量的数值换成名次（第 1 名、第 2 名……），再算皮尔逊相关。英文文献常把它记作 Spearman's ρ；本课程用 ρ 只表示总体相关；为免混淆，斯皮尔曼相关一律记作 \(r_s\)。它只关心“排序是否一致”，对偏态和极端值更稳健。
  • {{T:多分格相关|polychoric correlation}}：假设每道李克特题背后有一个连续的、正态分布的“潜在倾向”，被切成了几个等级；它估计的是这两个潜在连续变量之间的相关。题目等级少（如 0–3）、偏态明显时常用。网络分析中常用的 qgraph::cor_auto() 会自动检测：等级数不多（默认 ≤ 7）的变量被当作定序变量，计算多分格相关。

课程数据中“情绪低落”与“睡眠问题”（T1）：皮尔逊 r = 0.40，斯皮尔曼 \(r_s\) = 0.39，多分格相关 = 0.48。多分格相关通常比皮尔逊大一些，因为皮尔逊被粗糙的 4 个等级和地板效应“压低”了。

什么会影响 r 的大小？范围限制

相关不仅取决于两个变量的关系有多紧，还取决于样本里变量的变化范围。如果只研究“社会支持很高”的人，社会支持几乎人人相同，它与其他变量的相关就会被压低。课程数据中，全体 800 人里社会支持与孤独总分的相关是 −0.42；只看社会支持 ≥ 4 分的 185 人，相关缩小到 −0.22。这叫{{T:范围限制|restriction of range}}。社工研究常常只在“服务对象”中取样（他们的困扰程度本来就集中在较高的范围），这时得到的相关可能比在一般人群中弱，但这不一定说明关系本身弱。

相关矩阵：网络分析的原材料

有 p 个变量时，两两之间都有一个相关，排成一张 p × p 的表，叫{{T:相关矩阵|correlation matrix}}。对角线都是 1（自己与自己），而且上下对称（A 与 B 的相关 = B 与 A 的相关）。9 道题就有 9 × 8 / 2 = 36 个不同的相关。模块 6 你会看到：横断面网络几乎完全是从这张表“加工”出来的；CLPN 则用 T1 与 T2 之间的关系做回归。两种网络的原材料都是这类相关（协方差）矩阵。

相关 ≠ 因果：混杂变量

经典例子

夏天冰淇淋销量和溺水人数高度正相关。冰淇淋导致溺水吗？当然不是：天气炎热同时让人买冰淇淋和去游泳。这个同时影响两者的第三变量叫{{T:混杂变量|confounder}}。

社工领域的例子：“社区活动参与次数”与“抑郁得分”负相关。可能的解释至少有：(1) 参与活动降低抑郁；(2) 反向因果：抑郁的人本来就不愿出门参加活动；(3) 混杂：身体健康状况好的人既能参加活动、又不容易抑郁；(4) 选择偏差：只有状态较好的人才回答了问卷。一个相关系数无法区分这四种解释。

② 最少数学协方差与 r

$$\operatorname{cov}(X,Y) = \frac{\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y)}{n-1} \qquad r = \frac{\operatorname{cov}(X,Y)}{s_X\, s_Y} = \frac{1}{n-1}\sum_{i=1}^{n} z_{x_i}\, z_{y_i}$$
\((x_i-\bar x)(y_i-\bar y)\)
第 \(i\) 个人两个离均差的乘积：同号为正，异号为负（象限图）。
\(n-1\)
与方差一样，除以 \(n-1\)。
\(s_X, s_Y\)
两个变量各自的标准差；除以它们 = 消除量尺。
\(z_{x_i} z_{y_i}\)
两个 z 分数的乘积；r 就是这些乘积的“平均”（除以 \(n-1\)）。

小验证：一个变量和它自己的协方差是什么？\(\operatorname{cov}(X,X) = \sum (x_i-\bar x)^2/(n-1)\)，就是方差。所以 \(r(X,X) = s_X^2/(s_X s_X) = 1\)。

手算一个小例子

3 个人：孤独 \(x\) = 2, 4, 6；抑郁 \(y\) = 1, 3, 2。

  1. \(\bar x = 4,\ \bar y = 2\)。离均差：\(x\): −2, 0, 2；\(y\): −1, 1, 0。
  2. 乘积：2, 0, 0，和 = 2；\(\operatorname{cov} = 2/2 = 1\)。
  3. \(s_X = \sqrt{8/2}=2,\ s_Y=\sqrt{2/2}=1\)；\(r = 1/(2\times1) = 0.5\)。

③ R 代码cov()、cor() 与相关矩阵

对应脚本：R/L1-4.R。

```r R/L1-4.R（节选） source("R/_setup.R") dat <- read_course_data() dat$lone_sum_t1 <- rowSums(dat[, paste0(lone_items, "_t1")]) dat$dep_sum_t1 <- rowSums(dat[, paste0(dep_items, "_t1")]) x <- dat$lone_sum_t1; y <- dat$dep_sum_t1 cov_hand <- sum((x - mean(x)) * (y - mean(y))) / (length(x) - 1) # 协方差 r_hand <- cov_hand / (sd(x) * sd(y)) # 相关 cat("协方差：手算", round(cov_hand, 3), " cov()", round(cov(x, y), 3), "\n") cat("相关 r：手算", round(r_hand, 3), " cor()", round(cor(x, y), 3), "\n") vars <- c("lone_sum_t1", "dep_sum_t1", "social_support_t1", "sleep_hours_t1", "life_sat_t1") round(cor(dat[, vars]), 2) # 相关矩阵 cat("\nSpearman r(孤独, 抑郁) =", round(cor(x, y, method = "spearman"), 3), "\n") # 斯皮尔曼相关 ``` ```out 输出（R/output/L1-4_log.txt，节选） 协方差：手算 3.268 cov() 3.268 相关 r：手算 0.312 cor() 0.312 lone_sum_t1 dep_sum_t1 social_support_t1 sleep_hours_t1 lone_sum_t1 1.00 0.31 -0.42 -0.12 dep_sum_t1 0.31 1.00 -0.18 -0.29 social_support_t1 -0.42 -0.18 1.00 0.05 sleep_hours_t1 -0.12 -0.29 0.05 1.00 life_sat_t1 -0.33 -0.25 0.35 0.06 life_sat_t1 lone_sum_t1 -0.33 dep_sum_t1 -0.25 social_support_t1 0.35 sleep_hours_t1 0.06 life_sat_t1 1.00 Spearman r(孤独, 抑郁) = 0.316 ```

缺失值

如果数据中有 NA，cor() 默认返回 NA。可以加 use = "pairwise.complete.obs"（每一对变量用各自都不缺的个案）或 use = "complete.obs"（只用所有变量都不缺的个案）。2.5 课和 4.3 课详谈两者的区别。

完整例题：手算协方差与 r

5 个人的孤独 x = 1、2、3、4、5，抑郁 y = 2、4、5、4、5。

  1. 均值：x̄ = 3，ȳ = 4。
  2. 离均差：x 为 −2、−1、0、1、2；y 为 −2、0、1、0、1。
  3. 离均差乘积：4、0、0、0、2，和 = 6，协方差 = 6 ÷ 4 = 1.5。
  4. 标准差：x 的离均差平方和为 10，SD = √(10/4) ≈ 1.581；y 的为 6，SD = √(6/4) ≈ 1.225。
  5. r = 1.5 ÷ (1.581 × 1.225) ≈ 0.775。

可以在 R 里核对：cor(c(1,2,3,4,5), c(2,4,5,4,5))。你会看到，乘积为正的点（第 1、5 人：同时低于、同时高于均值）在推高 r；乘积为 0 的点（有一个变量正好在均值上）不贡献任何信息。

常见错误
  • 忽视异常值。在小样本里，一个极端个案就能把 r 从 0.1 拉到 0.4。画散点图，或用斯皮尔曼相关做一次对照。
  • 脱离情境给 r 贴“强 / 弱”的标签。r = 0.3 在心理社会研究中相当常见，也不算小：r² = 0.09，即约 9% 的变异可以“共享”。

小结带走三句话

  • 协方差 = 离均差乘积的平均；相关 r = 标准化后的协方差，范围 −1 到 1，符号看方向，绝对值看强弱。
  • 定序、偏态的题目可考虑斯皮尔曼或多分格相关；相关矩阵是网络分析的原材料。
  • 相关 ≠ 因果：至少还有反向因果、混杂、选择偏差等解释。下一课：{{L:1.5}}。
