① 直觉一排储物格：向量

十位服务对象的睡眠记录

社区睡眠健康小组的 10 位成员报告了昨晚的睡眠时长（小时）：7、5.5、8、（第 4 位没填）、6、4.5、7.5、（第 8 位没填）、9、5。你想知道：平均睡了多久？哪几位不到 6 小时，需要重点跟进？在 Excel 里你会把它们写成一列；在 R 里，你会把它们存进一个{{T:向量|vector}}。

向量是一排同类型的值，按顺序排列，每个位置有编号（从 1 开始）。用 c() 创建：

sleep <- c(7, 5.5, 8, NA, 6, 4.5, 7.5, NA, 9, 5)

这里的 NA（Not Available）是 R 表示{{T:缺失值|NA}}的特殊符号，意思是“这里本该有一个值，但我们不知道它是多少”。它不是 0，也不是空字符串。

类比：带编号的一排储物格

向量就像一排编了号的储物格。sleep[3] 是“打开第 3 格”，得到 8。数据框（下一课）则是很多排储物格并列在一起：每一排是一个变量（一列），同一位置是同一个人。

索引：取出你要的格子

方括号 [ ] 叫{{T:索引|indexing, [ ]}}，有三种用法：

  • 按位置：sleep[3] 取第 3 个；sleep[c(1, 3)] 取第 1 和第 3 个；sleep[-1] 取除第 1 个以外的所有值（负号 = 去掉）。R 的编号从 1 开始：sleep[0] 不会报错，而是返回一个空向量，所以这类错误很难发现。
  • 按条件（逻辑索引）：sleep[sleep < 6]。先算 sleep < 6，得到一串 TRUE/FALSE；再把 TRUE 位置上的值取出来。所以 x[x > 5] 的意思是“取出 x 中所有大于 5 的值”。
  • 按名字：如果向量的元素有名字，可以 v["lone1"]（数据框里常用 df$var，下一课）。

向量化：一次对所有格子做同样的事

R 的运算是{{T:向量化|vectorized}}的：sleep * 60 会把每一个值都乘以 60（换算成分钟），不需要写循环。sleep < 6 也是对每个值分别比较。两个等长向量相加，是对应位置相加。这让 R 代码写起来很短：(x - mean(x)) / sd(x) 一行就把整列变成 z 分数（1.3 课）。

数据类型：格子里装的是什么

每个向量都有一种{{T:数据类型|data type}}，用 class() 查看：

类型例子用途
数值 numeric（含整数 integer）7, 5.5, 3L量表分、年龄、睡眠时长
字符 character"小李", "P001"姓名、编号、开放题回答；必须加引号
{{T:逻辑值|logical, TRUE/FALSE}}TRUE, FALSE比较的结果、筛选条件
{{T:因子|factor}}factor(c(1, 0), levels = c(0, 1), labels = c("男", "女"))类别变量：性别、教育程度、服务类型

两个关键规则：

  1. 一个向量只能有一种类型。如果混合了数字和字符，R 会把所有值都变成字符：c(1, "二", 3) 得到三个字符串。问卷数据里只要有一个格子误填了“五”，整列就会被读成字符，mean() 就会出错。所以导入数据后要先用 class() 或 str() 检查每列的类型。强行转换 as.numeric(c("3", "4", "五")) 得到 3 4 NA，并警告 NAs introduced by coercion（强制转换产生了 NA）。
  2. 逻辑值可以当数字用：TRUE = 1，FALSE = 0。所以 sum(sleep < 6, na.rm = TRUE) 就是“少于 6 小时的人数”（3 人），mean(条件) 就是“满足条件的比例”。

为什么“性别”最好存成因子？

课程数据中 gender 存为 0/1。如果把它当数值，R 会认为“女（1）比男（0）多 1 个单位”，可以算平均数（0.534）。对 0/1 变量，平均数恰好等于编码为 1 的那一类所占的比例（这里是女性比例 53.4%），还有意义；但对于有三个及以上类别的变量（如“服务类型：1 个案、2 小组、3 社区”），把类别编码当数字就错了：“社区 = 3 倍的个案”没有意义。存成因子后：

  • R 知道这是类别，table()、summary() 会给出各类人数（男 373、女 427）。
  • 回归中 R 会自动把因子转为虚拟变量，并以第一个水平（level）为参照组。
  • 画图时自动按类别分组上色，标签显示“男 / 女”而不是 0 / 1。
  • 对因子求 mean() 会返回 NA 并给出警告，避免了无意义的计算。

缺失值 NA：会“传染”的未知

mean(c(1, NA, 3)) 返回 NA。逻辑很朴素：有一个值不知道，平均数当然也不知道。要在已知值中计算，加参数 na.rm = TRUE（NA remove，移除 NA）：mean(c(1, NA, 3), na.rm = TRUE) 返回 2。sum()、sd()、min()、max() 都有这个参数。

NA 与比较

NA < 6 的结果仍是 NA（不知道）。所以 sleep[sleep < 6] 会返回 5.5 NA 4.5 NA 5.0，两个 NA 混了进来。正确写法是加上“并且不是缺失”：sleep[sleep < 6 & !is.na(sleep)]。is.na() 判断每个值是否缺失，! 表示“非”，& 表示“并且”，| 表示“或者”。which(sleep < 6) 会自动忽略 NA，返回位置 2、6、10。找缺失值也不能写 x == NA（结果全是 NA），必须用 is.na(x)。

矩阵与列表：向量的两个“亲戚”

后面的课程还会遇到两种结构，这里先认识一下：

  • 矩阵（matrix）：二维的、所有元素类型相同的表格，有行和列。glmnet 要求预测变量是数值矩阵（3.5 课的 as.matrix()）；CLPN 的结果 B 也是一个 9 × 9 矩阵，第 i 行第 j 列用 B[i, j] 取出，逗号前是行、逗号后是列。数据框（2.3 课）也是二维表，但每列可以是不同类型；要把数据框交给 glmnet 等只接受矩阵的函数，先确认所有列都是数值，再用 as.matrix() 转换。
  • 列表（list）：可以装不同类型、不同长度东西的“大口袋”。很多函数的结果都是列表，例如 lm() 的结果里装着系数、残差、拟合值等，用 $ 取出其中一项，如 fit$coefficients。2.1 课的 sessionInfo()$R.version$version.string 就是在列表里一层层往下取。

社会工作情境：缺失值本身是信息

na.rm = TRUE 只是跳过缺失值，相当于只用有数据的人。在需求评估问卷中，“家庭收入”一题常有很多人不填。直接 na.rm = TRUE 计算平均收入，可能高估社区的经济水平，因为收入最低的家庭往往最不愿意回答。所以在用 na.rm 之前，先用 sum(is.na(x)) 看看缺了多少，再想一想是谁没填、为什么没填（4.3 课专门讨论缺失机制）。

自己写函数

当同一个操作要做很多次时，可以把它包装成{{T:自定义函数|user-defined function}}：

zscore <- function(x) (x - mean(x, na.rm = TRUE)) / sd(x, na.rm = TRUE)

读法：创建一个名叫 zscore 的函数，它接收一个输入 x，返回“x 减去 x 的均值，再除以 x 的标准差”。函数体较长时用花括号 { } 包起来，最后一行的值就是返回值。之后 zscore(sleep) 就像用 mean() 一样简单。

② 最少数学向量的记号

$$\mathbf{x} = (x_1, x_2, \dots, x_n)$$
\(\mathbf{x}\)
粗体表示一个向量（一整列数）。
\(x_i\)
第 \(i\) 个元素，对应 R 的 x[i]。
\(n\)
元素个数，对应 length(x)。

向量化运算就是“逐元素”运算：\(60\mathbf{x} = (60x_1, \dots, 60x_n)\)，\(\mathbf{x}+\mathbf{y} = (x_1+y_1,\dots,x_n+y_n)\)。z 分数函数：

$$z_i = \frac{x_i-\bar x}{s_x},\quad i = 1,\dots,n$$

\(\bar x\) 和 \(s_x\) 只用非缺失值计算（这就是 na.rm = TRUE）；缺失的 \(x_i\) 对应的 \(z_i\) 仍是 NA。逻辑值求和：\(\sum_i \mathbb{1}(x_i<6)\)，其中 \(\mathbb{1}(\cdot)\) 在条件成立时为 1、否则为 0，对应 sum(x < 6)。

完整例题：缺失值、类型转换与“循环补齐”

下面每一行先自己预测结果，再到 R 里运行核对。这些都是写 CLPN 脚本时会真实遇到的情况。

```r x <- c(3, NA, 5, 2) mean(x) # NA：只要有一个缺失，结果就是 NA mean(x, na.rm = TRUE) # 3.333…：(3 + 5 + 2) / 3，分母是 3 不是 4 sum(is.na(x)) # 1：TRUE 被当作 1 相加，常用来数缺失个数 c(1, "2", 3) # "1" "2" "3"：混入一个字符，整个向量都变成字符 as.numeric(c("4", "五")) # 4 NA，并给出警告 NAs introduced by coercion f <- factor(c("10", "20", "10")) as.numeric(f) # 1 2 1 ！得到的是水平编号，不是原来的数 as.numeric(as.character(f)) # 10 20 10：先转成字符，再转数值 c(1, 2, 3, 4) + c(10, 20) # 11 22 13 24：短向量被重复使用（循环补齐） y <- c(8, 6, 9) y[-1] # 6 9：负号表示“去掉第 1 个” y[y > 7] # 8 9：逻辑向量做索引 ```

逐条解释：

  • NA 会“传染”。这是 R 有意的设计：它不会悄悄忽略缺失。CLPN 中计算总分时，如果某题缺失，rowSums() 默认会返回 NA，你需要明确决定怎么处理（4.3 课）。
  • 向量只能有一种类型。从 Excel 导入时，“缺失”“不适用”这样的文字也会把整列变成字符。
  • 因子（factor）的陷阱。因子内部存的是 1、2、3 这样的编号，外面贴着标签。直接 as.numeric() 会拿到编号。SPSS 数据导入后常常带有这样的标签，务必小心。
  • 循环补齐。两个向量长度不同时，R 会重复短的那个。长度刚好是倍数时 R 不会警告，所以长度写错了可能悄无声息地得到错误结果。
常见错误
  • 忘记把结果赋值保存。sort(x) 只是显示排序结果，x 本身不变；需要写 x <- sort(x)。

函数的参数：按位置，还是按名字？

函数调用 round(3.14159, 2) 中，3.14159 和 2 是两个参数。R 允许按位置传参（第 1 个是要舍入的数，第 2 个是保留几位小数），也允许按名字传参：round(x = 3.14159, digits = 2)。按名字写更清楚，顺序也可以任意调换。建议的习惯是：第 1 个参数（通常是数据）按位置写，其余参数一律写名字。例如 mean(x, na.rm = TRUE)、cor(x, y, use = "pairwise.complete.obs")。这样半年后回头看脚本，仍然一眼就知道每个设置是什么意思。

读帮助文档的顺序

2.1 课介绍了帮助页的 Usage、Arguments 和 Examples。这里补两点。第一，Usage 中等号后面是默认值；默认值是一个向量时，表示默认用第一个，例如 ?cor 中的 method = c("pearson", "kendall", "spearman") 表示默认 pearson。第二，Value 一节说明函数返回什么（向量、矩阵还是列表），决定了后面该用 [ ] 还是 $ 取结果。

练习 2.2-A：睡眠向量

用向量存 10 个人的睡眠时长（含 2 个 NA），计算均值、找出少于 6 小时的人；写一个函数 zscore(x) 返回标准化后的向量，与 scale() 结果对比。

参考代码 ```r sleep <- c(7, 5.5, 8, NA, 6, 4.5, 7.5, NA, 9, 5) mean(sleep, na.rm = TRUE) # 6.5625 which(sleep < 6) # 2 6 10（第几位） sleep[sleep < 6 & !is.na(sleep)] # 5.5 4.5 5.0（具体时长） zscore <- function(x) { m <- mean(x, na.rm = TRUE) s <- sd(x, na.rm = TRUE) (x - m) / s # 最后一行就是返回值 } all.equal(zscore(sleep), as.numeric(scale(sleep))) # TRUE ```

要点：说明 NA 的处理方式；解释为什么 which() 给位置、方括号给值；all.equal() 比较两个结果是否（在浮点误差内）相等。

小结带走三句话

  • 向量是一排同类型的值；[ ] 按位置、条件或名字取值；运算自动向量化。
  • 四种基本类型：数值、字符、逻辑（TRUE = 1）、因子（类别变量）；类型错了，后续分析都会出错。
  • NA 会传染：用 na.rm = TRUE 和 is.na()，并想一想缺失的原因。下一课：{{L:2.3}}。
