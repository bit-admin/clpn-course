① 直觉“这个差异是真的，还是碰巧？”

女性更抑郁吗？

课程数据里，女性（427 人）的 T1 抑郁总分平均 4.21，男性（373 人）平均 3.41，差了 0.79 分。督导问：“这 0.79 分是两类人群真的有差别，还是只是这次抽样碰巧抽到的？”上一课你知道了，任何样本统计量都会因为抽样而波动；即使总体中男女完全没有差别，样本里也几乎不可能正好差 0 分。我们需要一个规则来判断：差异大到什么程度，才不太可能“只是碰巧”。

假设检验的逻辑：先假设“没有效应”，再看数据有多“意外”

类比：法庭审判

法庭遵循“无罪推定”：先假设被告无罪，再看证据。如果在“无罪”的前提下，这些证据极不可能出现，法官才判有罪。证据不足时判“无罪”，并不等于证明了被告清白，只是“不能排除合理怀疑”。

统计检验沿用这个逻辑：

  1. 提出{{T:零假设|null hypothesis, H₀}}：“没有效应”。例如“总体中男女抑郁均值相同”。与之对立的是{{T:备择假设|alternative hypothesis}} H₁：“有差异”。
  2. 假设 H₀ 为真，计算：像我们这样的数据（或更极端的数据）出现的概率有多大。这个概率就是{{T:p 值|p-value}}。
  3. 如果 p 很小（小于事先定好的{{T:显著性水平|significance level, α}}，通常 α = 0.05），就说数据与 H₀“不太相容”，拒绝 H₀，称结果“统计显著”。否则“不拒绝 H₀”。

拖动滑块：观察到的检验统计量越极端（离 0 越远），两条红色尾巴的面积（p 值）越小。当 |z| 超过 1.96 时，p < 0.05。课程数据中男女抑郁差异的 t = −3.33，p ≈ 0.0009：如果总体中男女真的没有差别，抽到这么大（或更大）差异的概率不到千分之一。

p 值的常见误读

p = 0.03 不表示以下任何一项
  • “零假设为真的概率是 3%。”p 值是在假定 H₀ 为真的前提下算出来的，它不能反过来告诉你 H₀ 为真的概率。
  • “结果有 97% 的概率是真的。”理由同上。
  • “效应很大 / 很重要。”p 值同时受效应大小和样本量影响，见下文。
  • “p = 0.06 说明没有效应。”“不显著”只是证据不足，不等于证明了“没有差异”。
  • “p = 0.049 和 p = 0.051 有本质区别。”0.05 只是一条约定俗成的线。

正确：“如果零假设为真，观察到至少这么极端的结果的概率是 0.03。”

统计显著 ≠ 实际重要：效应量

p 值的大小取决于两件事：效应有多大、样本有多大。样本非常大时，微小到没有实际意义的差异也会“显著”：SE 随 \(\sqrt n\) 缩小，任何非零的差异最终都会被检测出来。所以必须同时报告{{T:效应量|effect size}}：一个不随样本量膨胀、描述“效应有多大”的指标。

  • Cohen's d：两组均值差除以合并标准差，“两组相差几个标准差”。粗略参考：0.2 小、0.5 中、0.8 大。课程数据中男女抑郁差异 d = 0.235：统计上非常显著，但效应小。社工实务中，这意味着性别不是区分抑郁风险的强有力指标，个体差异远大于组间差异。
  • 相关系数 r 和标准化回归系数 β 本身也是效应量。CLPN 的边权重就是一种效应量。

两类错误与统计功效

真相：H₀ 为真（无效应）真相：H₀ 为假（有效应）
判决：拒绝 H₀{{T:I 类错误|Type I error}}（假阳性），概率 = α正确发现，概率 = 功效
判决：不拒绝 H₀正确II 类错误（假阴性），概率 = β

{{T:统计功效|statistical power}} = 1 − β：当效应真实存在时，研究能检测到它的概率。功效取决于效应大小、样本量和 α。小样本研究功效低，容易漏掉真实的小效应；而且小样本中“碰巧显著”的结果往往高估了效应。社工研究常常样本不大，这一点在解读“不显著”时尤其重要。（注意：这里表格中的 β 是 II 类错误的概率，与回归系数 β 只是同一个希腊字母，含义完全不同。）

多重比较：一个网络有 190 条可能的边

α = 0.05 意味着：每做一次 H₀ 为真的检验，有 5% 的机会犯 I 类错误。如果一次做很多检验呢？一个有 20 个节点的横断面网络，有 20 × 19 / 2 = 190 对节点。如果每一对都做显著性检验，即使所有真实关系都是 0，平均也会有 190 × 0.05 = 9.5 条“显著”的假边。这就是{{T:多重比较|multiple comparisons}}问题。

勾选 Bonferroni 校正（把 α 除以检验次数）后，假边几乎消失；但代价是门槛变得极高，真实的小效应也很难被发现。网络分析通常走另一条路：{{T:正则化|regularization}}（3.5 课的 LASSO、6.3 课的 graphical lasso），不逐条做显著性检验，而是让模型把不够强的边压成 0。所以很多 CLPN 论文里看不到每条边的 p 值。但要注意：正则化并不控制假阳性。用交叉验证选 λ（lambda.min）时，留下的边里常混有不少假阳性（{{L:7.2}} 会看到具体数字）；CLPN 方法论文推荐的完整流程，最后也要用 p 值筛选路径（{{L:7.5}}）。

② 最少数学检验统计量与 Cohen's d

大多数检验统计量都长这样

$$\text{检验统计量} = \frac{\text{估计值} - \text{H}_0\text{ 下的值}}{SE} \qquad \text{例：}\; z = \frac{(\bar x_1 - \bar x_2) - 0}{SE(\bar x_1 - \bar x_2)}$$

读法：“估计值离零假设有几个标准误那么远”。离得越远，在 H₀ 下越“意外”，p 越小。|z| > 1.96 ⇔ 双侧 p < 0.05 ⇔ 95% CI 不包含 0，这三句话说的是同一件事。R 的 summary(lm()) 里 “t value = Estimate / Std. Error” 就是这个公式（2.5 课）。

p 值的定义

$$p = P\big(\,|Z| \ge |z_{\text{观测}}| \;\big|\; H_0 \text{ 为真}\big)$$
\(P(\cdot)\)
概率。
竖线 \(\mid\)
读作“在……的条件下”。p 值是条件概率：条件是 H₀ 为真。
\(|Z| \ge |z_{\text{观测}}|\)
“至少和观察到的一样极端”（双侧：两个方向都算）。

微积分视角：p 值就是正态曲线下两条尾巴的面积，即概率密度函数的积分 \(2\int_{|z|}^{\infty} \varphi(u)\,du\)，其中 \(\varphi\) 是标准正态的密度函数。

Cohen's d

$$d = \frac{\bar x_1 - \bar x_2}{s_p}, \qquad s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}$$

\(s_p\) 是合并标准差（pooled SD）：两组方差的加权平均再开根号。课程数据：\(d = (4.21-3.41)/s_p \approx 0.235\)，可反推 \(s_p \approx 3.37\)。

③ R 代码t 检验、效应量与多重比较模拟

对应脚本：R/L1-6.R。

```r 1. t 检验：女性与男性的抑郁总分是否不同？ source("R/_setup.R") dat <- read_course_data() dat$dep_sum_t1 <- rowSums(dat[, paste0(dep_items, "_t1")]) t.test(dep_sum_t1 ~ gender, data = dat) # ~ 读作“按……分组” ``` ```out 输出（R/output/L1-6_log.txt） Welch Two Sample t-test data: dep_sum_t1 by gender t = -3.3345, df = 796.39, p-value = 0.0008939 alternative hypothesis: true difference in means between group 0 and group 1 is not equal to 0 95 percent confidence interval: -1.2601649 -0.3262758 sample estimates: mean in group 0 mean in group 1 3.412869 4.206089 ```

逐项读：

  • Welch Two Sample t-test：不假设两组方差相等的 t 检验（R 的默认，较稳妥）。
  • t = -3.3345：检验统计量。负号是因为 R 用“组 0（男）减组 1（女）”。
  • df：自由度，决定 t 分布的形状；Welch 检验的自由度可以是小数。
  • p-value = 0.0008939：p ≈ 0.0009 < 0.05。
  • 95 percent confidence interval: -1.26 -0.33：（男 − 女）均值差的 95% CI，不包含 0，与 p < 0.05 一致。
```r 2. 效应量 Cohen's d m <- tapply(dat$dep_sum_t1, dat$gender, mean) # 按性别分组求均值 s <- tapply(dat$dep_sum_t1, dat$gender, sd) n <- table(dat$gender) sp <- sqrt(((n[1] - 1) * s[1]^2 + (n[2] - 1) * s[2]^2) / (sum(n) - 2)) # 合并标准差 cat("Cohen's d =", round((m[2] - m[1]) / sp, 3), "（0.2 小 / 0.5 中 / 0.8 大）\n") ``` ```out 输出（R/output/L1-6_log.txt） Cohen's d = 0.235 （0.2 小 / 0.5 中 / 0.8 大） ``` ```r 3. 多重比较：20 个毫无关系的变量 → 190 个相关检验 set.seed(1) noise <- matrix(rnorm(200 * 20), 200, 20) # 200 人 × 20 个纯噪声变量 pv <- c() for (i in 1:19) for (j in (i + 1):20) pv <- c(pv, cor.test(noise[, i], noise[, j])$p.value) cat("纯噪声中，190 个相关里 p < .05 的有", sum(pv < .05), "个（期望约 9.5 个假阳性 false positives）\n") cat("Bonferroni 校正后显著的有", sum(p.adjust(pv, "bonferroni") < .05), "个\n") ``` ```out 输出（R/output/L1-6_log.txt，节选） 纯噪声中，190 个相关里 p < .05 的有 15 个（期望约 9.5 个假阳性 false positives） Bonferroni 校正后显著的有 0 个 ```

这次碰巧出现了 15 个假阳性（期望值 9.5，每次模拟会有波动）。p.adjust(pv, "bonferroni") 把每个 p 值乘以 190（上限为 1），等价于把 α 除以 190。

完整例题：从均值差到 p 值

干预组与对照组各 50 人，干预后孤独均值分别为 5 和 6，两组 SD 都是 2。

  1. 效应量 Cohen's d = (6 − 5) / 2 = 0.5，属于“中等”。
  2. 均值差的标准误 = 2 × √(1/50 + 1/50) = 2 × 0.2 = 0.4。
  3. t = 1 / 0.4 = 2.5，自由度 98，双侧 p ≈ .014。

同样 d = 0.5，如果每组只有 10 人：SE = 2 × √(0.2) ≈ 0.894，t ≈ 1.12，p ≈ .28，“不显著”。效应没变，变的只是证据的多少。所以论文要同时报告效应量和 p 值。

常见错误
  • 试了很多分析，只报告显著的那个（p-hacking）。换协变量、换子样本、换计分方式，每试一次都是一次新的检验；多重比较模拟说明，做 190 次检验平均会有 9.5 个“碰巧显著”。只报告显著的那个，读者就无从知道背后试过多少次。对策是事先写好分析计划（{{L:10.1}}），并报告所有做过的分析。

练习 1.6-B：思考（150 字）

一个有 20 个节点的网络有 190 条可能的边，逐条做显著性检验会出现什么问题？有哪些可能的应对方法？

要点
  • 问题：多重比较 → 即使所有真实边为 0，期望也有约 9.5 条假阳性边；网络图会“看起来很丰富”但很多边是噪音。
  • 应对：(1) 校正 α（Bonferroni 等），但功效会大幅下降；(2) 正则化估计（LASSO / graphical lasso），把弱边压为 0，这是网络分析的主流做法（模块 3.5、6.3），但它本身不控制假阳性率；(3) 用 bootstrap 评估边的稳定性（模块 8）；(4) 在独立样本中复现。

练习 1.6-D：用“法庭”走一遍检验

以本课的男女抑郁差异（t = −3.33，p ≈ 0.0009）为例，按三步写出：(1) H₀ 和 H₁；(2) p 值在说什么；(3) 你的决策（α = 0.05）。再回答：这个决策如果错了，会是哪一类错误？如果换成一项 n = 30、p = 0.20 的研究，又可能犯哪一类错误？

参考答案

(1) H₀：总体中男女的平均抑郁总分相同；H₁：不同。(2) 如果 H₀ 为真，抽到至少这么大差异的概率约为 0.0009。(3) p < 0.05，拒绝 H₀，差异统计显著（同时报告 d = 0.235，效应小）。拒绝了 H₀，如果错了就是 I 类错误（假阳性）。n = 30、p = 0.20 时不拒绝 H₀，如果真实效应存在，就是 II 类错误（假阴性）；样本小、功效低，这种错误很容易发生。

小结带走三句话

  • p 值 = 若 H₀ 为真，得到至少如此极端结果的概率；它不是 H₀ 为真的概率，也不衡量效应大小。
  • 永远同时报告效应量（d、r、β）与置信区间；大样本中微小效应也会显著。
  • 边很多时逐条检验会产生大量假阳性。网络分析常用正则化把弱边压成 0，但正则化本身也不保证没有假阳性。M1 到此结束，配合 {{L:2.1}}–{{L:2.6}} 完成 R 基础后，下一统计模块进入回归分析 {{L:3.1}}。
