① 直觉结果只有“是 / 否”的时候

谁会来寻求专业帮助？

社区服务中心想知道：抑郁分越高的居民，越可能主动寻求专业帮助吗？男性和女性有差别吗？课程数据里有一个变量 help_seek_t2：T2 时是否寻求过专业帮助（1 = 是，0 = 否）。800 人中有 182 人（22.8%）寻求了帮助；女性 28.6%，男性 16.1%。现在结果变量不再是连续分数，而只是“是 / 否”，这叫{{T:二分类结果|binary outcome}}。

为什么不直接用一条直线？

用普通线性回归预测 0/1 变量（称为“线性概率模型”），预测值可以解释为“寻求帮助的概率”。但这有三个问题：

  1. 概率有边界，直线没有。概率必须在 0 和 1 之间，而直线向两端无限延伸：抑郁分足够高时预测概率会超过 1，足够低时会小于 0，而“−10% 的概率去求助”没有意义。（课程数据中抑郁分范围有限，线性模型的预测值恰好落在 0.08–0.55 之间，但只要换个样本或外推，问题就会出现。）
  2. 关系很可能不是直线。在概率很低或很高时，同样的变化通常带来更小的概率变化：一个本来就极不可能求助的人，抑郁多 1 分也不会让他突然可能求助；一个已经很可能求助的人，概率也不能再涨多少。中间段变化最快。这种形状是 S 形。
  3. 误差不满足线性回归的假设。0/1 结果的残差只能取两个值，方差随预测值变化，标准误会不准。

{{T:逻辑回归|logistic regression}}的办法是：不直接对{{T:概率|probability}}画直线，而是先把概率换算成一个没有边界的量（对数几率），对它画直线，再换算回来，结果就是一条永远在 0 和 1 之间的 S 形曲线。

（组件中的散点是虚构的示意数据，横轴为 0–10 的“孤独感”；课程数据的真实结果见 R 代码部分。）

三个换算：概率 → 几率 → 对数几率

{{T:几率|odds}}（也译作“优势”）= 发生的概率 ÷ 不发生的概率。日常说“胜负三七开”就是一种几率说法。

概率 p几率 p/(1−p)读法对数几率 ln(odds)
0.100.1111 次发生 : 9 次不发生−2.20
0.200.251 : 4−1.39
0.501一半一半0
0.7533 : 11.10
0.9099 : 12.20

概率的范围是 0–1；几率的范围是 0 到 +∞；取自然对数后，{{T:对数几率|log-odds / logit}}的范围是 −∞ 到 +∞，没有边界了，可以用直线建模。

几率比：逻辑回归系数的“翻译”

逻辑回归的系数 b 表示：x 每增加 1，对数几率增加 b。对数几率不好理解，所以通常取指数 \(e^{b}\)，得到{{T:几率比|odds ratio, OR}}（也译“比值比”“发生比”）：x 每增加 1，几率乘以 OR。

  • OR = 1：几率不变（没有关联）。
  • OR = 1.5：几率乘以 1.5，即增加 50%。
  • OR = 0.67：几率乘以 0.67，即减少约 33%（0.67 ≈ 1/1.5，与 OR = 1.5 强度相同、方向相反）。
  • OR = 2：几率翻倍，但不是概率翻倍。
OR = 2 不等于“概率翻倍”

假设某人求助的概率是 0.5（几率 = 1）。OR = 2 让几率变成 2，概率变成 2/(1+2) = 0.667，只增加了 0.167，远不是 1.0。只有当事件很罕见（概率很小，例如 < 0.1）时，几率 ≈ 概率，OR 才近似于“概率的倍数”（风险比）。新闻里常把 OR 说成“风险增加 X 倍”，在事件不罕见时会夸大效应。

社会工作中的二分类结果

是否辍学、是否接受转介、是否复发、是否参加小组、是否有自伤行为……社会工作研究中的很多关键结果都是二分类的。逻辑回归是分析它们最常用的工具之一。

广义线性模型：一个大家族

线性回归和逻辑回归都属于{{T:广义线性模型|generalized linear model, GLM}}：先把预测变量做线性组合 \(b_0+b_1x_1+\cdots\)，再通过一个“连接函数”和结果变量的均值联系起来。线性回归的连接是“什么都不做”（恒等），逻辑回归的连接是 logit；计数结果（如求助次数）常用泊松回归（log 连接）。R 用同一个函数 glm() 拟合它们，用 family 参数选择家族。

与 CLPN 的联系：二分类节点

CLPN 的每个方程是“用全部 T1 节点预测一个 T2 节点”。如果某个节点是“是 / 否”题目（例如“过去两周是否有自杀念头”），这个方程就不能用线性回归，而要用逻辑回归。CLPN 所用的 glmnet 包同样支持带 LASSO 惩罚的逻辑回归，只需设定 family = "binomial"（R 代码部分有示例）。混合类型节点的网络还可以用 mgm 包（本课程不展开，知道有这个工具即可）。

② 最少数学logit 与 S 形曲线

$$\ln\!\left(\frac{p}{1-p}\right) = b_0 + b_1x_1 + b_2x_2$$
\(p\)
事件发生（如寻求帮助 = 1）的概率。
\(\frac{p}{1-p}\)
几率 odds。
\(\ln\)
自然对数（以 \(e\approx2.718\) 为底）。
\(b_0, b_1, b_2\)
系数：\(x_1\) 每增加 1，对数几率增加 \(b_1\)。

把方程反解，就得到概率本身（logistic 函数，S 形）：

$$p = \frac{1}{1+e^{-(b_0+b_1x_1+b_2x_2)}}$$

无论括号里的数多大或多小，\(p\) 总在 0 和 1 之间：括号 → +∞ 时 \(e^{-\cdots}\to0\)，\(p\to1\)；括号 → −∞ 时 \(p\to0\)。

为什么 \(e^{b_1}\) 是几率比？

\(x_1\) 从 \(x\) 增加到 \(x+1\)（其他不变），对数几率增加 \(b_1\)：\(\ln(\text{odds}_{x+1}) - \ln(\text{odds}_x) = b_1\)。对数之差等于比值的对数，所以 \(\text{odds}_{x+1}/\text{odds}_x = e^{b_1}\)。这个比值与 \(x\) 的起点无关：OR 是“乘法”的固定效应，而概率的变化量随起点而变。

估计方法不是最小二乘，而是{{T:最大似然|maximum likelihood}}：找让“观察到这批 0 和 1”的可能性最大的系数（第 5 模块的模型也用这个思路）。

③ R 代码glm(family = binomial)

对应脚本：R/L3-4.R。性别编码 0 = 男，1 = 女。

```r R/L3-4.R（核心部分） source("R/_setup.R") dat <- read_course_data() dat$dep_sum_t2 <- rowSums(dat[, paste0(dep_items, "_t2")]) fit <- glm(help_seek_t2 ~ dep_sum_t2 + gender, data = dat, family = binomial) summary(fit) OR <- exp(cbind(OR = coef(fit), confint.default(fit))) # exp(系数) = 几率比 odds ratio round(OR, 3) ``` ```out 输出（R/output/L3-4_log.txt，节选） Coefficients: Estimate Std. Error z value Pr(>|z|) (Intercept) -2.15441 0.17601 -12.241 < 2e-16 *** dep_sum_t2 0.13379 0.02462 5.434 5.5e-08 *** gender 0.63509 0.18091 3.510 0.000447 *** Null deviance: 857.98 on 799 degrees of freedom Residual deviance: 810.16 on 797 degrees of freedom AIC: 816.16 OR 2.5 % 97.5 % (Intercept) 0.116 0.082 0.164 dep_sum_t2 1.143 1.089 1.200 gender 1.887 1.324 2.690 ```
逐项读输出
  • Estimate 是对数几率尺度的系数：抑郁每高 1 分，对数几率高 0.134。
  • z value / Pr(>|z|)：逻辑回归用 z 检验（Wald 检验），读法同 t 检验。
  • OR 表：抑郁 OR = 1.143，95% CI [1.089, 1.200]。控制性别后，抑郁每高 1 分，求助几率乘以 1.14（增加约 14%）；区间不含 1，显著。性别 OR = 1.887：抑郁分相同时，女性求助的几率约为男性的 1.89 倍。截距的 OR 0.116 是“男性、抑郁 0 分”时的几率（概率约 0.104）。
  • Deviance 类似“残差平方和”：只有截距的模型 857.98，加入两个预测变量后降到 810.16。AIC 用于比较模型，越小越好。逻辑回归没有普通的 R²。
  • 注意：OR 的置信区间用 confint.default()（基于 Wald 方法），是 \(e^{b\pm1.96SE}\)；它在 log-odds 尺度上对称，取指数后在 OR 尺度上不对称。
和“真相”对照：模拟数据的好处

打开 data/simulate_data.R，可以看到 help_seek_t2 是这样生成的：rbinom(N, 1, plogis(-2.2 + 0.18 * 抑郁总分 + 0.4 * 性别))。也就是说真实的抑郁系数是 0.18（OR = e0.18 ≈ 1.20），性别系数是 0.4（OR ≈ 1.49）。我们的估计是 0.134 和 0.635，都和真值有差距，但 95% 置信区间（抑郁约 [0.086, 0.182]，性别约 [0.28, 0.99]）都覆盖了真值。这就是抽样误差的样子（1.5 课）：即使模型完全正确、N = 800，一次估计也不会正好等于真值；二分类结果携带的信息比连续分数少，所以误差更大。plogis() 就是 R 里的 logistic 函数 \(1/(1+e^{-x})\)，qlogis() 是它的反函数 logit。

```r 把系数翻译成概率：不同抑郁分与性别的预测概率 nd <- expand.grid(dep_sum_t2 = c(0, 5, 10, 15), gender = 0:1) nd$p <- round(predict(fit, newdata = nd, type = "response"), 3) # type = "response" 给概率 nd ``` ```out 输出（R/output/L3-4_log.txt，节选） dep_sum_t2 gender p 1 0 0 0.104 2 5 0 0.185 3 10 0 0.306 4 15 0 0.463 5 0 1 0.180 6 5 1 0.299 7 10 1 0.455 8 15 1 0.620 ```

看：同样的 OR（1.143/分），抑郁从 0 到 5 分，男性概率增加 0.081；从 10 到 15 分，增加 0.157。概率的变化随起点而变，这就是 S 形曲线。另外女性的 OR 是 1.887，但概率并不是男性的 1.887 倍（例如 15 分时 0.620 vs 0.463，比值仅 1.34）。

完整例题：从 logit 到概率

假设模型为 logit(p) = −2 + 0.5x，x 是抑郁总分，p 是“求助”的概率。

  1. x = 2：logit = −1，p = 1/(1 + e1) ≈ 0.269。
  2. x = 3：logit = −0.5，p ≈ 0.378。
  3. x = 4：logit = 0，p = 0.5。
  4. OR = e0.5 ≈ 1.65。x 从 2 到 3，odds 从 0.269/0.731 ≈ 0.368 变为 0.368 × 1.65 ≈ 0.607，对应 p = 0.607/1.607 ≈ 0.378，和第 2 步一致。

注意概率的增幅：从 2 到 3 增加了约 0.11，从 3 到 4 增加约 0.12，到了曲线两端增幅会越来越小。OR 是固定的，概率的变化不是。

常见错误
  • 直接解读 Estimate 列。summary(glm) 给出的是 log-odds，需要 exp() 才变成 OR。置信区间也要一起取指数：本课统一用 exp(confint.default(fit))（Wald 区间，即 \(e^{b\pm1.96SE}\)）。confint(fit) 对 glm 给出的是另一种区间，叫{{T:轮廓似然区间|profile likelihood CI}}，样本小或事件少时比 Wald 区间更准确；样本较大、事件不太少时，两者通常非常接近。两种都可以用，但同一篇报告里要统一，并在方法部分写明用的是哪一种。
  • 忽视“完全分离”的警告。如果某个预测变量能把 0 和 1 完美分开，R 会警告 “fitted probabilities numerically 0 or 1 occurred”，系数和 SE 会变得极大。这时要检查数据，而不是照抄结果。
  • 事件太少还放入很多预测变量。常见的经验法则是每个预测变量至少有 10 个“少数类”事件。

报告模板

论文中报告逻辑回归，一般包含：结果变量及其编码（1 = 求助，0 = 未求助）、各组人数、每个预测变量的 OR 及其 95% CI 和 p 值。例如：“控制性别后，T2 抑郁每高 1 分，求助的几率增加 X%（OR = …，95% CI […, …]，p = …）。”其中 X% = (OR − 1) × 100%。若 OR < 1，则写“几率降低 (1 − OR) × 100%”。为了让读者对效应有直观感受，还可以报告两个典型个体（例如抑郁 2 分与 10 分）的预测概率，用 predict(fit, newdata, type = "response") 得到。

⑤ 练习动手练习

练习 3.4-A：解释一个 OR

用 glm(family = binomial) 预测“是否寻求专业帮助”（help_seek_t2），预测变量为 T2 抑郁总分和性别。(1) 用一句话解释性别的 OR；(2) 说明 OR = 1.5 与 OR = 0.67 的含义。

参考答案

(1) 控制 T2 抑郁后，女性寻求专业帮助的几率约为男性的 1.89 倍，OR = 1.89，95% CI [1.32, 2.69]，p < .001。（注意说“几率”而不是“概率”或“可能性是 1.89 倍”。）

(2) OR = 1.5：预测变量每增加 1 个单位，几率乘以 1.5，增加 50%；OR = 0.67：几率乘以 0.67，降低约 33%。两者互为倒数，表示强度相同、方向相反的关联。

练习 3.4-B：加入孤独感

在模型中再加入 T1 孤独总分。孤独感的 OR 是多少？显著吗？请用 predict(..., type = "response") 比较孤独分为 6 和 12 的两名女性（T2 抑郁都为 5 分）的预测概率。

参考代码与提示 ```r dat$lone_sum_t1 <- rowSums(dat[, paste0(lone_items, "_t1")]) fit2 <- glm(help_seek_t2 ~ dep_sum_t2 + gender + lone_sum_t1, data = dat, family = binomial) round(exp(cbind(OR = coef(fit2), confint.default(fit2))), 3) predict(fit2, newdata = data.frame(dep_sum_t2 = 5, gender = 1, lone_sum_t1 = c(6, 12)), type = "response") ```

结果：孤独感 OR = 1.018，95% CI [0.960, 1.078]，p = .554，不显著；抑郁和性别的 OR 几乎不变（1.137、1.904）。两名女性的预测概率分别为 0.289 和 0.311，相差只有约 2 个百分点。解释：在模拟数据中，“是否求助”只由抑郁和性别生成（见 data/simulate_data.R），所以控制它们之后孤独感几乎没有额外预测力。你知道“真相”，所以可以检验方法是否给出了正确的答案。在真实数据中，“不显著”不能被解读为“没有关系”（3.3 课）。

练习 3.4-C：概率与几率互换

把概率 0.05、0.25、0.6 换成几率；再把几率 0.5 和 4 换回概率。

参考答案

0.05 → 0.0526；0.25 → 0.333；0.6 → 1.5。几率 0.5 → 0.5/1.5 = 0.333；几率 4 → 4/5 = 0.8。注意概率 0.05 时几率 0.0526 与概率几乎相等，所以罕见事件时 OR ≈ 风险比。

练习 3.4-D：直线 vs S 形；glmnet 的二分类版本

(1) 用 lm(help_seek_t2 ~ dep_sum_t2 + gender, data = dat) 拟合线性概率模型，用 range(fitted(...)) 看预测值的范围。这次预测值都在 0–1 之间，为什么仍然推荐逻辑回归？(2) 运行本课“带 LASSO 的逻辑回归”代码，再把 s = "lambda.min" 改成 s = "lambda.1se"，各有几道题的系数不为 0？

参考答案

(1) 预测值约在 0.08–0.55 之间，碰巧没越界。但换一个样本或外推到更高的抑郁分，直线就可能给出大于 1 的“概率”；而且真实关系是 S 形，0/1 结果的残差方差也随预测值变化，标准误不准。逻辑回归没有这些问题。(2) lambda.min 保留 3 道抑郁题（dep1、dep3、dep5）；lambda.1se 下 9 道题全部为 0。只要设 family = "binomial"，同一个 glmnet 就能处理二分类节点。

小结带走三句话

  • 二分类结果用逻辑回归：对对数几率建直线模型，概率是 S 形曲线，永远在 0–1 之间。
  • 系数取指数得 OR：x 每增 1，几率乘以 OR；OR ≠ 概率倍数（事件不罕见时差别大）。
  • glm 是一个家族；glmnet 也可以 family = "binomial"，为 CLPN 中的二分类节点做准备。下一课：{{L:3.5}}。
