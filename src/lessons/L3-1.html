① 直觉穿过点云，画一条“最好”的直线

社会支持能“预测”抑郁吗？

社工站计划为社会支持低的居民开展“邻里互助”小组。立项前，督导想知道：在我们的数据里，社会支持每高 1 分，抑郁总分平均会低多少？1.4 课相关矩阵里的 r = −0.18 告诉我们“有负相关、比较弱”，但没有回答“低多少分”。回答这个问题的工具是{{T:回归|regression}}：用一条直线概括“X 变化时，Y 平均怎样变化”。

在回归里，用来预测的变量叫{{T:自变量/预测变量|predictor}}（这里是社会支持，记作 x），被预测的叫{{T:因变量/结果变量|outcome}}（抑郁，记作 y）。一条直线由两个数确定：

  • {{T:截距|intercept}} \(b_0\)：x = 0 时直线的高度（直线和纵轴的交点）。
  • {{T:斜率/回归系数|slope / coefficient}} \(b_1\)：x 每增加 1 个单位，预测的 y 变化多少。这是我们最关心的数。

对每个人，直线给出一个“预测值” \(\hat y\)；实际值 \(y\) 和预测值之差叫{{T:残差|residual}}：\(e = y - \hat y\)。残差就是直线“没猜中”的部分：点在直线上方，残差为正；在下方，为负。

什么是“最好”的直线？

直线可以画无数条。我们需要一个标准。最常用的标准是：让所有残差的平方加起来最小。这叫{{T:最小二乘法|ordinary least squares, OLS}}（“二乘”就是“平方”的旧称）。为什么是平方？和 1.2 课的方差同一个理由：去掉正负号，并且让“猜得特别离谱”的点付出更大的代价。

请先自己拖动两个滑块，试着让残差平方和（SSE）尽量小；勾选“画出残差平方”可以看到每个点贡献的橙色正方形。然后再点“显示最小二乘解”看看你离最优有多远。下方的小图画的是：当斜率取不同值时 SSE 的大小。它是一条碗形曲线，最低点处切线水平，也就是“导数等于 0 的地方是极值点”。

斜率怎么读：一个“平均意义上”的说法

课程数据中，用社会支持（1–5 分）预测 T1 抑郁总分（0–15 分），R 给出：

$$\widehat{\text{抑郁}} = 6.36 - 0.75 \times \text{社会支持}$$
  • 斜率 −0.75：社会支持每高 1 分，预测的抑郁总分平均低 0.75 分。比如社会支持 2 分的人，预测抑郁 = 6.36 − 0.75 × 2 ≈ 4.86；社会支持 4 分的人，预测 ≈ 3.35。
  • 截距 6.36：社会支持 = 0 时的预测值。但量表最低是 1 分，没有人得 0 分，截距只是让直线“定位”的数学参数，不应解读为“完全没有社会支持的人抑郁 6.36 分”。在数据范围之外的预测叫{{T:外推|extrapolation}}，要非常小心：样本里社会支持在 1–5 分之间，用这条线去预测 0 分或 8 分的人都没有根据。想让截距有意义，可以先把 x 中心化（减去均值），截距就变成“社会支持处于平均水平的人”的预测值。
用词：“预测”而不是“导致”

“社会支持每高 1 分，抑郁平均低 0.75 分”描述的是人与人之间的比较：社会支持高 1 分的那群人，平均抑郁低 0.75 分。它不等于“如果给某个人增加 1 分社会支持，他的抑郁会降低 0.75 分”。后一种说法是因果的、个人内部的，需要干预研究。这个区分在 4.1 课（被试间 vs 被试内）和 5.4 课会再次出现。

R²：直线解释了多少差异？

如果完全不用 x，最好的猜法是“人人都猜平均数 \(\bar y\)”，此时的误差平方和叫总平方和（SST）。用了回归直线后，误差变成 SSE。直线“消除”的那部分比例就是{{T:决定系数|R²}}：

$$R^2 = 1 - \frac{SSE}{SST}$$

课程数据中 R² = 0.031：社会支持只解释了抑郁差异的约 3%。这是否说明模型“没用”？不一定：

  • 人的心理状态受成百上千种因素影响，单个预测变量能解释 3%–10% 在心理和社会研究中很常见；
  • R² 小不等于斜率不重要：在全人群层面，平均 0.75 分的差异也可能有政策意义；
  • 但 R² 小确实意味着：用社会支持去预测某一个人的抑郁，会很不准（个体之间散布得很开）。

在简单回归（只有一个 x）里有一个好记的事实：\(R^2 = r^2\)。这里 \((-0.175)^2 \approx 0.031\)。

为什么要看残差图？

回归直线总能画出来，但它是否“合适”？看残差：以预测值为横轴、残差为纵轴画散点图，R 里是 plot(fit, which = 1)（见下面的代码）。理想情况下应该是一团在 0 上下随机散布、宽度大致不变的点。如果看到弧形（关系其实是曲线）、喇叭口（预测值越大残差越分散，误差大小随预测值变化，标准误可能不准确），或几个离得很远的点（极端值），就说明直线模型可能不够好。我们的抑郁数据是右偏的、有大量 0 分，残差图会出现明显的“条纹”和不对称，这在李克特数据中很常见。这时报告结果要更谨慎，可以改用稳健标准误，并在论文中说明这一局限。

② 最少数学用求导找到最好的 b₀ 和 b₁

$$\hat y_i = b_0 + b_1 x_i \qquad SSE(b_0,b_1) = \sum_{i=1}^{n}\big(y_i - b_0 - b_1 x_i\big)^2$$
\(\hat y_i\)
第 \(i\) 个人的预测值（“y 帽”）。
\(b_0, b_1\)
待求的截距和斜率。
\(SSE\)
残差平方和（sum of squared errors），是 \(b_0,b_1\) 的函数：换一条线，SSE 就变。

要让 SSE 最小，对两个未知数分别求偏导（把另一个当常数），令其等于 0：

$$\frac{\partial SSE}{\partial b_0} = -2\sum_i (y_i - b_0 - b_1x_i) = 0, \qquad \frac{\partial SSE}{\partial b_1} = -2\sum_i x_i(y_i - b_0 - b_1x_i) = 0$$

“\(\partial\)”读作“偏”，偏导数就是“只让一个变量动、其他不动时”的导数，求法和普通求导一样（这里用了链式法则）。解这两个方程，得到：

$$b_1 = \frac{\operatorname{cov}(X,Y)}{\operatorname{var}(X)} = r\cdot\frac{s_Y}{s_X}, \qquad b_0 = \bar y - b_1\bar x$$

三个值得记住的推论：

  1. 斜率 = 协方差 / X 的方差：回归系数和相关系数关系密切，区别只在量尺。如果 X 和 Y 都标准化了（\(s_X=s_Y=1\)），斜率就等于相关系数 r（3.3 课）。
  2. 第一个方程说明 \(\sum e_i = 0\)：OLS 直线的残差加起来恰好为 0；而且直线一定穿过点 \((\bar x, \bar y)\)。
  3. 1.2 课的微积分补充是这里的特例：没有 x 时（只有 \(b_0\)），最优的 \(b_0\) 就是 \(\bar y\)。

课程数据验证：\(\operatorname{cov}/\operatorname{var} = -0.7519\)，\(\bar y - b_1\bar x = 6.3604\)，与 lm() 输出完全一致。

公式语法 y ~ x

R 里 ~（波浪号）左边是结果变量、右边是预测变量。多元回归就是在右边用 + 加更多变量：y ~ x1 + x2 + x3（下一课）。这个语法在 glm()（3.4 课）、lavaan（5.2 课）中都会用到。

完整例题：手算一条回归线

沿用 1.4 课的 5 个人：x（孤独）= 1、2、3、4、5，y（抑郁）= 2、4、5、4、5。已算得协方差 1.5，x 的方差 2.5。

  1. 斜率 b₁ = cov(x, y) / var(x) = 1.5 / 2.5 = 0.6。
  2. 截距 b₀ = ȳ − b₁ x̄ = 4 − 0.6 × 3 = 2.2。回归线是 ŷ = 2.2 + 0.6x。
  3. 预测值依次为 2.8、3.4、4.0、4.6、5.2；残差（y − ŷ）为 −0.8、0.6、1.0、−0.6、−0.2，加起来正好是 0。
  4. 残差平方和 = 0.64 + 0.36 + 1 + 0.36 + 0.04 = 2.4；总平方和 = 6，所以 R² = 1 − 2.4/6 = 0.6，正好等于 r² = 0.775²。

在 R 中验证：lm(y ~ x) 会给出截距 2.2、斜率 0.6。lm() 做的就是找残差平方和最小的那条线。

常见错误
  • 以为“x 预测 y”的斜率倒过来就是“y 预测 x”的斜率。反过来回归的斜率是 cov / var(y)，一般不等于 1/b₁。上例中 y 对 x 的斜率是 0.6，x 对 y 的斜率是 1.5 / 1.5 = 1.0，而不是 1/0.6 ≈ 1.67。两者的乘积等于 r² = 0.6。
  • 把斜率大小当成关系强弱。b₁ 依赖单位：生活满意度用 0–100 分和用 0–10 分，斜率差 10 倍。比较强弱要看 r 或标准化系数（3.3 课）。

```r source("R/_setup.R") dat <- read_course_data() dat$dep_sum_t1 <- rowSums(dat[, paste0(dep_items, "_t1")]) plot(jitter(dat$social_support_t1), jitter(dat$dep_sum_t1), pch = 16, col = rgb(0, 0, 0, .25)) my_b0 <- 7; my_b1 <- -1 # ← 换成你自己读出的数 sum((dat$dep_sum_t1 - (my_b0 + my_b1 * dat$social_support_t1))^2) ```
参考答案

OLS：截距 6.36、斜率 −0.75、RSS = 8942.8。你的直线的 RSS 一定 ≥ 8942.8（等号仅在你恰好画出 OLS 直线时成立）。很多人手画的直线会比 OLS 更陡。原因不是少数高分点，而是人眼倾向于沿着点云的“长轴”画线，画出来的接近 {{T:SD 线|SD line}}（斜率 = ±sy/sx，穿过两个均值）或主轴（让点到直线的垂直距离最小）。OLS 只让竖直方向的残差最小，它的斜率是 r·sy/sx；只要 |r| < 1，它的绝对值就比 SD 线小，看起来更“平”。这也是“回归向均值”的另一种说法：x 高 1 个 SD 的人，y 平均只高（或低）|r| 个 SD。写一句话解释：OLS 直线之所以“最好”，只是在“残差平方和最小”这个特定标准下最好。

4 个人：x = 1, 2, 3, 4；y = 2, 4, 5, 5。计算 OLS 的 \(b_1\) 和 \(b_0\)，并写出每个人的残差，验证残差之和为 0。

\(\bar x = 2.5,\ \bar y = 4\)。离均差 x：−1.5, −0.5, 0.5, 1.5；y：−2, 0, 1, 1。乘积和 = 3 + 0 + 0.5 + 1.5 = 5；x 离均差平方和 = 2.25 + 0.25 + 0.25 + 2.25 = 5。\(b_1 = 5/5 = 1\)，\(b_0 = 4 - 1\times2.5 = 1.5\)。预测值 2.5, 3.5, 4.5, 5.5；残差 −0.5, 0.5, 0.5, −0.5，和 = 0 。（\(b_1\) 用“协方差/方差”时，分子分母的 n − 1 相互抵消，所以直接用离均差乘积和 / 离均差平方和即可。）

小结带走三句话

  • 回归直线 ŷ = b₀ + b₁x；斜率 = x 每增 1 单位，预测的 y 平均变化多少。
  • OLS = 让残差平方和最小；用偏导数为 0 求解，得 b₁ = cov / var(x)。
  • R² = 被直线解释的差异比例；R² 小不等于斜率无意义。下一课：{{L:3.2}}。
